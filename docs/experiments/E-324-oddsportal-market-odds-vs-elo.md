# E-324. Кэфы OddsPortal против ELO на pp-картах

- **Дата:** 2026-09-23. Продолжение [E-323](E-323-pp-accuracy-levers-stage4.md): владелец выбрал
  «История кэфов + прокси», затем «Публичный бесплатный прокси».
- **Вопрос:** несёт ли рынок силу команд сверх ELO `new3x_dur_ac` + драфт по про-лигам + pm20
  (70,52 % на pp, E-323)?
- **Прогноз до замера:** AUC рынка на pp 0,73–0,77; прибавка +0,3…+1,2 п.п. **Не сбылся.**

## Как достали кэфы

- **Фиды OddsPortal зашифрованы.** Ответ `/proxy/ajax-*` = base64(«шифртекст_base64:iv_hex»),
  AES-256-CBC, ключ = PBKDF2-SHA256 (1000 итераций) из пароля и соли, которые открыто лежат в
  JS-бандле сайта; внутри gzip + JSON (`op_decrypt.py`). Простой GET без браузера и без cookies
  отдаёт тот же ответ, что и страница.
- **Фильтр букмекеров — на сервере по IP.** Из Германии/Болгарии архив PGL Wallachia S7 даёт
  `total 0 … no odds available from your selected bookmakers` при любой маске букмекеров в URL,
  включая «все биты» и «только Pinnacle (id 18)». Маска в URL игнорируется.
- **Поправка к прошлому выводу.** «Из CA/JP/MX/AR/ZA киберспорт скрыт» — ошибка: `/esports/results/`
  перенаправляет на футбольные результаты из любой страны, включая Германию. Архивы турниров из этих
  стран открываются.
- **Перебор стран (`geo_sweep.py`).** 26 647 публичных прокси из proxifly, proxyscrape и geonode,
  ответили 1 366. Архив с кэфами (47 матчей) видят NL, JP, FR, KR, MX, RU, FI, UA, PL, DE и CN
  (страна — по IP прокси).
- **Букмекеры по странам** (id в `positionsWithProviders`): KR — 12, JP и DE — 7, FI — 5, PL — 4,
  RU, FR и NL — 2. **Pinnacle (18) нет ни в одной стране.** 1xBet (417) есть в KR, JP и DE.
- **Список турниров.** На новом сайте общего архива турниров Dota нет. Дневные страницы
  `/esports/<дата>/` хранят только 30 дней. Турниры нашлись подбором слага `dota-2-<название>` по
  названиям лиг master: 7 из 17 попыток. Отборочные, EPL Masters и EWC не нашлись.
- **Строки архива:** линия на серию (`bettingTypeId 3`, `scopeId 2`), средний кэф по активным
  букмекерам. Первый исход — хозяева: исход совпал с `home-winner` в 324 из 324 строк. Фаворит
  рынка выиграл серию в 67,0 % из 324.

## Склейка с master (`build_op_market.py`)

- **Турнир → лига** по точному названию, команды — по названиям id (`base/id_to_names.py` +
  OpenDota `/api/teams`), старт серии ±6 ч.
- **Итог склейки:** 215 из 297 серий master, 461 карта. Счёт серии совпал в 202 из 215.
- **Без пары остались:** 1win Essence II (7 из 28), BLAST Slam VII (51 из 79), PGL S8 (11 из 19).
- **Вероятность на карту:** линия на серию без маржи, обращённая по формуле best-of-N (N из
  `stypes`).

## Результат (435 pp-карт теста, 204 серии, 6 турниров, медиана 13 букмекеров)

| прогноз | точность | AUC | log loss |
|---|---|---|---|
| ELO | 61,15 % | 0,654 | 0,6585 |
| рынок | 61,38 % | 0,663 | 0,6510 |
| E-323 (помесячные фолды, как в E-323) | 66,90 % | 0,688 | 0,6341 |
| A: LR [ELO, драфт, pm20], leave-one-tournament-out | 64,14 % | 0,685 | 0,6376 |
| B: A + рынок, LOTO | 63,45 % | 0,693 | 0,6339 |
| S: LR [E-323, рынок], LOTO | 63,91 % | 0,681 | 0,6386 |

Сравнения:
- **B − A:** точность −0,69 п.п. [−3,52; 2,03], log loss −0,0037 [−0,0137; 0,0070].
- **S − E-323:** −2,99 п.п. [−5,12; −0,92]. **Рынок − E-323:** −5,52 п.п. [−11,09; −0,66].
- **Корреляция логитов:** рынок–ELO 0,918, рынок–E-323 0,805.
- **Стандартизованные веса в B:** ELO 0,063, драфт 0,462, pm20 0,068, рынок 0,595. Рынок вытесняет
  ELO, а не добавляется к нему.

**Механизм.** На топ-турнирах рынок видит силу команд так же, как наш рейтинг игроков: корреляция
логитов 0,918. Сверх ELO у него остаётся около +0,01 AUC, а драфта в линии на серию нет. Это
согласуется с потолком E-322: информация о силе насыщена, и ещё один её источник точность не
двигает. Эти 435 карт — самые трудные в тесте: E-323 на них 66,9 % против 70,52 % на всех 1 720.

## Итог этапа

- Рычаг «кэфы рынка» по точности закрыт. Pinnacle недоступен, а средний рынок из 13 букмекеров
  повторяет ELO.
- Лучшим остаётся 70,52 % (E-323). До 71,9 % не хватает 1,4 п.п.
- **Проверено заодно:** паблик-корпус (5,09 млн карт, 24.03–09.08.2026) как рейтинг для
  малоопытных игроков. У 92 % игроков pp-карт за 30 дней до карты 0 паблик-игр в нём, ≥ 10 игр
  только у 3,7 %. Источник непригоден.

## Где искать ошибку

- **Средний кэф ≠ закрытие Pinnacle.** Среднее по 13 букмекерам (в KR-наборе) мягче острой линии.
  Гипотеза (не проверено): Pinnacle дал бы больше, но линия средних букмекеров обычно идёт за ним.
  Проверка — проспективный сбор линий Pinnacle.
- **Покрытие неполное.** Нет отборочных, EPL Masters и EWC; 82 серии без пары. Выборка смещена к
  LAN-финалам, где команды ровнее.
- **LOTO-обучение на ~370 картах слабее помесячных фолдов на всём master** (A 64,14 % против E-323
  66,90 %). Поэтому прибавку рынка честно сравнивать как B − A, а не B − E-323.
- **Формат best-of-N** взят из `stypes` первой карты серии. Bo2 обращён как условная вероятность без
  ничьей.
- **Страна прокси определена по IP самого прокси** (ip-api), а не по выходу. У части прокси это
  разные страны.
