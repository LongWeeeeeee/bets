# E-382. ELO-фаворит против первой цены Winline после драфта

**Вопрос (карточка ingame-yxst).** Бьёт ли ELO цену Winline на исход карты в момент, когда драфт закончен, а игра только началась? Карточка ждала до 20.11 сбора предматчевых цен. Владелец 10.10: «можно и на прошлых всё понять». Первая котировка Winline после драфта уже лежит в двух источниках:
- в панели E-378 — строка на 0–5′ игры;
- в журнале диспетчера — тик до горна (game_time ≈ −79 с), в истории котировок Winline.

**Решение, которое меняется:** предлагать ли владельцу новое правило WIN-ставки на старте карты.

**Контекст.**
- E-360: против Pinnacle у ELO A края нет (−3,5 %).
- E-378, контроль: ставка на ELO-фаворита (|ΔELO| ≥ 50) по первой цене без фильтра даёт −1,5 % (n 183). Андердог: −16,9 %.
- Контрпрогноз в карточке (08.10): Winline копирует острые конторы, маржа больше, значит ROI < 0.

## Метод

- **Вероятность ELO.**
  - Панель: P(Radiant) из `elo_a` в base_table.npz, предматчевая, причинная. Для сравнения — `elo_k24`.
  - Журнал: `1/(1+10^(−elo_diff/400))` по ELO прода в момент тика. До 25.09 10:02 это K24, после — A.
- **Цена.** Котировка Winline на победителя текущей карты, обе стороны из одной котировки, маржа снята пропорционально.
  - Панель: первая строка с ценой при minute_live 0–5. Ориентация — по team_id (E-378).
  - Журнал: последняя принятая открытая котировка в [ts−600; ts+5]. Обе команды совпадают по имени точно, иначе карты нет (правило E-373).
- **Правило.** Перевес = P_ELO(сторона) − P_рынок(сторона). Ставка на ELO-фаворита, если перевес ≥ 0,05. Одна ставка на карту, 1 единица по цене котировки.
- **Исход.**
  - Панель: radiant_win, сверен с base_table (0 расхождений из 329).
  - Журнал: STRATZ didRadiantWin (197 карт), леджер ELO (1).
- **Выборки не пересекаются.** 167 карт журнала, которые есть в панели, исключены.
- **Статистика.** ROI = mean(победа·кэф − 1). Бутстрэп по сериям: 2 000 повторов, seed 20261010.

**Прогнозы (записаны до прогонов).**
- Панель: δ 0,05, все стороны: ≈ −3 % [−15; +9].
- Журнал, после панели: δ 0,05, только фаворит: ≈ +5 % [−12; +22].
- Порог «прошло»: ROI > 0 по точке. «Сильно»: нижняя граница ДИ > 0.

## Независимая проверка (gpt-6-astra, Worked-by: claude, run 4e21e998)

**VERIFIED: арифметика и ориентация сторон.**
- Ориентация: журнал 15/15 (8 ставок с кэфом ≥ 2, один обратный порядок p1/Dire), панель 10/10 при кэфе ≥ 2 (3 обратные ориентации). Сверено с сырыми котировками, team_id корпуса и победителями STRATZ. Переворота сторон нет.
- Пересчёт с нуля сошёлся: панель 151 / 99 побед / +10,93 %; журнал 98 / 62 / +11,38 %; вместе 249 / 161 / +11,11 % [+1,19; +22,09]. Кэф ≥ 2: 87 / 48 / +25,9 %. Повторных карт нет, NaN не просачивается.
- Котировок с прошлой карты нет: 0 из 102, минимальный разрыв 1 619 с.

**Найденные слабые места:**
- **Кластеры.** Одна серия попала в обе половины, а `pool.py:13` разводит её префиксом источника. С общими id серий (100 000 повторов): ДИ [+0,14; +22,45].
- **Котировка после «missing».** Карта 9014519155 взяла открытую цену возрастом 80 с, хотя за 1,6 с до решения записан `missing` (`gate_cf.py:186` такие строки отбрасывает). Без этой карты: 248 ставок, +10,74 % [−0,35; +22,06].
- **Только прошлые цены.** 15 из 98 цен журнала взяты из следующих 5 с (окно ts+5, `journal_oos.py:27`). Если брать только цены до решения: журнал 90 / 57 / +10,5 %.
- **Время входа.** 92 из 98 ставок журнала сделаны до горна (game_time ≈ −79 с). Если первый тик брать строго на 0–300 с после горна: 68 ставок, +2,3 % [−18,0; +25,2]. После горна цена уже включает события игры, а ELO стоит на месте, поэтому правило — для цены до горна.
- **Исходы.** 13 подходящих сигналов выкинуты без исхода: STRATZ их не знает, в свежем леджере ELO с serv1 их тоже нет. Если все 13 проиграли, журнал даёт −1,7 %. **Компромисс:** 13 из 111 сигналов, худший случай указан.
- Перекос «фаворит — длинный кэф» как объяснение не доказан. Поправка на перебор клеток панели не делалась.

## Вывод и механизм

- **Прогноз ведущего провален.** Ждал −3 %, получил +6,9 % на обе стороны и +10,9 % на фаворите. Прогноз на журнал (+5 %) по точке превышен: +11,4 %.
- **Механизм (гипотеза, проверяемая).** В среднем ELO и первая линия Winline одинаково точны по log loss, но ошибаются по-разному:
  - когда Winline даёт фавориту ELO меньше, чем ELO (часто делает его андердогом, кэф ≥ 2), прав чаще ELO;
  - когда Winline увереннее ELO в фаворите, ставка на андердога по ELO проигрывает (K24 −17,5 %).
  Это классический перекос «фаворит — длинный кэф» у конторы плюс сведения ELO о силе команд, которых нет в первой линии. Зона дохода — умеренные фавориты (P_ELO 0,5–0,7, +22 %). У сильных фаворитов (≥ 0,7) края нет: −2,6 %.
- **Почему не протухшая цена:** через 1–5 минут край почти тот же (+10,8 %).
- **Новое WIN-правило на старте карты = новая автоматическая ставка** — нужно решение владельца. Предлагаемое правило — ровно записанное до журнала: ELO-фаворит, перевес ≥ 0,05, цена не старше 300 с, env-флаг, отдельный тег правила для учёта.
- **Что опровергнет:** ROI ≤ 0 на ≥ 100 новых ставках после 10.10, по журналу с тем же харнессом (`journal_oos.py` на свежей копии serv1). Либо найденная ошибка ориентации сторон — её проверяет независимый верификатор (gpt-6-astra, Worked-by: claude).

## Где искать ошибку

- **Ориентация сторон — главный подозреваемый.** Перепутанные p1/p2 Winline дали бы ложную «победу фаворита по кэфу ≥ 2». Как обеспечена ориентация:
  - журнал: имена из canonical_key (p1 = первое из двух последних полей), обе команды должны совпасть точно;
  - панель: team_id + `orientation.json` E-378 (тест с переворотом красный).
  Отдельная сверка по сырым строкам — у верификатора.
- **NaN в ELO.** Первая версия `elo_vs_q1.py` не выкидывала карты без ELO A: `abs(NaN) < δ` ложно, и такие карты ставились на Dire. Это дало ложные −0,8 %. Исправлено фильтром `np.isfinite`. В журнальном скрипте elo_diff проверяется на конечность.
- **Подбор на панели.** На панели просмотрено 18 клеток: 2 ELO × 3 δ × 3 стороны. Только фаворитная сторона выбрана по прежним данным: андердог по ELO в минусе в E-374, E-378, E-380. Журнальная половина проверялась одной заранее записанной клеткой.
- **Гиперпараметры ELO A** подобраны 25.09 (E-338) на данных, включающих панель. K24 даёт тот же или больший край. Журнал до 25.09 считан на K24 прода как есть, без пересчёта.
- **Часы панели.** «Минута 0» = start_ts + off_seconds. На августе глобальные часы свежее на ~1,5 мин (E-378). На цене это почти не сказывается: в первые минуты она стоит.
- **Пропуски.** В журнале 151 карта без котировки и 23 без исхода — отбор не зависит от исхода. Связка с доставленными ставками прода по леджеру ненадёжна (`market` пуст у 552 строк), поэтому пересечение с уже сделанными ставками не доказано: «нет ставки прода» у 96 из 98.
