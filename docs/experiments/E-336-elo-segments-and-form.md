# E-336. K24 по типам матчей и «форма» поверх рейтинга

- **Запрос владельца (24.09.2026), после [E-335](E-335-elo-swing-mov-and-ceiling.md):**
  - «Протестируй наше ELO на разных типах матчей: offline, online, tier1 vs tier1, tier2 vs tier2, tier3 vs tier3
    и их миксы, квалы, начало турнира (плей-офф обычно начинается после перерыва в пару дней и без вылетевших
    команд), плей-офф, финалы».
  - «Возможно, нам недостаточно ELO: у команды высокий рейтинг, но сейчас она в плохой форме; рейтинг снизится со
    временем, но это время — куча лузов».
- **Что оценивается:** показываемый в Telegram K24 — среднее K24 пяти аккаунтов (E-335). Вероятности взяты из реплея
  E-335: он совпадает с боевым `k24_prob` до 3·10⁻⁸.

## Часть 1. Типы матчей (`segments.py`)

**Разметка:**
- **LAN/онлайн и тир Liquipedia** — сопоставление лиг с `liquipedia_tournaments.json` по подмножеству токенов
  названия, покрытие 8,7 % карт (97 лиг).
- **Тиры команд** — текущие списки `tier_one_teams` / `tier_two_teams` + overlay; остальные команды считаются T3.
- **Стадия** (72,5 % карт):
  - в каждой лиге ищется самый длинный перерыв ≥ 36 ч после ≥ 40 % серий;
  - до перерыва — группы, после — плей-офф;
  - первая серия после перерыва — «старт плей-офф»;
  - последняя серия лиги в bo3/bo5 — финал;
  - первая серия команды в лиге — «старт турнира».

`gap` — прогноз ELO для фаворита минус его фактический винрейт. Минус значит, что фаворит выигрывает чаще, чем
говорит ELO. Δ — лучший вариант E-335 (`new3x_dur_ac+km_e31`) к K24 на валидации и тесте вместе, с 95 % ДИ.

**Итоги по типам матчей:**
- **Разница в точности между типами — это разница в разрывах рейтингов, а не в качестве ELO.** Квалы угадываются
  на 73 %, потому что там много явных фаворитов (AUC 0,82). T1 против T1 — на 62 %, потому что команды близки.
  Почти половина тестовых карт (47 %) имеет |ΔELO| < 50 и угадывается на 54 %. Там и сидят промахи.
- **LAN и онлайн не отличаются:** 63,5 % против 63,2 %.
- **Старт турнира и старт плей-офф не хуже групп.** Гипотеза «ELO ошибается после перерыва перед плей-офф» не
  подтвердилась: 64,2 % на 279 картах, на валидации и тесте вместе 60,6 % на 637.
- **Калибровка расходится в двух местах:**
  - в квалах, плей-офф и финалах фаворит выигрывает чаще прогноза: gap −0,02…−0,06;
  - в T1 против T1 — реже: +0,043 на 1 396 картах валидации и теста. Разброс рейтингов топ-команд шире, чем
    разница их силы.

  Точность это не меняет (фаворит тот же), меняет уверенность панели.
- **Смена состава:** 59,7 % против 62,5 % при том же составе. Калибровка в обоих случаях в норме, просто такие
  матчи менее предсказуемы.

## Часть 2. Форма (`form_replay.py`)

**Персистентность остатков.**
- **Как считалось:** для каждой стороны берётся сумма (исход − прогноз K24) за 5 последних карт, закончившихся до
  начала текущей: R5. Затем смотрится остаток следующей карты. Две единицы: 5 аккаунтов состава и id команды.
- **Выборка:** валидация и тест вместе — 77 951 карта, 155 902 стороны.
- **Что вышло:** связь монотонная и значимая на всех картах и на не-pp. На pp хвостов нет: при R5 ≤ −2 остаток
  +0,005 [−0,057; +0,069] (n = 217), при R5 ≥ 2 +0,028 [−0,028; +0,082] (n = 293).

| R5 | состав (5 аккаунтов): карт / остаток следующей | id команды: карт / остаток |
|---|---|---|
| ≤ −2 | 1 042 / −0,071 [−0,098; −0,042] | 2 443 / −0,031 [−0,049; −0,012] |
| −2…−1 | 10 915 / −0,045 | 12 817 / −0,014 |
| −1…0 | 64 665 / −0,011 | 89 120 / −0,004 |
| 0…1 | 63 769 / +0,011 | 32 643 / +0,007 |
| 1…2 | 13 649 / +0,033 | 15 599 / +0,017 |
| ≥ 2 | 1 862 / +0,062 [+0,041; +0,082] | 3 280 / +0,032 [+0,016; +0,047] |

**Сценарий владельца** — фаворит (p ≥ 0,6) в плохой форме (R5 ≤ −2):
- **по id команды** эффекта нет: 71,9 % против прогноза 70,2 % (n = 463);
- **по составу** эффект есть: 69,0 % против 73,3 % (n = 232), на не-pp 63,5 % против 72,5 % (n = 137);
- **на pp** обратное: по id команды 82,6 % против 74,6 % (n = 92), по составу 76,8 % против 74,4 % (n = 95).
  Это шум.

**Рычаг.** Двухмасштабный рейтинг: K24 плюс быстрая добавка f на аккаунт.
- **Обновление:** f растёт на K_f·(исход − прогноз), где прогноз — полный (K24 + f), и затухает с полураспадом
  h дней.
- **Сетка:** K_f ∈ {12, 24, 48}, h ∈ {3, 7, 14, 30}, версии по аккаунтам и по id команды.
- **Контроль:** K_f = 0 воспроизводит K24 до 2,7·10⁻¹⁵.
- **Выбор на валидации:** `acc_Kf24_h3` (log loss 0,65451 против 0,65574).

| тест | K24 | + форма | Δ, п.п. [95 %] | Δ log loss [95 %] |
|---|---|---|---|---|
| все карты (31 989) | 60,81 % | 61,06 % | +0,25 [−0,02; +0,53] | −0,0013 [−0,0019; −0,0007] |
| не-pp (18 867) | 60,40 % | 60,76 % | +0,36 [+0,04; +0,67] | −0,0015 [−0,0023; −0,0007] |
| pp (1 743) | 68,10 % | 68,39 % | +0,29 [−0,93; +1,44] | +0,0008 [−0,0023; +0,0040] |
| карты бота (2 240) | 67,23 % | 67,28 % | +0,05 [−1,03; +1,03] | +0,0004 [−0,0024; +0,0031] |

Версии по id команды слабее (лучшая +0,10 п.п.). K_f = 48 и h = 30 ухудшают валидацию.

**Механизм.**
- ELO по победам реагирует на серию неудач с опозданием: в хвостах следующая карта недобирает 3–7 п.п.
- Но хвосты редкие: |R5| ≥ 2 у 1,9 % сторон. Сдвиг вероятности на 0,05–0,07 меняет фаворита только при близком
  рейтинге, поэтому в точности набегает лишь +0,25 п.п.

## Часть 3. Форма поверх лучшего варианта E-335 (прогон run4)

- **Как сделано:**
  - в `swing_replay.py` добавлен токен `f<Kf>h<дни>` — та же быстрая добавка, что в `form_replay.py`;
  - контроль: `K24+f24h3` повторяет `acc_Kf24_h3` (тест 61,06 %, log loss 0,65117);
  - `K24` совпадает с боевым `k24_prob` до 3·10⁻⁸.
- **Выбор на валидации** (log loss; без формы 0,64581): f24h3 — 0,64630 (хуже), f24h7 — 0,64720, f24h2 — 0,64600,
  f12h3 — 0,64578, **f24h1 — 0,64568 (выбран)**.
- **Край сетки закрыт:** на чистом K24 полураспад 1 день на валидации тоже чуть лучше 3 дней (0,65440 против
  0,65451). На тесте разницы нет: 61,01 против 61,06 %.

Тест, `new3x_dur_ac+km_e31+f24h1`:

**Механизм.**
- Поверх лучшего варианта форма даёт около нуля: log loss к нему −0,00045 [−0,0009; 0,0000].
- Гипотеза (не проверено): разгон новичков ×3 и поправка 538 уже ускоряют реакцию рейтинга на свежие результаты,
  и быстрой добавке остаётся мало. Проверка — сравнить остатки R5 у варианта E-335 с остатками у K24.

## Прогнозы

- **Лид:** «остаток следующей карты в пределах ±0,02, рычаг ≤ +0,3 п.п.».
  - Первая часть **не сбылась**: хвосты −0,07 / +0,06.
  - Вторая **сбылась**: +0,25.
- **Владелец:** «ELO плохо работает на старте плей-офф после перерыва» — **не подтвердилось**: не хуже групп,
  фаворит выигрывает даже чаще прогноза.

## Где искать ошибку

- **LAN/онлайн размечены только на 8,7 % карт.** Остальные 28 852 тестовые карты без метки: микро-лиги, FACEIT,
  китайские лиги в Liquipedia не находятся. Сопоставление по подмножеству токенов может склеить квалы и основную
  стадию одноимённых турниров.
- **Тиры команд — сегодняшний снимок списков, а не на дату карты.** Команда, попавшая в T2 в августе, считается
  T2 и в мае.
- **Стадия — эвристика по перерыву.** Лига без перерыва ≥ 36 ч целиком считается группами. «Старт плей-офф» — одна
  серия на лигу (279 карт). Финал лиги, не доигранной к 20.09, — просто её последняя серия.
- **Остатки части 2 считаются по K24 без учёта формы.** В сценарии владельца n = 92…463, интервалы широкие.
- **h = 3 дня — край сетки.** Более короткий полураспад не проверялся.
- **Тестовый период 05–09.2026** использовался в E-319…E-335. Выбор здесь только по валидации.
