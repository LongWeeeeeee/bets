# E-269. Подтверждение анонимных карт по игрокам

- **Дата:** 2026-09-10 (запрос alex: live Inner Circle–PuckChamp и Zero
  Tenacity–Team Synapse; часть карт SourceTV приходит анонимно без команд —
  подтверждение искать по игрокам; кэфы должны идти в любом случае, карты —
  уже искаться).
- **Вопрос:** как проводить анонимные карты (нет team_id, имя-плейсхолдер)
  через пайплайн и опрос кэфов, не доверяя слепо устаревшим тегам составов.
- **Замер эфира (10.09.2026, Steam WebAPI):** лига EPL 19944 — 0 живых игр;
  broad (0) — 18 игр, почти все частично/полностью анонимны
  (`? vs ?`, `Nemiga Gaming vs ?`, `Dark Tamplars vs Stormriders`).
  Вывод: серий IC–PC / ZT–Synapse на GC прямо сейчас нет вообще — карты
  парсить не из чего, стратегия: (а) кэфы гнать с Winline независимо от моста,
  (б) анонимные GC-карты подтверждать и разбирать сразу как появятся.
- **Дизайн (синтез с решением пира E-267, не переименование):** peer deliberate
  pinned «имена из тегов НЕ строим» (замер: устаревшие теги LGD угоняют карту)
  + тест `test_roster_identification_does_not_rename_the_sides`. Итог:
  probe пишет в мост только EVIDENCE (`player_hint`: team_key при консенсусе
  4/5 + supporters), имена/id не трогает; ПОДТВЕРЖДАЕТ пару cyberscore ЖИВОЙ
  карточкой Winline (оба имени — имя моста или team_key хинта — в одной
  карточке). Нет карточки — прежний путь. Переименование происходит только
  при двойном подтверждении (составы 4/5 + букмекер с реальными деньгами).
- **Что сделано:**
  - probe: `_attribute_sides_by_players` (персидный консенсус, собственные
    имена/индекс/порог `_PLAYER_ATTRIBUTION_MIN_AGREE=4` — независимо от
    незакоммиченных хелперов допуска), `_is_anonymous_side`,
    `_player_hint_for_game` (хинт только анонимным сторонам; коллизия
    «обе стороны в один тег» гасит обе), `player_hint` в `_build_target`
    и в payload моста;
  - cyberscore: `_winline_player_confirm` (имена моста-неплейсхолдеры или
    team_key хинта → join снимка; team_key уровня radiant/dire отклоняется —
    такое слово есть в любом тексте), интеграция в team_id-гейт только на
    drop-path (подтверждённые имена/id идут обычным путём: тир, ELO, опрос
    кэфов через существующий поллер), лог `🧬 Player-confirmed`;
  - snapshot: рядом с текстом хранится capped DOM (`html`, 1.5M) — задел под
    перечисление карточек для кэфов series без GC (пока не используется).
- **Харнесс:** `base/tests/test_player_attribution.py` (8 тестов).
- **Запуск:** `venv_catboost/bin/python3 -m pytest base/tests/test_player_attribution.py base/tests/test_sourcetv_paths.py base/tests/test_winline_first_admission.py -q`
  (53 passed; red на HEAD-пробе через предзагрузку модуля: 5 failed —
  новых имён там нет).
- **Дефекты, найденные ДО выводов:** первая версия ПЕРЕПИСЫВАЛА имена/id в
  мосту — сломала тест пира `..._does_not_rename_the_sides`; переделано на
  evidence-only + подтверждение карточкой (тест пира снова зелёный).
- **Контроль:** хинт без карточки ничего не меняет (drop как раньше);
  плейсхолдер-ключи в join не ходят; коллизии гаснут; multi-id
  (PuckChamp {457 мёртв, 10164236 жив — проверено OpenDota) → max;
  allowlist/denylist не тронуты (E-268): хинт работает только внутри
  допущенных лиг, т.к. мост пишется только для них.
- **Где искать ошибку:** (1) устаревшие теги целого ростера, перешедшего
  вместе (4/5 укажут на СТАРУЮ организацию) — ловит только карточка, а если
  Winline тоже показывает старый бренд, ошибка сквозная: смотреть evidence
  (`account_ids`) и расхождение imён карточки/хинта; (2) порог 4/5 взят из
  замера E-267 на тикете 10877 — на других лигах не перемерялся;
  (3) `player_hint` в bridge пишется всегда (дешёвый чистый вызов), читается
  только на drop-path team_id-гейта.
- **Что НЕ сделано (следующий шаг):** кэфы series вообще без GC-присутствия
  (как IC–PC сейчас) — нужно перечисление карточек ленты в
  (лига, команды, карта); задел (DOM в snapshot) готов, нужен захват живой
  ленты dota_2 для контракта парсера.
- **Вывод:** внедрено. Откат: хинт игнорируется удалением чтения
  `player_hint` в гейте (одна ветка); поток опроса кэфов и гейты не тронуты.
