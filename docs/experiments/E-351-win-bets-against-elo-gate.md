# E-351. Запрет ставок на победу против ELO

- **Вопрос владельца (03.10.2026, после E-350):** ставки ML WIN против ELO проигрывают, пол по кэфу их не ловит. Владелец выбрал «запрет с проверкой»: сначала прогон, потом выкатка.
- **Прогноз до прогона** (`.omc/decisions.md`): частота выигрыша 30–37 %, средний кэф 3,4–3,8. При менее отобранном правиле цены доверительный интервал ROI пересекает ноль. После 30.09 ставок не больше 15. Итог: подтвердилось. Частота 33,9 %, кэф 3,9, ставок после 30.09 — 14, исход известен у 3.
- **Определение.** Целевая сторона WIN-решения — андердог, если её ELO (`elo_r`/`elo_d` из того же тика журнала) ниже ELO соперника на ≥ D. Сравнивались D = 0, 25, 50, 75, 100.

## Прочее

- **Корзины кэфов (P2):**
  - <2,5: 10/6, ROI −7,2 %. Здесь букмекер сам считает нашу сторону фаворитом.
  - 2,5–3,2: 3/8, −23,9 %.
  - 3,2–4,5: 2/7, −16,0 %.
  - ≥4,5: 3/13, +8,8 %.

  При P1 и P3 знаки другие. Пол по кэфу для ставок против ELO не выводится.
- **По правилу диспетчера:**
  - `win_single_model_confirm` отсеянные: 13/29, ROI −20…−26 % при всех трёх правилах цены.
  - `win_late_after_wait` отсеянные: 7/10, разброс по правилам цены огромный: P1 −83 %, P2 +20 %.
- **После 30.09:** 8 ставок, исход у 3 (2/1). Это ничего не значит.

## Решение

- Владелец 03.10: запрет с порогом 50, `base/ml_dispatch.py` `_win_against_elo`.
- Переменные: `ML_DISPATCH_WIN_UNDERDOG_BLOCK` (по умолчанию 1, откат =0) и `ML_DISPATCH_WIN_UNDERDOG_BLOCK_MIN_DIFF` (50).
- Отсеянные решения пишутся в журнал как `skipped` с причиной `win_against_elo_blocked`, стороной и обоими ELO. Поэтому их исходы и цены можно досчитать задним числом без теневого режима.
- **Перепроверить** после ~40 отсеянных карт с исходом на all7m (≈2 недели). Если P2 и P3 окажутся ≥ 0, снять запрет или поднять порог.
- **09.10.2026 — запрет снят по просьбе владельца** (карточка ingame-8ht2): `ML_DISPATCH_WIN_UNDERDOG_BLOCK` по умолчанию `0`, откат `=1` (возвращает и узкое снятие E-365). На момент решения: отсеянные с 03.10 — 18 карт, 9/7, по правилу ingame-3e0e P2 +70,6 %, P3 +15,8 % (16 карт с исходом из ~40); отстающие по NW андердоги эры all7m — 7/15, ROI Q1 −54,9 %, Q3 −37,7 % (E-365). Проверка ingame-3e0e теперь идёт по ДОСТАВЛЕННЫМ WIN-ставкам на андердога (|ΔELO| ≥ 50) с 09.10, отдельно ведущие и отстающие по NW на тике ставки.

- **Харнесс/запуск:** `venv_catboost/bin/python3 runtime/experiments/draft-cp/against_elo_gate_20261003/run.py` (Codex run 26f15b61, 22 мин) → `runtime/artifacts/draft-cp/against_elo_gate_20261003/{results.md,results.json,rows.json,verification.json}`. Входы — копии с serv1 от 03.10 ~08:45 в `inputs/`. Разбивка до/после 24.09 — однострочный подсчёт ведущего по `rows.json` (`elo_disadvantage ≥ 50`, `ts` < / ≥ 24.09 10:43 MSK, бутстрап по `cluster`).
- **Где искать ошибку:**
  - Это рекомендации, а не исполненные ставки. Цены — архивные котировки.
  - Исхода нет у 52 из 246.
  - P2 игнорирует закрытие рынка. P3 — котировка после решения.
  - Кластеры частично «пара команд × день».
  - Корзины и пороги не поправлены на множественность.
  - Граница каталога взята по времени старта прода, а не по полю журнала: хеша модели в строках нет.
