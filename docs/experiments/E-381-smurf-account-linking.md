# E-381. Связка смурф-аккаунтов про-игроков

- **Дата:** 2026-10-10. Запрос владельца: «почти у всех про игроков есть "смурф"
  аккаунты у кого-то больше 2. поищи информацию об этом и свяжи по каждому про
  игроку все его аккаунты. я думаю это очень важно» и «надо будет вероятно
  пересобрать модели где мы анализируем публичные игры персонажа». Карточка
  ingame-4k8x.
- **Вопрос:** сколько про-слотов без пабной истории закрывает связка аккаунтов,
  и сколько это стоит боевой модели ML Laning (refit_final, sha 6ea4ab2c) на
  про-картах. Пререгистрация до замера: прирост охвата свежей истории < +3 п.п.
  → хранилище не пересобираем.
- **Харнесс:** `runtime/experiments/pubs-rebuild/smurf_link/`
  - `d2pt/d2pt_harvest.py` — ростер и профили dota2protracker (curl_cffi
    `impersonate='chrome'`, Referer d2pt; простой curl получает 403);
    связь «аккаунт с пометкой `(smurf N)`/`(old)` → единственный аккаунт без
    пометки с тем же именем», без нечёткого сравнения.
  - `census/census.py` — перепись активных про-аккаунтов через STRATZ
    (анонимность, последняя рейтинговая игра, история ников); запускать с
    `PYTHONPATH=base`, иначе `_post` без токена и всё 403.
  - `behav/generate.py` — поведенческий поиск (герои, часы, роль, недели) по
    хранилищу истории.
  - `rebuild/export_aliased.py` — экспорт хранилища, где события всех
    аккаунтов одного игрока лежат под КАЖДЫМ его id (сервинг не меняется);
    кластер, два аккаунта которого сыграли в одном матче, отбрасывается как
    ложная связь. `--selftest`: пустая карта связей → байт-в-байт тот же
    экспорт.
  - `rebuild/history_value_eval.py` — та же модель, те же карты, история из
    хранилища против нулевой истории (ровно то, что сервинг видит у аккаунта
    без событий).
- **Артефакты:** `runtime/artifacts/pubs-rebuild/smurf_link/` —
  `d2pt/pro_alias_map_v2.json` (156 пар), `d2pt/alt_status_20261010.json`,
  `census/summary.md`, `behav/full/candidates.jsonl`,
  `history_value_prod20260926.json`.
- **Запуск:**
  `venv_catboost/bin/python3 runtime/experiments/pubs-rebuild/smurf_link/rebuild/history_value_eval.py --tag prod20260926`
  (≈10 мин на Маке); D2PT —
  `venv_catboost/bin/python3 runtime/experiments/pubs-rebuild/smurf_link/d2pt/d2pt_harvest.py --max-minutes 110`.

## Дефекты, найденные ДО выводов

- Импорт `base.stratz_map_result` из корня репо берёт `from keys import
  api_to_proxy` мимо `base/` → запросы без токена → 403 на всё. Починка:
  `PYTHONPATH=base`, перепись падает, если `keys` не импортировался.
- `players(steamAccountIds:[…])` в STRATZ принимает не больше 5 id; при 100
  id ответ пустой (мой первый замер «355 из 355 без данных STRATZ» был
  этим артефактом и выброшен).
- 3 из 5 пар «токен–прокси» STRATZ отвечают 403 (истёкшие токены, карточка
  ingame-g2mw), `_post` перебирает их по порядку: 4 вызова на запрос.
- Перепись считает «рейтинговой» игру с lobbyType 7, обход пабов —
  gameModeIds [22] в любом лобби (`maps_research.py:1529`). У Topson
  последняя игра по первому определению 14.09.2024, по второму 13.06.2025;
  обе >180 дней, корзина та же.

## Результат

**Кто без истории.** Про-карты после 04.09: 2 734 слота без ролевой истории
до карты (из 7 150), 355 аккаунтов; все 355 уже в списке обхода
(`pub_player_steam_ids.json`, 600 132 id) — список не причина.

| основной аккаунт (STRATZ) | аккаунтов | доля пустых слотов |
|---|---:|---:|
| анонимный, рейтинговых игр не видно | 184 | 55,7 % |
| открытый, последний рейтинг >180 дн | 59 | 30,5 % |
| открытый, рейтинг ≤30 дн | 95 | 11,3 % |
| прочие | 17 | 2,5 % |

**Источники связей.**

| источник | что дал | проверка |
|---|---|---|
| D2PT ростер + 334 профиля | 156 пар, 106 игроков, 262 аккаунта | точный (имя с пометкой → имя без), неполный: альтов Topson/Azverin нет |
| история ников STRATZ | перепись 2 205 аккаунтов, наборы ников | ники — не id второго аккаунта; нужны кандидаты |
| поведенческий поиск | 3 013 запросов с кандидатами | на парах D2PT: из 16 проверяемых пар настоящий альт в топ-20 у 1 → **опровергнут** |

**Охват** (28 707 карт, порядок парсера, задержка 3 600 с):

| карты | без связей | со связями D2PT | прирост |
|---|---:|---:|---:|
| все | 46,08 % | 46,24 % | +0,16 п.п. |
| после 04.09 (715) | 61,76 % | 63,36 % | **+1,6 п.п.** (114 слотов) |

Почему мало: из 156 альтов D2PT 111 анонимны (71 %) (их рейтинговых игр не видно),
33 открытых не играли рейтинг >180 дней, а все 12 открытых с рейтингом за
180 дней уже в списке обхода и в хранилище. Добавлять в обход нечего.

**Цена всей пабной истории для ML Laning** (история против нуля, парный
бутстреп по дням, Δ = история − ноль, минус = история помогает):

| группа | n | охват слотов | ll3 ноль | ll3 история | Δ ll3 [95 % ДИ] |
|---|---:|---:|---:|---:|---|
| все | 28 707 | 0,461 | 0,65087 | 0,64936 | −0,0015 [−0,0027; −0,0003] |
| PRO_PRE | 23 741 | 0,445 | 0,65225 | 0,65046 | −0,0018 [−0,0031; −0,0005] |
| PRO_FWD1 | 4 275 | 0,522 | 0,64326 | 0,64203 | −0,0012 [−0,0049; +0,0028] |
| после 04.09 | 715 | 0,618 | 0,64557 | 0,65401 | +0,0084 [−0,0060; +0,0222] |
| охват <0,3 | 8 850 | 0,069 | 0,65392 | 0,65407 | +0,0002 [−0,0007; +0,0010] |
| охват 0,3–0,7 | 10 557 | 0,460 | 0,64901 | 0,65002 | +0,0010 [−0,0011; +0,0032] |
| охват ≥0,7 | 9 300 | 0,835 | 0,65009 | 0,64412 | −0,0060 [−0,0090; −0,0028] |

Прогноз до запуска был −0,003…−0,010 на всех картах; вышло −0,0015, то есть
история стоит ещё меньше прогноза. Помогает она только на картах, где история
есть почти у всех десяти (≥0,7); частичный охват не даёт ничего.

**Про-история не расщеплена:** на альтах D2PT лежит 214 из 287 070 про-слотов,
только у 2 из 106 игроков про-карты разнесены по двум аккаунтам.

## Контроль

- Сравнение парное: те же карты, та же модель, меняется только история — сдвиг
  состава карт исключён.
- Ложные связи проверяются данными: кластер с двумя аккаунтами в одном матче
  отбрасывается (`export_aliased.py`, selftest).
- Охват считается тем же путём, что сервинг (`LaningHistoryStore`, роль =
  позиция парсера, отсечка ts − 3 600 с); база 61,8 % совпадает с записанной
  в E-339 (61,7–61,8 %).

## Где искать ошибку

- D2PT неполон (857 профилей в очереди на момент замера; ростер даёт 169
  помеченных имён) — прирост охвата может немного вырасти, но 71 % найденных
  альтов анонимны, и это ограничивает любой источник id.
- Нулевая история как «нет связки» — верхняя граница: модель училась на пабах,
  где пропуск истории устроен иначе, чем на про-картах.
- 715 карт после 04.09 — широкий ДИ; знак +0,0084 (история вредит) не значим.
- Охват ≥0,7 — другие команды (топ-тир), поэтому Δ по корзинам нельзя
  переносить на карты с частичным охватом.
- Анонимность STRATZ скрывает список рейтинговых игр аккаунта, но не его id в
  чужих матчах: 441 из 842 анонимных про-аккаунтов всё равно есть в хранилище.

## Вывод

Связка смурфов из открытых источников (D2PT, ники STRATZ, поведение) ML Laning
не улучшит: охват +1,6 п.п. при цене всей истории −0,0015 ll3 даёт ожидаемый
эффект ≈ −0,0001, это ниже шума. Хранилище не пересобираем, сервинг не меняем.
Карта связей D2PT (`pro_alias_map_v2.json`) остаётся как данные — например,
для банов по игроку (альт обходит бан по account_id). На картах после 04.09
история не помогает ML Laning (n 715, не значимо) — перепроверка на большем
числе карт: idea-карточка ingame-i0y4.
