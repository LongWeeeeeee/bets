# E-363. Сколько Winline платит за окно килов 5–15

**Вопрос.** Лучшее живое правило — панельные килы 5–15 (kills_panel_window, w_5_15 ≥ 0,60): попадание 64,3 %
(n=196, E-359). Окупаемость не считалась: цен на окно не было, в расчётах стояло допущение 1,80
(`kills_window_odds18_policy_pick.md`). Владелец 08.10: на Winline окна есть во вкладке «быстрые»
(появляется и пропадает, на тир 2–3 может не быть), на BetBoom — в обычной вкладке матча.

**Снимок** (`runtime/artifacts/odds-winline/quick_tab_20261008/16890543_20261008T184904Z_quick.txt`, через прокси CA):

| рынок (3-я карта) | цены |
|---|---|
| исход 1X2 убийств в интервале 5–15 минут | LEGION 1,85 · ничья 7,63 · BLASTERBI 2,23 |
| фора убийств в интервале 5–15 минут | LEGION −0,5 1,85 · BLASTERBI +0,5 1,85 |
| чет/нечет убийств в интервале 5–15 минут | 1,85 · 1,85 |

Маржа: 1X2 ≈ 12 %, фора ≈ 8 %. Тир-3 матч FREEDOM FIGHTERS–MOONLIGHT WISPERS в те же минуты показал вкладки
«Все / Матч / 2 карта / 3 карта» без «Быстрые».

Безубыточная цена: 1/0,643 = 1,56 для −0,5 и 1/0,724 = 1,38 для +0,5.

**Механизм (гипотеза, не проверено).** Фора ±0,5 по 1,85/1,85 означает, что Winline оценивает окно как монетку.
Если так ставится большинство матчей, панель с попаданием 64 % выигрывает у рынка, который не моделирует окно.
Опровергнет: цены на окно, сдвинутые к нашей стороне (например, −0,5 по 1,45–1,55) на большинстве снятых матчей.

## Решение

Пока нет: цена — один снимок одного матча. +0,5 доступна, только если Winline даёт нашей стороне +0,5.
Сбор идёт: цикл на serv1 каждые 10 минут (`winline-quicktab-loop`, до 40 снимков «Быстрые»), разбор рынков
в строки — задача доставки winline-quick-windows-parser-20261008. Следующий шаг: связать снимки с боевыми
ставками kills_panel_window по матчу и карте и посчитать ROI по цене на момент ставки (карточка ingame-2hyy).

## Где искать ошибку

- Исход «ничья = проигрыш» взят из E-359; окно [5:00, 15:00) STRATZ по верным часам (E-362), а у Winline граница
  окна может считаться иначе (включительно/по таймеру) — сверить по правилам Winline.
