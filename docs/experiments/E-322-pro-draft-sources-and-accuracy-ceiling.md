# E-322. Цель +5 п.п. на про-картах: новые источники драфта и потолок точности

- **Дата:** 2026-09-23. Задача владельца: «Добейся лучших результатов +5% хотя бы… драфт это основа
  предсказания», затем «достигни поставленной цели и не останавливайся пока не достигнешь».
  Цель в числах: точность вне выборки ≥ 71,9 % на 1 720 pp-картах мая–сентября 2026
  (V2b 66,92 % + 5 п.п.). До этой записи лучшим было 68,84 % (LR ELO new3x_dur_ac + паб-драфт,
  [E-320](E-320-k24-elo-dynamics-on-pro-maps.md)).
- **Протокол у всех частей один:** помесячные фолды май–сентябрь, зазор 1 ч, из обучения
  вычищаются серии теста, бутстрап по сериям 1000×, seed 20260923. Гиперпараметры выбираются
  только на апреле.

## L-A. Метрики Dota2ProTracker (cp1vs1, duo) — ноль

- Источник: 117 страниц героев, скачанных 24–25.04.2026, то есть раньше любой тестовой карты.
  10 страниц переписаны 01.08 со старой встроенной датой и исключены. Сверка с `check_old_maps.py`
  на 50 картах совпала, включая знак стороны.
- Прогноз предрегистрации: AUC драфта 0,605, прибавка +0,5 п.п. **Не сбылся.**

| признак (pp) | n | AUC | точность | corr с ELO |
|---|---|---|---|---|
| cp1vs1 match-WR | 1 532 | 0,548 | 54,4 % | +0,04 |
| duo synergy match-WR | 1 391 | 0,555 | 54,3 % | +0,03 |
| LR по обоим | 1 720 | 0,546 | — | — |

Связка ELO + паб-драфт + протрекер: 68,37 % против 68,49 % у той же связки без протрекера.
Разница −0,12 п.п. [−0,94; +0,70], по log loss −0,0001 (интервал проходит через 0).
Сентябрьские лейн/соло-метрики с августовских страниц проверены только на 112 картах:
+1,79 п.п. [−2,54; +6,36], вывода нет.

## L-C. Драфт по про-лигам: герои, пары союзников, пары против — лучший результат, порог не пройден

- Модель: разреженная L2-логрегрессия. Признаки: знаковые индикаторы героев, пары союзников и
  антисимметричные пары противников. Обучение на лиговых картах `pro_corpus_rich` с 2025-01-01,
  вес затухает по времени. Для каждого месяца теста модель переобучается отдельно на картах,
  закончившихся раньше `начало месяца − 1 ч`.
- Итог: `new_logit = β·паб_логит + γ·лиговый_логит`.
- Выбор на апреле, pp n = 366, 144 кандидата: полураспад 180 дней, C 0,003, поддержка пары ≥ 30,
  β 0,5, γ 1,0.
- Прогноз предрегистрации: строгий порог, скорее всего, не пройдёт. **Сбылся.**

| pp, 1 720 карт | точность | AUC | log loss |
|---|---|---|---|
| паб-драфт отдельно | 56,22 % | 0,582 | 0,6861 |
| драфт по про-лигам отдельно | 57,56 % | 0,608 | 0,6748 |
| LR ELO, обучение на pp | 68,20 % | — | — |
| LR ELO + паб-драфт, обучение на pp | 68,49 % | 0,759 | 0,5814 |
| **LR ELO + драфт по про-лигам, обучение на pp (предрег.)** | **69,77 %** | 0,767 | 0,5753 |
| LR ELO + паб-драфт, обучение на всех лигах | 68,90 % | 0,760 | 0,5817 |
| LR ELO + драфт по про-лигам, обучение на всех лигах | 70,06 % | 0,768 | 0,5760 |

- Прибавка к ELO + паб-драфту (предрегистрация, обучение на pp): +1,28 п.п. [−0,06; 2,53],
  log loss −0,0061 [−0,0103; −0,0018]. На всех лигах: +1,16 п.п. [−0,23; 2,49], log loss
  −0,0057 [−0,0101; −0,0013].
- К ELO без драфта: +2,50 п.п. [0,95; 4,23].
- Корреляция логита нового драфта с ELO 0,113, у паб-драфта 0,090.
- Порог предрегистрации (AUC ≥ 0,62 или +1 п.п. с интервалом выше нуля) **не пройден**.
  Log loss улучшается значимо.
- Прибавка есть только на pp. На всех 20 210 тестовых картах: +0,00 п.п. [−0,41; 0,41].
- Независимая проверка (hard-verifier) по семи пунктам: утечки нет. Пересечение обучения и теста
  по match id, по сериям master и по source series id равно 0 во всех фолдах. Последняя обучающая
  карта кончается за 18–2 985 с до среза. Словарь пар строится только по обучающим картам фолда.
  Время прогона 219 с.

**L-E, сетка за краями L-C.** β 0,5, γ 1,0 и C 0,003 стояли на краях сетки, поэтому сетку
расширили: γ до 3,0, β до 0, C до 0,001, полураспад до 60 дней, поддержка пары до 10.
96 кандидатов, отдельная предрегистрация `grid_ext/PREREG.md`. Апрель снова выбрал ту же
конфигурацию: log loss 0,6752. Все расширенные значения хуже: γ 1,5 — 0,6764, γ 3,0 — 0,6842,
C 0,001 — 0,6764, β 0 — 0,6800, полураспад 60 — 0,6769. Прогноз «оптимум уйдёт за край»
**не сбылся**. В этом классе моделей драфт по про-лигам выжат.

## Потолок: сколько вообще можно угадать на pp

**Идея.** Карты 1 и 2 серии играют те же две команды, поэтому сила команд у них общая.
Пусть победители карт независимы при заданной силе s. Тогда доля серий, где одна команда берёт
обе первые карты, равна c = E[s² + (1−s)²]. Отсюда без всякой модели следуют две оценки для
прогноза, который знает только силу команд:
- верхняя граница по Йенсену, без предположений о распределении s: (1 + √(2c−1)) / 2;
- реалистичная оценка: сила имеет форму нашего ELO, растянутого до наблюдённого c.

| выборка | серий | c | граница по Йенсену (только сила) |
|---|---|---|---|
| pp, май–сент. 2026 | 667 | 0,612 [0,574; 0,648] | 73,6 % [69,3; 77,2] |
| pp, сент. 2025 – сент. 2026 | 2 787 | 0,596 [0,579; 0,614] | **71,9 % [69,8; 73,9]** |
| pp, 2024–2026 | 12 991 | 0,601 [0,593; 0,610] | 72,5 % [71,6; 73,4] |
| не pp, май–сент. 2026 | 1 948 | 0,604 [0,582; 0,626] | 72,8 % [70,2; 75,1] |

За последний год верхняя граница для прогноза, знающего только силу команд, равна ровно 71,9 %,
то есть самой цели.

На тестовых картах master (648 серий, c = 0,610 [0,571; 0,647]) видно:
- **Наш ELO уже знает почти всю силу.** С наклоном, откалиброванным на тесте, он даёт c = 0,598:
  это ~90 % дисперсии силы, общей для серии. Ожидаемая точность 68,2 %, фактическая 68,0 %,
  то есть ELO откалиброван.
- **Остатка от формы внутри серии нет.** Победитель прошлой карты выигрывает следующую ровно
  настолько, насколько говорит ELO (+0,006 / −0,009, E-320). Сторону на карте 2 проигравший
  карту 1 берёт radiant в 47,8 %, перекоса нет.
- **Ожидаемая точность** (калибровка на тесте, это диагностика, а не прогноз):

| сценарий | ожидаемая точность |
|---|---|
| сейчас: ELO + драфт по про-лигам | 69,4 % (факт 69,7 %) |
| идеальное знание силы, без драфта | 69,3 % [65,2; 72,9] |
| идеальное знание силы + драфт по про-лигам | **70,5 % [66,8; 73,7]** |

- **Какой драфт нужен для 71,9 %:** AUC на pp 0,684 при нынешнем ELO и 0,657 при идеальном знании
  силы. Сейчас лучший — 0,608. Проверка симуляции: при нынешних коэффициентах она даёт AUC 0,610
  против наблюдённых 0,608.

Вывод: при точечной оценке c цель требует драфта примерно вдвое сильнее в логит-шкале (×2,0),
чем лучший из измеренных. Все проверенные источники информации о конкретной карте дали ноль:
- протрекер (выше);
- опыт игрока на герое (E-89, E-169, E-175, E-309, E-314, E-315, E-317, E-214);
- порядок пиков и баны (E-160, ΔAUC −0,0000 [−0,0003; +0,0002]);
- состояние серии (E-320, −0,58 п.п.);
- котировка Winline (E-321, pp 0,0 п.п.).

## Итог по цели

- Путь от V2b 66,92 %: ELO new3x_dur_ac + паб-драфт 68,84 % (E-320) → ELO + драфт по про-лигам
  69,77 % по предрегистрации (70,06 % при обучении на всех лигах). Это **+2,85…+3,14 п.п.**
  вместо +5.
- Цель 71,9 % лежит выше ожидаемой точности даже при идеальном знании силы команд и лучшем
  драфте (70,5 %). Внутри доверительного интервала потолка она есть, но только у его верхнего края.
- Прод не менялся. Вопрос о связке ELO + драфт по про-лигам в v2 остаётся за владельцем:
  интеграция v2 в диспетчер на паузе.

## Где искать ошибку

- **Независимость карт серии.** Формула для c предполагает, что при заданной силе победители
  карт 1 и 2 независимы. Импульс внутри серии завысил бы c и потолок; по E-320 его нет.
  Преимущество проигравшего в выборе пика занизило бы c; по стороне перекоса нет (47,8 %),
  по первому пику не проверено.
- **Форма распределения силы.** «Реалистичный» потолок предполагает, что сила имеет форму ELO.
  Граница по Йенсену от формы не зависит: 73,6 % в тестовом окне, 71,9 % за год.
- **Калибровка на тесте.** В расчёте потолка наклон и коэффициент драфта подобраны на самих
  тестовых картах. Это диагностика разброса, не прогноз. Прогнозные числа — только из помесячных
  фолдов.
- **Повторное использование теста.** Май–сентябрь pp уже использовали E-319, E-320, E-321, L-A,
  L-C и L-E. Лучший результат склонен к «проклятию победителя». При 1 720 картах стандартная
  ошибка точности ~1,1 п.п. Чистая проверка — октябрьские карты, заранее.
- **Сравнение L-A.** Эталон L-A 68,49 % обучен после 26.04, чтобы сравнение было парным, поэтому
  он не равен 68,84 % из E-320. Оба числа воспроизведены.
- **Предупреждения в L-C.** В `run.log` L-C есть RuntimeWarning (переполнение в matmul).
  Выходы проверены на конечность, `n_iter` 18–21 < 150. Устойчивость решателя глубже не
  проверялась.
