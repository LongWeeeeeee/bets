# E-92. Отыграться нельзя научиться, дожимать — можно

- **Дата:** 2026-08-12 (продолжение E-89/E-91 по запросу alex «по порядку каждую»)
- **Харнесс:** `runtime/experiments/misc/ideas_batch3.py` (21 признак),
  `comeback_own_population.py` (замер на своей популяции)
- **Артефакты:** `runtime/artifacts/misc/ideas_batch3.md`,
  `comeback_own_population.md`, кэш `ideas_batch3.npz`

## 1. Предматчевый замер: ноль по всем семи группам

База — всё выжившее из E-88/E-89/E-91: **0.6968**.

| идея файла | признаков | к базе |
|---|---:|---:|
| 30. объекты (башни к 20-й, башни на единицу перевеса) | 2 | +0.0001 |
| 31. распределение ресурсов (доли нетворта по позициям) | 4 | +0.0001 |
| 28. тенденции команды (перевес на 10/15, первая башня, WR при лиде/отставании) | 6 | +0.0000 |
| 29. конвертация лида и камбек | 2 | +0.0000 |
| 34. синхронность таймингов | 1 | −0.0000 |
| 32. ресурсная совместимость драфта | 2 | −0.0002 |
| 33. кривые силы по длительности | 4 | −0.0005 |
| все вместе | 21 | **−0.0003** |

Бутстрап всей партии: 95% ДИ [−0.0017, +0.0011], за партию 31.4% пересборок.

**Это опровергает ставку первичного разбора.** Там траекторные профили команд
(идеи 28-29) стояли первым номером именно потому, что бьют в задачу «ловить
камбеки» и опираются на игровые показатели, которых в наборе нет. Данные на
диске были, признаки построены, вклад — ноль.

## 2. Почему ноль: замер на своей популяции

Правило 5 журнала: метрика меряется на своей популяции. «Вытащит ли отстающий»
имеет смысл только там, где кто-то отстаёт. Популяция — перевес >= 2000 по
нетворту на 15-й минуте; цель — победит ли ОТСТАЮЩАЯ сторона; база популяции
**20.3%** (16 312 карт проверки).

| предиктор | AUC | доля камбеков в верхней четверти |
|---|---|---|
| камбек-история отстающей команды | **0.5019** | 20.0% |
| конвертация лида у ведущей | **0.5508** | 24.8% |
| обе истории | 0.5552 | 24.4% |
| разница рейтингов | 0.6173 | 29.3% |
| размер отставания | **0.6740** | 32.0% |
| отставание + рейтинги + истории | **0.6986** | **34.6%** |

**Асимметрия — главное содержание записи.** Историческая способность команды
отыгрываться не предсказывает НИЧЕГО (0.5019, монетка). Историческая способность
ведущей команды дожать даёт 0.5508. То есть различаются команды по умению
закрывать выигранное, а не по умению вытаскивать проигранное. «Камбек-команда» —
это иллюзия наблюдателя: камбек делает не тот, кто умеет отыгрываться, а тот,
против кого не сумели дожать.

Обе истории при этом перекрыты: рейтинги дают 0.6173, а сам размер отставания —
0.6740. В связке 0.6986 и 34.6% камбеков в верхней четверти против базы 20.3%.

## 3. Где искать ошибку

- **порог 2000 на 15-й минуте не подбирался** — при другом пороге популяция
  другая, и асимметрия может измениться;
- **шринкедж историй** `(w + 3)/(n + 6)` не калиброван; у камбек-истории
  покрытие 52.4%, то есть у половины команд её просто нет;
- 34.6% в верхней четверти — это ВИНРЕЙТ, а не прибыль: цена отстающего на
  15-й минуте живая, и её у нас в архиве по этой популяции нет;
- одно тестовое окно; кластерный бутстрап по сериям не делался;
- признаки предматчевые, но популяция определяется состоянием на 15-й минуте —
  это не предматчевый продукт, а живой; для прода потребуется тот же расчёт в
  реальном времени.
