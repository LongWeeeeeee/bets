# E-76. Мы весь день оптимизировали не ту величину

- **Дата:** 2026-08-12

## 1. Откуда взялись цены

`runtime/winline_odds_history.jsonl` (serv1) пишет движение линии с 09.08:
7 360 записей, 90 матчей, 80 с обеими ценами. Ключ `canonical_key` содержит id
обеих команд и лиги, поэтому джойн с про-корпусом механический.

| | медиана | p10 | p90 |
|---|---|---|---|
| фаворит | **1.52** | 1.33 | 1.72 |
| андердог | **2.35** | 2.00 | 2.90 |

Маржа букмекера — 8.3%.

## 2. Прибыль по сторонам

Прод-отбор (звёзды + вето ML-модели), сторона «фаворит/андердог» определена по
про-ELO составов:

| блок | ставок | винрейт | ROI | на фаворита | на андердога |
|---|---:|---|---|---|---|
| early_nw | 1 539 | 68.7% | **+27.3%** | 824 / 77.1% / +17.1% | 715 / 59.2% / **+39.0%** |
| early_win | 954 | 64.0% | +16.6% | 521 / 74.9% / +13.8% | 433 / 51.0% / +19.9% |
| late | 1 447 | 59.6% | +12.2% | 737 / 66.1% / **+0.4%** | 710 / 53.0% / +24.5% |
| post_lane | 1 549 | 57.5% | +7.7% | 769 / 66.7% / **+1.4%** | 780 / 48.5% / +13.9% |
| **портфель** | **5 489** | 62.3% | **+15.9%** | | |

**В late и post_lane фаворитская половина зарабатывает ноль.** 66% побед по цене
1.52 дают +0.4% и +1.4% — на уровне шума и комиссии. При этом те же блоки на
андердогах дают +24.5% и +13.9% при винрейте ниже 53%.

Зависимость сквозная: чем выше винрейт группы, тем ниже её доходность, потому
что цена фаворита падает быстрее, чем растёт вероятность.

## 3. Почему «выкинуть фаворитов» — неверный вывод

Если убрать фаворитские ставки в late и post_lane:

| | ставок | ROI на ставку | суммарная прибыль |
|---|---:|---|---|
| как есть | 5 489 | +15.9% | 873 ед. |
| без фаворитов в late/post_lane | 3 983 | **+21.6%** | 860 ед. |

Доходность на ставку выросла на треть, **суммарная прибыль не изменилась**:
отрезана треть объёма, которая зарабатывала мало, но зарабатывала. Решение
зависит от того, что является узким местом — капитал или количество матчей.
При ограниченном капитале резать правильно, при ограниченном потоке — нет.

## 4. Что из этого следует для прежних решений

- **вето по силе команд (E-75) отклонено верно**: оно вырезает андердогов, то
  есть единственный прибыльный сегмент в late и post_lane;
- **`ml_win` звёздной метрикой** выглядит хорошо и по этой шкале: добавленные
  карты дают +16.5% ROI на фаворитах и +28.7% на андердогах против +0.8% и
  +14.1% у текущего отбора — прибавка по обеим половинам, а не размен;
- общий принцип на будущее: **правку оценивать по ставка × цена, а не по доле
  выигранных**. Всё, что поднимает винрейт за счёт смещения к фаворитам,
  экономически нейтрально или вредно.

## 5. Чего этот замер НЕ доказывает

- цены медианные, не по каждой карте: фаворит на нижнем краю (1.33) при 66%
  побед даёт **−12% ROI**, то есть внутри фаворитской половины почти наверняка
  есть убыточный кусок, и его надо искать отдельно;
- сторона определена по про-ELO, а не по реальной линии букмекера — они
  коррелируют, но не совпадают;
- 80 матчей с ценами — мало для распределения; для точного расчёта нужен джойн
  по каждой карте, а он появится по мере накопления `winline_odds_history`.
