# E-353. Ставка на ELO-андердога после перевеса по нетворсу

- **Идея владельца (06.10.2026).** С 03.10 WIN-ставка на ELO-андердога (дефицит ≥ 50) режется
  `win_against_elo_blocked` (E-351). Предложение: отправлять её, если андердог к минуте m набрал
  перевес по нетворсу ≥ X. Пример: Cloud Dawning – Yangon Galacticos, карта 2 (06.10): ΔELO −263,
  четыре драфт-★ за CD, перевес +1 111 на 05:19, +3 744 на 10:00. Карта выиграна CD.
- **Что решает замер.** Ставку продаёт букмекер, а он видит тот же нетворс. Поэтому вопрос не «как
  часто выигрывает андердог с перевесом», а «выше ли эта частота, чем вероятность в цене Winline в
  ту же минуту».
- **Прогноз до прогона** (`.omc/decisions.md`, 06.10 14:35): андердог с ★ на 10-й при +2 тыс. —
  60–65 %, при +4 тыс. — 72–78 %; Winline к этому моменту уже сдвинет цену; ROI ±10 % с ДИ через
  ноль. Итог: частоты подтвердились (66,7 % / 74,9 %), ROI оказался хуже прогноза (−20…−30 %).

## Определения

- U — сторона с меньшим ELO (в живом журнале `elo_r`/`elo_d` тика, вариант A с 25.09), d — дефицит в
  очках. C0: d ≥ 50. C1: диспетчер хотел WIN-ставку на U (решение или `win_against_elo_blocked`).
  C2: хотя бы одна драфт-модель (All / Late / Early Win / Early NW) даёт U ≥ 0,60. В подсчётах ниже
  C1 и C2 всегда пересечены с C0.
- lead_U(m) — `radiantNetworthLeads[m]` STRATZ, повёрнутый к U; карта должна идти дольше m минут.
- Цена в минуту m, t = гудок + 60·m (гудок = ts − game_time журнала): Q1 — последняя открытая
  котировка после гудка, возраст ≤ 120 с, без закрытия рынка до t; Q3 — первая котировка в (t, t+180]
  (консервативная проверка против устаревших котировок).
- ДИ ROI — бутстрап 2 000 по сериям (`corpus_series_id`; base_url у DLTV свой у каждой карты).

## 2. Живые цены Winline: ставка на ведущего андердога убыточна

Покрытие: 472 карты в журнале, исход + NW у 350, цена Q1 на 4-й минуте у 263, на 10-й у 226, на
15-й у 206 (после исправления фильтра рынков).

Правило владельца, одна ставка на карту — первая минута из {5, 6, 7, 8, 10, 12, 15}, где
lead_U ≥ k·m, цена Q1 этой минуты (Q3 — в скобках):

| когорта | k = 200 | k = 300 |
|---|---|---|
| C0 | 15/31, кэф 1,72, ROI −25,3 % [−55; +7] (Q3 −28,5 %) | 5/9, 1,44, −28,8 % |
| C1 | 5/11, 1,85, −24,6 % [−79; +39] | 1/3 |
| C2 | 11/23, 1,77, −22,3 % [−57; +17] (Q3 −25,9 %) | 5/8, 1,41, −19,9 % [−69; +20] |

Калибровка Winline на строках U (d ≥ 50, Q1, 1 526 строк): средняя вероятность в цене 0,350,
частота побед 0,280 (строки минут одной карты пулированы, ДИ — по сериям). В корзинах, где рынок уже считает андердога фаворитом (0,5–0,6), U выигрывает 34,8 %
(5–8′, 89 строк / 45 карт) и 37,3 % (10–15′, 51 / 34). Коэффициент при перевесе сверх цены ≈ 0
(5–8′: −0,138 [−0,494; +0,218] на 1 000 золота; 10–15′: −0,004 [−0,214; +0,207]) — перевес рынок
учитывает полностью, а ★ за андердога рынок не недооценивает (+0,175 [−0,52; +0,87]).

Модель из части 1 против рынка на тех же строках: LL модели хуже на +0,010 [−0,027; +0,047]
(1 526 строк, 203 карты); до 25.09 (ELO K24 и в бою) +0,016, после −0,004 — дело не в варианте ELO. Правило «p_model × цена ≥ 1,05», первая минута, одна ставка на карту:
C0 21/83, ROI −11,2 % [−49; +30]; C1 13/37, +8,9 % [−38; +62]; C2 13/54, −25,4 % [−61; +13].
Команда сведения выводит все ячейки; ни одна не даёт ДИ выше нуля.
Ни одна ячейка не даёт ROI с ДИ выше нуля.

**Механизм.** Winline в игре переоценивает ELO-андердога: рынок двигает цену за ранним перевесом
сильнее, чем перевес меняет исход между командами разной силы. Наш перевес-сигнал — то же, что
видит рынок, а ELO (наше преимущество над рынком, E-351: ставки с ELO +16…+20 %) снятие запрета
выбрасывает.

## 3. Зеркало: отстающий на 4–8′ ELO-фаворит

Подмножество тех же строк (C0, Q1), где перевес у андердога, но ставка — на ELO-фаворита по его
цене. Посчитано после того, как увидены данные, поэтому это гипотеза, а не доказанное преимущество.

По минутам (строки одной карты на разных минутах зависимы — 62 из 101 карты повторяются):
4-я 54/76, частота 0,711 при заложенной Winline 0,581, ROI +15,8 % [−2; +33]; 5-я 36/56, 0,643 при
0,551, +10,7 %; 8-я 34/53, 0,642 при 0,513, +14,0 %; на 10-й разрыв закрывается (−1,8 %), на 15-й
+8,0 % [−21; +41]. Все ДИ через ноль.

Одна ставка на карту, первая минута 4–8, где фаворит отстаёт:

| условие | все | до 25.09 | с 25.09 |
|---|---|---|---|
| отстаёт > 0 | 73/109, 1,66, +7,8 % [−6; +23] | 53/77, +12,8 % | 20/32, −4,1 % [−31; +23] |
| отстаёт ≥ 500 | 40/57, 1,83, +21,7 % [+0,4; +44,5] | 28/39, +25,6 % | 12/18, +13,2 % [−26; +54] |
| отстаёт ≥ 1 000 | 21/32, 2,03, +17,8 % [−13; +54] | 13/19, +26,1 % | 8/13, +5,7 % |

Без фильтра d ≥ 50 — +3,5 % / +9,9 % / −8,7 % (n 160 / 93 / 59). Механизм тот же, что в части 2, с другой стороны:
рынок переоценивает ранний перевес относительно силы команд, а ELO (наше преимущество) говорит
обратное. Риски: порог 500 выбран по данным; основная прибыль — до 25.09 (смена ELO на вариант A
и каталога all7m 24.09); гудок восстановлен по 3–6 тикам на карту.

**Предрегистрация проверки (06.10.2026, до новых данных):** правило «ELO-фаворит (d ≥ 50) отстаёт
на ≥ 500 золота в первую минуту из 4–8, ставка по Q1-цене фаворита этой минуты, одна на карту».
Проверка — только карты с первым тиком после 06.10 14:32 MSK, n ≥ 40 (ожидаемо ~23.10 при ~2,4 карты
в сутки). Успех — ROI ≥ 0 и при Q1, и при Q3. Неудача — ROI < 0 хотя бы при одном правиле цены.
Запуск: свежие копии serv1 в `inputs/` нового каталога, `live/run.py` с этим каталогом, отбор по
`first_ts`.

## 4. Ставка на 5-й минуте при +1 000 (уточнение владельца, 06.10)

Владелец поставил на CD на 5-й минуте при перевесе ~1 000 по кэфу ~1,9. Котировки Winline этой
карты (`winline_odds_history.jsonl`, копия 06.10 14:32; гудок 14:04:19): до гудка CD 2,7 при YG 1,37
(без маржи 0,34) → 2,3 на 3:37 → на 4:43–5:35 скачет 2,3 / 1,85 / 2,3 / 2,02 → 1,9 при YG 1,8 на 6:57 →
1,40 на 10:00. К 5-й минуте рынок уже сдвинул CD с 0,34 до 0,40–0,50. Безубыточность при 1,90 —
52,6 %, при 2,30 — 43,5 %.

- **Модель части 1** (5-я, +1 000, ELO −263, вердикты этой карты): P(CD) = 0,43. При 1,90 это
  −19 %, при 2,30 — около −1 %; безубыточный кэф — 2,34. Четыре ★ модель почти не добавляет: при All в модели Late,
  Early Win и Early NW имеют отрицательные коэффициенты.
- **Офлайн pp, d ≥ 50, перевес ≥ 1 000 на 5-й** (★ не требуется): 2026 H1 — 27/51 (52,9 %);
  июль–сентябрь — 17/35 (48,6 %). Лиговые карты: 57,5 % / 52,5 %. С ★ на лиговых картах — 61,6 %
  (часть 1). Но медианный дефицит в этой ячейке 94 (у CD 263, d ≥ 200 — только 7 % ячейки), а уровень
  ниже про.
- **Живые карты, d ≥ 50** (исход есть у всех): перевес ≥ 1 000 на 5-й — 4/12, на 7-й — 9/26,
  на 10-й — 19/39. С ценой Q1 на 5-й — 1/8 при среднем кэфе 1,90. Последовательно (первая минута
  4–7 с ≥ 1 000, одна ставка на карту): C0 7/26 по 2,14, ROI −45 % [−82; −3]; C2 5/16 по 2,02,
  −27 % [−79; +36].

Вывод: на 5-й минуте рынок отдаёт андердогу с +1 000 около 50 %. Наши данные дают столько же или
меньше. Выигрыш CD — один исход, а не довод.

## Решение

- Запрет `win_against_elo_blocked` (E-351) остаётся без исключения по нетворсу. Код не менялся.
- Даже если бы правило окупалось, текущий пол по кэфу (`1/(expected_wr − 0,12)` от драфт-вероятности)
  отрезал бы такие ставки: к минуте перевеса цена падает (в примере CD — 1,40 при поле ≈ 1,85).
  Освобождённой ставке понадобился бы свой пол по поминутной вероятности.
- Зеркальная гипотеза ждёт проспективной проверки ~23.10 (карточка `ingame-45eg`). Ставок не
  включает. Решение о новой ставке — за владельцем и только после неё.
- Найдено независимой проверкой и исправлено до записи (`live/run.py`): в цены попадали рынки
  «дуэль игроков, убийства» с теми же именами (42 строки Q1, 16 карт); статусы `missing`/`error`
  между котировкой и моментом не считались закрытием (160 строк); бутстрап живого узла шёл по карте,
  а не по серии. После исправления заголовочные числа те же (11/23, −22,3 %).

## Где искать ошибку

- Офлайн ELO (K24) есть только у карт длительностью ≥ 20 мин (master): ранние таблицы условны на
  этой выборке; живое ELO — вариант A с 25.09, модель учена на K24.
- Цена — архивная котировка, а не исполненная ставка; Q1 требует возраст ≤ 120 с, Q3 — первая после
  момента. Закрытие рынка учтено по журналу, приостановка внутри открытого статуса — нет.
- 122 карты журнала без NW (STRATZ теряет ~21 % про-карт), 54 карты без совпадения имён Winline.
- Строки разных минут одной карты зависимы; ROI по минутам — не независимые проверки. Сетка ячеек
  не поправлена на множественность.
- Выравнивание минут: знак NW STRATZ и журнала минутной модели совпал 46/46 при |NW| ≥ 1 500.
