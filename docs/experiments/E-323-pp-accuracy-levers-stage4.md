# E-323. Цель 71,9 % на pp, этап 4

- **Дата:** 2026-09-23. После [E-322](E-322-pro-draft-sources-and-accuracy-ceiling.md) владелец
  написал: «продолжи работу считай что цель достижима».
- **Цель:** ≥ 71,9 % вне выборки на 1 720 pp-картах мая–сентября.
- **Исходная точка — связка E-322** (LR ELO `new3x_dur_ac` + драфт по про-лигам): 69,77 % при
  обучении на pp и 70,06 % при обучении на всех лигах.
- **Протокол у всех частей:** помесячные фолды, связка учится на строках с апреля, закончившихся
  до `начало месяца − 1 ч`, серии теста вычищены; бутстрап по сериям 1000×, seed 20260923.
  Везде стоит assert, что эталон воспроизводится.
- **Отбор:** где был выбор, он делался на апреле или на не-pp картах. Pp-тест запускался один раз.

## Где связка теряет (разбор ошибок)

| срез pp-теста | карт | точность | ожидаемая (по уверенности) |
|---|---|---|---|
| у всех 10 игроков ≥ 349 прошлых игр (верхние 60 %) | ~1 030 | 65–67 % | 64,5–66,0 % |
| есть игроки с меньшим опытом | ~690 | 73–78 % | 69–72 % |
| карта 1 / 2 / 3 серии | 852 / 648 / 220 | 71,7 / 67,9 / 67,7 % | 67,6 / 67,8 / 63,2 % |

Согласованность серий по срезам: доля серий, где одна команда взяла обе первые карты (c), против
того же, что предсказывает связка (c_hat).
- **Опытные карты:** c 0,582 [0,534; 0,627] против 0,570; граница по Йенсену 70,2 %.
- **Карты с новичками:** c 0,653 [0,594; 0,713] против 0,613; граница 77,7 % [71,6; 82,6].

Недоучтённая сила сидит на картах с менее опытными игроками.

- **Веса ELO и драфта** подобраны по месяцам: отношение 0,76–0,91. Даже вес, подобранный прямо
  на тесте, даёт максимум 70,0 %. Не рычаг.

## Рычаги

| **L-H** | **отрыв прошлой карты серии по нетворсу на 20-й мин., ориентированный к нынешней Radiant** | **+0,76 [0,06; 1,44] → 70,52 %** | −0,0005 (NS) | **принят** |
| L-K | отбор признаков прошлой карты на не-pp (10/20/30 мин., скорость разгрома, убийства) | выбран только pm20 | — | подтверждает L-H |

Подробности по рычагам:
- **L-H проверен вне pp.** На 18 490 не-pp картах log loss −0,00077 [−0,00125; −0,00026],
  точность +0,10 п.п. [−0,10; 0,28]. На всех лигах log loss −0,00078, значимо. Сигнал настоящий,
  но в точности маленький. Прибавка +0,76 на pp, скорее всего, завышена отбором: честная оценка
  +0,2…+0,4 п.п. При обучении связки на всех лигах: 70,23 % (+0,17 [−0,65; 0,99]).
- **Исход прошлой карты без отрыва** по-прежнему ничего не добавляет (как в E-320).
- **L-I.** Корреляция командного ELO с рейтингом игроков всего 0,543. Id организаций переживают
  смену составов, и рейтинг несёт старую силу.
- **L-J.** Ориентация данных проверена: на самой карте разница IMP угадывает победителя с AUC 0,876.
- **L-N.** AUC ELO на pp 0,7523 → 0,7573, на картах с новичками 0,8118 → 0,8198.
- **L-F.** Отдельно AUC 0,694, корреляция с ELO 0,756.
- **L-M.** Позиция по рангу нетворса за последние 20 карт совпадает с фактической у 58,6 % игроков
  (26,2 % для всей стороны). Апрель оставил блок ролей с перевесом 0,00003 по log loss.

Прогнозы, записанные до прогонов:
- L-H (+0,2…+0,8) — сбылся;
- L-N — сбылся по AUC (+0,002…+0,006), не сбылся по точности;
- L-G, L-I, L-J, L-F (+0,2…+1,0) — не сбылись;
- L-L (0…+0,3) — сбылся на нижней границе: ноль;
- L-M — не сбылся.

## Итог этапа

- Лучшая точность на pp: **70,52 %**. Это [ELO `new3x_dur_ac`, драфт по про-лигам, pm20] при
  обучении связки на pp; 70,23 % при обучении на всех лигах.
- К V2b (66,92 %) это +3,6 п.п., до цели 71,9 % не хватает 1,4 п.п.
- Три рычага (драфт по про-лигам, pm20, старт новичков) значимо улучшают вероятности, но двигают
  точность в пределах ±0,8 п.п. Стандартная ошибка точности на 1 720 картах ~1,1 п.п.
- Гипотеза (не проверено): для 71,9 % стеку нужен AUC ~0,79 (сейчас 0,768). Ни один
  проверенный источник силы или драфта столько не добавляет: всё, что знает о силе, коррелирует
  с ELO на 0,75+.

## Где искать ошибку

- **Повторное использование pp-теста.** Май–сентябрь pp используется уже в E-319…E-323. Лучшая
  связка (L-H) выбрана из многих сравнений. Отбор на не-pp снижает риск, но октябрьская
  проспективная проверка (E-322, карточка ingame-uoao) должна включить pm20.
- **Ориентация pm20.** Прошлая карта засчитывается только при том же наборе двух команд и
  `end_prev < ts`. Команда берётся из `pro_corpus_rich.teams`, где `teams[:,0]` — Radiant
  (совпадение `wins` с master на 26 980 картах, E-321).
- **`nw[:,T]` — отрыв Radiant по нетворсу на минуте T.** Знак на 20-й минуте совпадает с
  победителем в 75,4 % карт. Для коротких карт колонка держит последнее значение.
- **Грубые метки позиций в L-M** (58,6 %) — отрицательный результат не исключает позиции при
  хорошей разметке.
- **Код формата серии в `stypes`** — это N из best-of-N (1/2/3/5), а не enum OpenDota: первый
  прогон L-L ошибся в кодах и был перезапущен.
