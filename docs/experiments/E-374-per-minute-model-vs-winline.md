# E-374. Поминутная модель против цены Winline

Карточка ingame-5mgd. Повод — владелец 10.10: «либо нужна поминутная модель» (после E-372, где стадийные гейты ставок на андердога сработали по проценту побед, но не в деньгах).

## Вопрос

Важно не «предсказывает ли поминутная модель победу» (предсказывает: E-347), а «знает ли она что-то сверх цены Winline в ту же минуту». Только это даёт деньги.

## Прогноз и правило решения (записаны до прогонов, `.omc/decisions.md` 10.10)

- **Прогноз.** Прирост log loss против рынка (Q1) в пределах −0,01…+0,01, ДИ через ноль; ставки на расхождение ≥0,05 — ROI в пределах ±10 %.
- **Правило.** Поминутную модель для ставок строим (сначала тенью), только если одновременно:
  - сводный OOT-прирост log loss против рынка по Q1 > 0 и ДИ не задевает ноль;
  - ROI ставок на расхождение ≥0,05 > 0 и по Q1, и по Q3.

## Исходы (M3)

Исходов не было у 72 из 136 карт M2 и у 78 из 544 карт M1. Это были в основном 06–10.10: снимки исходов заморожены 06–08.10, а ночная перебазировка ELO с 03.10 закрывает карты без `radiant_win`.

OpenDota `proMatches` + `teams/<id>/matches` закрыл 46 карт. Сопоставление: пара team_id, окно времени [start − 10 мин; start + duration + 25 мин], без нечёткого сравнения имён. Контроль на уже известных картах: совпало 232, расхождений 0. Осталось без исхода 28 карт M2 и 32 карты M1 (тир-3 вне OpenDota pro).

Песочница Codex сеть не видит (DNS), поэтому сбор шёл локально. urllib получил Cloudflare 1010 — блок подписи Python-urllib, не квота. Помог браузерный UA, как в `base/opendota_research.py`.

## Контроль без модели: фаворит и андердог по живой цене

Чтобы отделить модель от простого перекоса цен, на той же выборке M4 (первый тик с ценой на карту) ставили без модели:

| ставка | Q1: n, побед, ср. кэф, ROI [ДИ] | Q3 |
|---|---|---|
| ELO-андердог (ΔELO ≤ −50) | 249, 70, 3,37, **−32,5 % [−46; −18]** | 271, −33,2 % [−45; −20] |
| — андердог впереди по NW на тике | 129, 55, 2,23, −17,3 % [−34; +0,6] | 146, −20,2 % [−36; −3,5] |
| — андердог позади | 189, 36, 4,04, −40,6 % [−58; −22] | 255, −36,5 % [−50; −24] |
| ELO-фаворит (ΔELO ≥ 50) | 249, 179, 1,60, +3,6 % [−4,4; +12] | 271, +3,9 % [−4; +11] |
| фаворит рынка | 333, 233, 1,39, −5,7 % [−12; +1,7] | 376, −11,2 % |
| андердог рынка | 333, 100, 3,43, −17,8 % [−31; −4] | 376, −12,9 % |

**Механизм.** По живой цене Winline ELO-андердогу без маржи положено 35,7 %, а выигрывает он 28,1 %. Модель M4 даёт ему 32,0 % — ближе к правде, но тоже выше. При перевесе андердога (кэф < 2) он выигрывает 45,9 % при цене 59,3 %. Рынок переоценивает ранний перевес слабой команды и недооценивает силу (ELO). Отсюда и у M4 модельные ставки на андердога в минусе (δ ≥ 0,05: Q1 −35,9 % [−61; −8], n 80), а на фаворита — в плюсе (δ ≥ 0,08: Q1 +18,8 % [+3; +37], n 115; Q3 +13,2 % [−0,0; +26,8], n 155). Фаворитный срез выбран после взгляда на данные (16 групп × 2 цены), поэтому это идея на проверку, а не результат.

## Решение

- **Поминутную модель для ставок не строим.** Правило не выполнено ни в одном узле: сводный прирост против рынка ≤ 0 везде, ROI δ 0,05 по Q3 отрицательный.
- **E-347 в бою остаётся строкой** (служебный бот + `runtime/ml_minute_shadow.jsonl`). Она не мешает и копит данные.
- **Идея ingame-cccu** (пересчёт ~10.11): ставка на ELO-фаворита, когда поминутная модель выше рынка на ≥0,08. Заморозить `perminute_v1.json` и посчитать на тиках после 10.10.
- **Ставки на ELO-андердога: гейт «трио ≥ 0,60»** (решение 10.10 после второго дополнения ниже). Полный запрет не возвращаем. WIN на андердога уходит, только если Early Win, Early NW и All каждая за него с уверенностью ≥ 0,60 (`ML_DISPATCH_WIN_UNDERDOG_TRIO_MIN`, откат `=0`). Без такой поддержки ставки самого диспетчера на андердога: 50 карт, 32 % побед, ROI −47 % [−76; −12] (Q3, n 26). С ней — 30 карт, 43 %, +48 % [−27; +129] (n 18). Перепроверка — ingame-vmwo и ingame-3e0e (~17.10).

## Дополнение 10.10: правило владельца «трио + перевес по NW»

Владелец: «если обе early + all за андердогом или все тоже + late и они ведут по нетворсу ещё, то это полюбому плюсовые ставки». Проверено на тех же тиках M4 (журнал 12.09–10.10, все эры): ELO-андердог (ΔELO ≤ −50), первый тик карты, где условие выполнено, цена Winline на этом тике.

| условие на тике | поддержка = сторона модели (P > 0,5) | поддержка = ★ (P ≥ 0,60) |
|---|---|---|
| Early Win + Early NW + All за андердога | 77, 32 %, 3,01, Q1 −23,7 % [−48; +4] | 31, 39 %, 3,25, Q1 +11,8 % [−42; +69] |
| + андердог впереди по NW | 45, 44 %, 2,11, Q1 −18,2 % [−46; +9] | **17, 47 %, 2,22, Q1 +8,4 % [−48; +70]** |
| + Late за андердога | 48, 29 %, 3,04, Q1 −26,5 % [−59; +8] | 12, 42 %, 3,34, Q1 −0,1 % |
| + Late + впереди по NW | 29, 38 %, 2,17, Q1 −28,6 % [−60; +5] | 7, 57 %, 1,97, Q1 +23,9 % [−57; +112] |

Клетка = карт, процент побед, средний кэф, ROI. Q3 даёт те же знаки: ★ + NW +5,8 % n 17, сторона + NW −18,4 % n 47. В эре all7m ★ + NW — 9 карт, 5 побед, Q1 +11,1 % [−62; +79].

**Вывод.** «Полюбому плюс» данными не подтверждается:

- при простой поддержке трёх моделей (каждая > 0,5) это минус −18…−29 %;
- при ★ у каждой из трёх точечно плюс, но n 7–31 и ДИ шириной ~120 п.п.

Механизм тот же, что в контроле: перевес по NW Winline уже заложил в цену. Андердог впереди стоит 2,1–2,2, то есть безубыточность ~46 %. Голоса 0,5–0,6 к этой цене ничего не добавляют.

**Как фильтр к нынешним ставкам правило неприменимо.** Диспетчер ставит на андердога на 0–5′ (28 из 37 карт) или на 31′+ (9). На тике ставки «★ трио + впереди по NW» не выполнялось ни разу (0 из 37), потому что на 00 перевеса ещё нет. Значит, такой гейт равен полному запрету, а не узкому. Рабочая форма — отдельный отложенный вход: ждать, пока андердог с ★ трио выйдет вперёд по NW. Среди карт диспетчера таких 5 (3 победы, Q3 +11,5 % n 4). Это идея к ingame-mfir: пересчёт при ≥ 40 картах с ценой Q1. Сейчас их 17, в эре all7m прибавляется ~0,56 карты в сутки, то есть ~начало декабря.

**Прогноз, записанный перед проходом по ставкам диспетчера, не сбылся.** Ожидалось: внутри правила −10…+25 %, снаружи ≤ −20 %. Вышло: внутри 0 карт, снаружи Q3 −2,2 % (n 20).

## Дополнение 10.10 (2): пороги 0,65/0,70, ELO и отдельная модель

Владелец: «возможно также нужны для андердога не ≥ 0,6, а 0,65–0,7, или динамически в зависимости от ELO diff; возможно, отдельная ML-модель». Вместо перебора порогов на 17 картах проверено, как результат зависит от поддержки: min(Early Win, Early NW, All за андердога), все ELO-андердоги с ценой, первый тик карты.

**Сама поддержка рынком не учтена.** Цена Winline одинакова во всех корзинах: андердогу положено 34–36 % побед. Выигрывает он по-разному:

| min трио | живое: n, побед, ROI Q1 | офлайн: n, побед (P по ELO) |
|---|---|---|
| < 0,55 | 205, 27 %, −38 % [−52; −23] | 11 866, 25,8–37,0 % (33–34 %) |
| 0,55–0,60 | 14, 21 %, −50 % | 1 219, 42,9 % (33,8 %) |
| 0,60–0,65 | 18, 39 %, +17 % [−49; +95] | 728, 47,0 % (34,3 %) |
| 0,65–0,70 | 8, 38 %, +27 % | 396, 51,0 % (33,5 %) |
| ≥ 0,70 | 4, 50 %, −15 % | 193, 56,0 % (34,3 %) |

Офлайн — корпус phase_state_20261002, 14 402 карты андердога до 21.09. Драфт-модели на нём вне выборки по match_id, но не по времени: они видели мету тех же месяцев, поэтому уровень завышен.

**Ставки самого диспетчера на андердога** (обе эры, первый тик решения):

| трио | правило | карт, побед | ROI Q3 [ДИ] |
|---|---|---|---|
| < 0,60 | все | 50, 32 % | −47 % [−76; −12], n 26 (Q1 n 5: −78 %) |
| < 0,60 | 0–5′ (`now`) | 26, 31 % | −41 % [−78; +4], n 19 |
| < 0,60 | `win_late_after_wait` | 24, 33 % | −65 % [−100; −26], n 7 |
| ≥ 0,60 | все (только `now`) | 30, 43 % | +48 % [−27; +129], n 18 |

**Вывод по идеям владельца:**

- **0,65 / 0,70.** Офлайн процент побед растёт монотонно: 47 → 51 → 56 %. Но уже корзина 0,60–0,65 выше безубыточности: при медианном кэфе ~2,7 нужно ~37 %, а вживую в ней 7 побед из 18 при цене 36 %. Порог 0,65 срезал бы половину оставшихся ставок (медиана поддержки у ставок диспетчера — 0,626) без измеренной пользы. Берём 0,60.
- **Динамический порог по ELO.** Офлайн трио добавляет к вероятности по ELO одинаково при любой разнице: +15, +17 и +13 п.п. при 50–150, 150–300 и ≥ 300. Довода за динамику нет. Риск один: при ΔELO ≥ 300 даже с трио побед 24 % (n 46), безубыточность там от кэфа 4,2. Вживую таких ставок единицы.
- **Отдельная модель.** Линейная зависимость в логит-шкале поверх цены рынка ≈ 0: +0,06 [−0,41; +0,55] (n 249). Зависимость ступенчатая, и гейт — её однопараметрическая форма. Модели с 4–5 признаками нужно ≥ 600 карт с ценой, сейчас 249 (~9 в сутки). Идея записана в ingame-clgo (пересмотр ~18.11).
- **Правило решения E-372 выполнено** для вето «трио < 0,60»: снимаемые ставки в минусе по Q1 (−78 %, n 5) и по Q3 (−47 %, n 26); офлайн 31,9 % (n 13 085) ниже безубыточных 43,7 % при медианном кэфе Q3 2,29. Гейт найден после взгляда на данные (порог 0,60 взят из правила владельца), поэтому через неделю нужен перезамер на свежих ставках.
- **Механизм.** Winline в игре не учитывает драфт-голоса. Без поддержки андердог переоценён: цена даёт 36 %, вживую он выигрывает 27 %. E-347 мерил «★ против ELO» на одной модели (ROI −46 %), здесь нужна поддержка всех трёх.

## Где искать ошибку

- **Ориентация цен.** Все тики — в ориентации Radiant (`side`=radiant у 3 498 из 3 498). `implied_no_vig` = (1/p)/(1/p + 1/q) сверен на 1 431 котировке из 1 431. Q3 берёт будущую котировку (до 180 с) — это стресс-проверка, не исполнимая цена.
- **Исходы.** Ключи леджера — на карту (`<url>.0`, 177 ссылок, ни у одной двух карт). Исход карты 1 в карты 2–3 не протекает. Расхождений между источниками 0. OpenDota-исходы — `outcomes/outcomes_extra.jsonl` и `outcomes/control.json`.
- **Признаки M4.** В журнале нет киллов: основная модель без них, киллы только из корпуса. «All» в журнале статичный из драфта. 307 тиков без NW исключены. Драфт-логиты корпуса до 21.09 in-sample для all7m — как в боевом рецепте.
- **Первый тик на карту.** Журнал пишет тик, когда диспетчер решает. Это не случайная минута, а момент оценки, чаще всего 10–15′ и 0–5′.
- **Многократность.** M4 — 16 групп × 2 цены × 4 δ; контроль — 4 базовых ставки × окна. ДИ поточечные. Фаворитный срез — после взгляда на данные.
- **Бутстрап M4 на v2** выдал предупреждения переполнения в matmul (`run.py:312`), но `verify.py` прошёл (exit 0) и сводные числа совпали с `verify`.
- **Правило владельца.** Знак логитов проверен: все пять (`early_win`, `early_nw`, `all`, `late`, `elo_100`) положительно коррелируют с победой Radiant (0,07–0,34). ★ = логит > ln 1,5. «Первый тик» = первая запись журнала, где условие выполнено: журнал пишет тики решений, а не каждую минуту, поэтому реальный вход мог быть раньше. Перебрано 16 клеток (2 порога × 4 условия × 2 цены), ДИ поточечные.
- **Трио-гейт.** Поддержка = min из трёх логитов в сторону андердога > ln 1,5. На 0–5′ котировки Q1 почти нет (n 5 у диспетчера), поэтому для ставок на 00 цена — Q3, первая котировка после тика. Офлайн-корпус ELO хранит P(Radiant) по K24, ΔELO = |logit P|·400/ln 10. Регрессия в бутстрепе давала переполнения на разделимых выборках; на точечную оценку они не влияют.
