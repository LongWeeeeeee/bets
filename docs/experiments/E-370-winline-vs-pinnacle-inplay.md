# E-370. Winline против Pinnacle по ходу карты

**Вопрос (карточка ingame-mof7).** Наши модели и ELO цену Winline по ходу карты не обыгрывают (E-361, дополнение 3).
Может ли перевес дать сама острая линия: если Winline платит за сторону больше, чем честная (без маржи) цена Pinnacle
в ту же секунду, выигрывает ли ставка на Winline? Раньше Winline и Pinnacle напрямую не сравнивали (E-326/E-327 сравнивали
Pinnacle только с нашими моделями).

**Предсказание до прогона (09.10 09:50 MSK, на карточке).** Pinnacle точнее Winline по log loss на ≥0,005; при пороге 5 %
80–250 сигналов, ROI +2…+10 % с ДИ через 0; медиана живучести расхождения < 60 с. Опровержение: ROI ≤ 0 при всех порогах ≥5 %
или Pinnacle не точнее. Решение: живучие (≥60 с, ручная ставка из Telegram) прибыльные расхождения → живой поток Pinnacle и сигнал
в бот за флагом; иначе закрыть рычаг.

## Склейка
Ключ Winline `sourcetv:league:L|id:A|id:B|mapN|Имя1|Имя2`: p1 — это Имя1; id в ключе отсортированы независимо от имён
(сопоставление имя→id через псевдонимы, `svs_join.orient_ids`). Матч OddsPapi ↔ серия Winline по обоим именам и времени,
карта N ↔ рынок 1647/1649/1651, ориентация проверена согласием вероятностей (корреляция 0,979, 13 карт отклонены). Цена Pinnacle
на момент t — последние записи ≤ t по обоим исходам, обе `active` (иначе рынок приостановлен), без маржи нормировкой 1/цена.
Строго прошлые данные; проверено: 0 из 2 557 записей Pinnacle позже строки Winline.

Воронка (fix1): 1 770 ключей Winline со временем → 290 карт матчей с pinnacleId → 232 после проверки ориентации → 94 с исходом
→ 84 уникальные карты. Главная потеря — 1 042 ключа без матча Pinnacle: pinnacleId есть только у крупных турниров
(PGL Wallachia, BLAST Slam, EPL, TI).

Сигналов ≈8 в день (26 дней наблюдения), почти все по ходу карты. Наблюдаемая живучесть: ≥60 с подтверждена у 6 из 78 сигналов.
Механизм: Winline обновляет цену позже Pinnacle (Pinnacle — медиана 6,4 с между обновлениями, наш опрос Winline — 31,5 с);
расхождение — это запаздывание мягкой книги после событий карты, а не устойчивая ошибка оценки.

**Фаворит по ходу карты (H2).** Все карты Winline с явным match_id (~460 карт, ~230 серий), первая строка, где вероятность

Фаворит недооценён на ~3 п.п., маржа Winline на этих ценах 6–7 п.п. — ставка «на фаворита по ходу карты» убыточна.
Предсказание («откалиброван ±3 п.п., ROI −3…−5 %») сбылось. Срез 0,70–0,80 на 10–20-й минуте +0,9 % (n=101) — после факта, не значим.

**Наши WIN-ставки по цене Pinnacle.** 46 ставок win_single (доставленные и заблокированные, 12.09–08.10) с ценой Pinnacle на момент
отправки: побед 76,1 %, Pinnacle 61,8 %, Winline 64,8 %, уверенность модели 72,5 %; z(побед − Pinnacle) = 2,15. «EV по Pinnacle»
этих ставок −4,9 % [−8,6; −1,4] (31 доставленная), фактический ROI +12,5 %. Выбор стороны диспетчером несёт информацию сверх
Pinnacle (тот же знак, что E-327: +10,8 п.п.; выборки пересекаются 12–21.09), поэтому цена Pinnacle не может служить несмещённой
оценкой EV наших ставок. Уверенность модели при этом переоценена (log loss 0,598 против 0,541 у Pinnacle).

## Решение
- Живой поток Pinnacle и сигнал «Winline выше Pinnacle» для ручной ставки не строить: через 60 с ожидаемая прибыль ≤ 0.
- Поймать +5 % можно только автоматической ставкой за ≤15 с — это новая автоматика с деньгами (решение владельца), и мягкая книга,
  скорее всего, быстро режет лимиты таким счетам (гипотеза, не проверялась). Не предлагается.
- Ставка на фаворита по ходу карты по цене Winline — нет (−4…−6 %).
- Для оценки правил по-прежнему ROI по исходам (E-361); «EV по Pinnacle» наших ставок не использовать.

## Где искать ошибку
- Склейка исходов: r1 брала соседнюю карту серии на 4 из 63 карт (окно привязано к trueStartTime OddsPapi, опаздывающему ~на час;
  явный match_id вне корпуса проваливался в подбор по порядку). fix1: явный id вне корпуса — отказ `explicit_mid_unresolved`, окно
  от карт серии в корпусе, у пар-псевдонимов A|B/B|A оставляется одна копия. Красный тест на 4 реальных картах до исправления.
- H2 r1 был недействителен: бриф ошибочно утверждал p1 = первый id ключа (id отсортированы); r2 берёт id Имени1 через
  `orient_ids`, ключи с неразрешимыми именами отбрасываются.
- Время Pinnacle — `createdAt` OddsPapi (UTC); соответствие реальному моменту изменения цены у Pinnacle не проверялось.
- Независимая проверка fix1 (Opus, 09.10): все 84 исхода, окна времени 84/84, 4 известные карты, красный/зелёный тест и основные числа
  воспроизведены (зеркало — только по файлу результатов). Остатки: у строк Winline нет `dom_captured_wall`, отсутствие заглядывания
  вперёд проверено по `wall` (у всех 78 сигналов r1 `dom_age_seconds` = 0); у 6 из 84 карт исход взят по явному match_id без сверки
  с порядком карт серии (предыдущей карты нет в корпусе); правило окна теоретически приняло бы карту N−1 при лишней (переигранной)
  карте в корпусе — среди 84 карт таких 0.
- Опрос Winline раз в ~30 с: живучесть и затухание измерены с этим шагом.
- Покрытие Pinnacle — только крупные турниры; на тир-2/3 вывод не переносится.
