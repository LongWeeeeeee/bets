# E-332. Map NW dominator: «кто первым выйдет в +N нетворса»

Запрос alex (24.09.2026): есть ранний доминатор Early NW; не обучить ли ML-модель на всех картах
«какая команда первой достигнет N нетворса» — доминатор на всю карту.

Как устроен Early NW, с которым сравниваем: метка = первая минута в окне 20–28, когда перевес
по нетворсу ≥ динамического порога (~6000 на 20-й → ~8500 на 28-й, три группы по алхимику),
`base/build_draft_phase_corpus.py:139-150` → `base/analise_database.py:_first_dynamic_threshold_reach`.
Признаки всех драфт-голов — только 10 hero_id по позициям (`hero_role_position_pair`, signed).

Буквальное «первой набрать N суммарного нетворса» посчитать нельзя: у игроков в сырых данных есть
только итоговый `networth`, поминутно есть лишь перевес `radiantNetworthLeads`. Поэтому метка здесь —
«первой выйти в перевес +N» в любую минуту карты (N = 2k…20k; модели на 6k/10k/15k).

## 1. Пререгистрация (`.omc/decisions.md`, до чисел)

- Гипотеза: dom_N коллинеарна All (корреляция логитов ≥ 0.95, AUC победы в пределах ±0.003), dom_6k ≈ early_nw
  (основание — E-136, E-242: для предматчевых признаков «ранний перевес» и «победа» — одна величина).
- Опровергается, если какое-то N даёт AUC победы > All + 0.005 на тех же тестовых картах, либо корреляция
  < 0.85 и с All, и с early_nw при AUC победы ≥ All − 0.005.
- Решение: строить новую голову диспетчера (обучение на всём, бандл, shadow) или записать отрицательный результат.
- Прогноз: P(победа | первый до +10k) ≈ 0.85–0.9; разница AUC победы с All в [−0.004; +0.002].

**Итог по пререгистрации:** гипотеза коллинеарности опровергнута (0.52–0.71 вместо ≥0.95), но первый
критерий пользы (AUC победы > All + 0.005) не выполнен ни для одного N, второй тоже (AUC победы на 0.033+
ниже All). Прогноз по метке сбылся (0.898/0.919), прогноз по AUC нет: разница −0.033…−0.056, а не ≥ −0.004.
Поправка к переносу E-136/E-242: там признаки были предматчевые с силой команд (ELO), и цели «перевес» и
«победа» сливались через силу команды; в чистом драфте на пабах (команды равны по подбору) они расходятся.

E-243 (Late на цели маркера AUC 0.484). All — смесь режимов, поэтому в среднем лучше.

## 8. Где искать ошибку

- Индекс минут: `rad_first/dire_first` — номер элемента ряда +1 (прод берёт `leads[minute-1]`); для порядка
  «кто первый» смещение не важно, для медианных минут — ±1.
- Ряд обрезан по фактической длительности (`duration//60 + 1`), как в сборщике; нечисловые элементы пропущены.
- Early NW-метка взята продовой функцией через `canonicalize_match` — совпадение 0.999 на 6k это подтверждает.
- Модели dom учатся только на определённых картах (подмножество со своими a′/b′ внутри ОБЩИХ разрезов);
  тестовый фолд у всех одинаков.
- Выборка — каждая 4-я часть пабов (1.72 млн из ~7.3 млн); абсолютные AUC на полном корпусе будут чуть выше
  (All в E-317 на 7.3 млн), сравнение голов между собой — на одних и тех же картах.
- Про-когорты применяют модели, обученные на пабах; ELO и игроков в моделях нет.

## 9. Решение

Отдельную голову «Map NW» в диспетчер не строить: как голос за победу она хуже All и в стеке ничего не
добавляет (§3–4). Её содержательная часть — ось темпа — уже есть в Early NW и работает только в связке
с живым состоянием карты (§5–6); это вопрос правил входа, а не новой предматчевой модели. Прод не менялся.
