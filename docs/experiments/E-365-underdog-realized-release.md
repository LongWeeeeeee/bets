# E-365. Ставка на ELO-андердога, который реализует перевес моделей

- **Идея владельца (08.10.2026).** Отменить запрет `win_against_elo_blocked` (E-351, с 03.10). Андердог,
  за которого ML-модели и который это реализует (ведёт по нетворсу, когда срабатывают Early NW / Early
  Win, All за него, возможно Late; или выиграл линию), выиграет. И наоборот: команда, которая должна была
  выиграть линию / раннюю игру, но отстаёт по нетворсу, скорее всего проиграет. ELO отстаёт от реальной
  формы (пример — 1win).
- **Что решает замер.** Ставку продаёт Winline, который видит тот же нетворс. Поэтому вопрос — ROI по цене
  Winline на тике, когда диспетчер отправил бы ставку, а не частота побед.
- **Прогноз до прогона** (`.omc/decisions.md`, 08.10 21:30): реализованный андердог 55–65 % по кэфу
  1,6–1,8, ROI −10…+5 % с ДИ через ноль; нереализованный 25–40 %, ROI −20…−40 %. Итог: реализованный
  выиграл чаще прогноза (85 %), ROI выше; нереализованный — как в прогнозе.
- **Правило решения (записано до прогона).** Узкое снятие под env-флагом, если клетка R1/R3 эры all7m даёт
  ROI ≥ 0 и при Q1, и при Q3. Полное снятие, если вся отсеянная когорта ≥ 0 при P2 и P3 (правило E-351).
  Иначе запрет остаётся.

## Определения

- Строка — одна на (карта, сторона): тик, на котором WIN-решение было бы отправлено (`timing == "now"`:
  `base/cyberscore_try.py:13097` шлёт только его). Доставленные до 03.10 09:59 — первый тик с `now`;
  отсеянные после — первый `win_against_elo_blocked` тик, где решение было бы `now` (game_time ≥ 600,
  ★ ML Laning за цель ≥ 0,60 на 00, или early-NW release). Карты ключуются по `base_url` + `map_num`
  (суффикс `match_key` меняется от тика к тику).
- U — цель ниже по ELO тика на ≥ 50; F — выше на ≥ 50; E — |d| < 50.
- Ячейки: UNOBS — game_time < 300 (ставка на 00, реализация не видна); R1 — перевес цели по
  `radiant_networth_lead` журнала > 0 и game_time ≥ 300; R2 — перевес ≥ 200·m; R3 — R1 и All за цель и
  (Early NW или Early Win) за цель; R4 — линия (использует признаки после ставки — не для решения);
  NR — цель отстаёт, game_time ≥ 300.
- Эры: pre_all7m до 24.09 10:43 MSK, all7m после. Цены — правила Q1/Q3 из E-353 и P1/P2/P3 из E-351;
  ДИ — бутстрап 2 000 по сериям.

## 4. Независимая проверка и пол по кэфу

Native Opus hard-verifier (08.10, скрипты `/private/tmp/claude-501/underdog_verify/`): все 37 строк R1/NR
эры all7m воспроизведены — тик отправки, знак перевеса, исходы (0 расхождений; 3 исхода только из
файла E-353), все 24 котировки Q1/Q3 найдены заново с теми же значениями (рынок «победа на карте»,
не дуэль). Вердикт ACCEPT_WITH_CAVEATS:

- **Пол по кэфу.** Из 7 строк R1 с ценой Q1 пол `1/(p_cal − 0,12)` проходят 3 (1/2, ROI −12,7 %); все 4
  не прошедшие — победы по 1,21–1,71. С полом освобождение андердога почти ничего не даёт.
- Но по всем WIN-ставкам, где сторона ставки ведёт на тике (U + F + E, обе эры), пол работает как задуман:
  прошедшие пол — 17 ставок, ROI Q1 +39,8 %; не прошедшие — 30 ставок (25 побед по ~1,2), +5,4 %.
  Освобождённый андердог ведёт себя как остальные ведущие (11/2 против 17/0 у фаворита и 9/1 у равных),
  поэтому пол для него не отключается.
- Две доставленные победы R1 (9021762797#2, 9026176585#2) на тике были отклонены полом и ушли на
  777–884 с позже, когда свежей цены не было: по правилу пола сигнал без свежей цены уходит с текстом
  «Ставить от кэфа X» (кэф в тот момент ~1,02–1,11). Это задокументированное поведение, не дефект;
  ROI по таким строкам с 08.10 20:06 считается по цене отправки из леджера.
- Одна победа R1 (Yangon Galacticos, 06.10) была бы срезана запретом на команду (с 29.09).

## Решение

- **Узкое снятие (решение ведущего по правилу, записанному до прогона).** `base/ml_dispatch.py`: WIN на
  ELO-андердога не режется, если на тике game_time ≥ 300 и перевес цели по нетворсу > 0. Env
  `ML_DISPATCH_WIN_UNDERDOG_REALIZED_RELEASE` (по умолчанию 1; откат =0), пороги
  `ML_DISPATCH_WIN_UNDERDOG_REALIZED_MIN_TIME=300`, `..._MIN_LEAD=0`. Пол по кэфу, гейт E-357 и дедуп
  действуют как прежде. Ставки 00 по ★ ML Laning режутся на 00, но на следующем тике (обычно ~10:00)
  могут пройти, если андердог ведёт: в отсеянных all7m таких 4 карты (3/1) и ещё 1 карта NR, где андердог вышел
  вперёд позже (проигрыш), — этот срез (3/2) измерен только по исходу.
- Полное снятие — пока нет: NR all7m 7/15, до all7m 3/18; ROI отрицателен при 4 из 5 правил цены (P2 +12,6 %).
  Остаток запрета (NR и 00) решит заранее записанная проверка ingame-3e0e на ~40 отсеянных картах — теперь
  в эту когорту попадают только нереализованные ставки.
- Пол по кэфу остаётся: с ним из 7 строк R1 с ценой прошли бы 3 (1/2). Эффект освобождения в деньгах пока мал — это
  выравнивание правил (реализующий андердог проходит те же гейты, что и фаворит), а не новый источник прибыли.
- **Проверка на новых данных:** вместе с карточкой ingame-3e0e (~15–17.10) и через ~2 недели по
  `reason` в журнале. Провал — ROI освобождённых ставок < 0 и при Q1, и при Q3 на ≥ 15 картах → откат флагом.

## Где искать ошибку

- Тик отправки для отсеянных строк восстановлен по правилам `_timing_for_win`, а не наблюдался.
- R1 — 13 карт, цена есть у 7–8; ДИ ROI от −40 до +86 %. Это решение по правилу, а не доказанное преимущество.
- У отсеянных строк нет `min_odds` в журнале — прохождение пола по кэфу для них не оценено.
- Котировка архивная, не исполненная ставка; рынки «дуэль игроков» отфильтрованы по E-353.
- Перевес журнала — `radiant_networth_lead` на тике (> 0 — Radiant впереди); ориентация проверена на 2 картах.
