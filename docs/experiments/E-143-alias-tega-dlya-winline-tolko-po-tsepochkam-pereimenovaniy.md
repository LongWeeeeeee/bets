# E-143. Старый тег в поиске карточки букмекера

- **Дата:** 2026-08-13 (alex: «мы делали нормализацию имён чтобы состав читался
  даже при смене тега… то же самое должно работать для winline, сейчас кэфы на
  Iron Wing не парсятся»)

## 1. Заявленная причина замером не подтвердилась

В мониторе по паре `Nigma Galaxy — Iron Wing` (match_id 8943000927) ровно
**5 попыток**, все 13.08 с 03:35 по 03:40 UTC, и у всех одинаковый исход:

```
"status": "ok", "odds": [], "details": "winline current map winner market missing"
```

Это важно, потому что сообщения РАЗНЫЕ у разных стадий:

| стадия | сообщение | случаев в логе |
|---|---|---:|
| карточка пары не найдена | `match not found in rendered DOM/network payload` | 2 086 |
| карточка найдена, рынка карты нет | `winline current map winner market missing` | 4 448 |
| рынок есть, закрыт | `winline current map market closed` | 880 |
| кэфы получены | — | 4 830 |

Карточка доказывается `_text_matches_teams`, а она требует **оба** названия в
окне 2 500 символов. Раз ветка «нет рынка», значит `Iron Wing` на странице
нашёлся. Тот же исход в тот же час был у `Team Falcons — LGD Gaming`, где
переименования нет вовсе.

**Вывод:** конкретный случай, ради которого правка задумывалась, ею НЕ чинится.
Причина там другая — на карточке не было рынка победителя текущей карты.

## 2. Почему склейку составов нельзя отдавать букмекеру

Провал по имени существует отдельно и стоит 2 086 попыток. Но прямая подстановка
имён из организации — ошибка, и это видно на примерах склейки:

```
aurora    <- talon               обе продолжают играть
invictus  <- g2xig               обе продолжают играть
edge      <- mosquitoclan, waska
beastcoast -> m80 -> oglatam
```

Склейка по составу (>=4 из 5) ловит и ПЕРЕИМЕНОВАНИЕ, и ПЕРЕХОД игроков. Для
ELO и истории встреч это правильно — сила едет с составом. Для букмекера нет:
там имя обозначает организацию, и если Talon играет на той же странице, поиск
`Aurora` по алиасу `TALON` может доказать чужую карточку. Ошибка не видна в
логе: кэфы приходят, просто не те.

## 3. Критерий, который разделяет

Активность тегов во времени. У переименования интервалы матчей не пересекаются
(допуск неделя на доигровку турнира), у перехода игроков оба тега играют
параллельно. На 64 организациях с двумя и более именованными тегами:

**40 переименований против 24 переходов.**

Цепочка организации 8121295 попадает в переименования:

```
8291895  tundra    2021-02-02..2026-05-18
10150413 ironwing  2026-05-19..2026-05-30
10182357 1w        2026-07-07..2026-08-05
```

Отдельно стоит `chimera -> virtuspro`: по названиям выглядит так же
подозрительно, как `talon -> aurora`, но данные другие — Chimera отыграла
94 карты и остановилась 2025-03-01, этот состав Virtus.pro начал 2025-04-01.
Старый тег мёртв, подставлять безопасно. **Разницу видно только по времени.**

## 4. Что внедрено

- `base/tools/build_team_org_aliases.py` -> `data/team_org_aliases.json`
  (37 цепочек, 88 имён). Имена берутся с ПРОДА: записи вида
  `tier_two_teams['ironwing']` дописывает рантайм на serv1, и локальная копия
  справочника про новые теги не знает — первая сборка на этом споткнулась и
  дала только `tundra <-> 1w` без `ironwing`;
- `team_name_aliases.alias_spellings` читает таблицу лениво и ставит её ПОСЛЕ
  ручного справочника: там написания, подтверждённые на странице букмекера, и
  они точнее наших внутренних имён;
- `compact_key` — свёртка без пробелов: из потока имя приходит как `Iron Wing`,
  а справочник хранит `ironwing`;
- рестарт прода не нужен: парсер запускается подпроцессом и перечитывает модуль
  каждый опрос.

Проверка на проде: `Iron Wing -> ['tundra', '1w']`, `Aurora -> []`.

## 5. Где искать ошибку

- эффект НЕ измерен: сколько провалов «карточка не найдена» реально починится,
  покажет только живой поток. Оценка сверху — 32.6% упоминаний команд в этих
  провалах имеют хоть какое-то альтернативное название, но совпадёт ли оно с
  написанием Winline, неизвестно;
- у топ-виновников (`no hoodwink` 328, `team spirit academy` 318, `ilbirs` 294)
  альтернатив нет вовсе — им нужен ручной справочник, а не этот механизм;
- имена в таблице свёрнуты (`blacklistrivalry`), а `_norm` букмекера пробелы
  сохраняет: многословные старые теги на странице не совпадут. Односложные
  (tundra, 1w, m80, waska) совпадут;
- критерий непересечения проверен на корпусе до 11.08. У совсем свежего
  ребрендинга истории мало, и цепочка может быть не видна.
