# E-207. Ассисты, синергия и модель — все три не нужны

- **Дата:** 2026-08-16 (alex: «а что ассисты? может можно обучить ml модель на
  этих данных»)
- **Почему ассисты вообще можно проверить:** победа и урон берутся из OpenDota
  (33 тысячи карт), ассисты — только у Stratz (15 тысяч). Но лифт — это
  СПРАВОЧНИК по паре героев, а не свойство карты: собрать его можно на тех
  картах, где ассисты есть, а применять к любой. Поэтому ассисты дают признак
  на всём тесте.

## 1. Устройство

Три куска по времени: A 19 829 карт (справочники), B 4 957 (обучение),
C 8 263 (тест). База — классический cp1vs1 из прод-словаря ProTracker.

Первый заход учил модель только на B — 4 957 карт при 16 признаках, и этого
мало, чтобы судить о модели. Во втором заходе модель получает и A, но признаки
для A считаются **по чужим фолдам**: A режется на четыре части, для каждой
справочники строятся по остальным трём. Иначе карта участвовала бы в
собственной оценке. Обучающих карт стало **24 786**.

## 2. Результат (тест 8 263 карты)

| состав | AUC | прирост к cp1vs1 |
|---|---|---|
| только cp1vs1 | 0.5655 | — |
| **cp1vs1 + урон (ОДНА сумма)** | **0.5766** | **+0.0111** |
| cp1vs1 + урон по блокам (4 признака) | 0.5755 | +0.0100 |
| cp1vs1 + ассисты | 0.5641 | **−0.0014** |
| cp1vs1 + синергия | 0.5637 | **−0.0019** |
| всё вместе, логрегрессия (16 признаков) | 0.5721 | +0.0066 |
| CatBoost глубина 3, 300 деревьев | 0.5711 | +0.0056 |
| CatBoost глубина 4, 600 деревьев | 0.5670 | +0.0014 |
| CatBoost глубина 6, 800 деревьев | 0.5588 | −0.0068 |

## 3. Что это значит

**Ассисты не работают на победе карты.** Это согласуется с E-205: на убийство
приходится 1.87 помогавших из пяти, то есть ассист описывает, кто был в драке —
уровень КОМАНДЫ, а не пары. Команда на победе карты уже учтена, и ассисты
приносят только шум.

**Синергия тоже не работает** (−0.0019), хотя по надёжности была лучшей из мер
синергии (0.550 в E-205). Ещё один случай, когда измеримость не равна пользе.

**Модель не нужна.** Ухудшение растёт монотонно с ёмкостью: глубина 3 → 4 → 6
даёт +0.0056 → +0.0014 → −0.0068. Значит за пределами линейной суммы структуры
нет — инженерия признака (лифт из строгой модели ожидания, сумма логарифмов по
25 парам) уже забрала всё, что там было.

**Меньше — лучше.** Одно суммарное число даёт +0.0111; то же самое, разложенное
на четыре блока, — +0.0100; шестнадцать признаков — +0.0066.

Прирост +0.0111 совпадает с независимым замером E-206 (+0.0107, бутстрап
+0.0108 с полосой [+0.0057; +0.0157]) — два разных прогона на одном тесте дали
одно и то же.

## 4. Оговорка

Справочник ассистов вышел вчетверо тоньше справочника урона: 2 888 ячеек против
10 294, потому что карт с ассистами в куске A оказалось 7 490 из 19 829. Часть
отрицательного результата — это тонкость справочника, а не природа величины.
Сбор второго прохода продолжается (собрано 13.6 тысячи из 17.6), и на полном
корпусе проверку стоит повторить. Но разворота ждать не приходится: E-205
измерил, что информации о паре в ассисте вдвое меньше, чем в убийстве, при
вдвое большем числе событий.
