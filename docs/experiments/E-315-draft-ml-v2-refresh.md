# E-315 — обновление draft-фазовых моделей: свежий драфт 7.41f и v2 (players+teams+portraits)

23.09.2026. Offline/retrospective. Продолжение линии draft-phase моделей;
портфель гейтов, свежий драфт-only рефит на патч 7.41f и новый ансамбль
v2 (draft + причинные team/player признаки + «портреты» игрока из пабликов).

## Вопрос и предсказания (записаны до прогонов)

Источник: `.omc/decisions.md`, секция «2026-09-23 draft ML refresh + v2»
(строки ~580–600), задача владельца — свежий draft-only (Early NW / Early Win /
Late / All, патч 7.41f, обнаружен 15.09.2026) должен побить старые модели от
05.09, а v2 (draft + players + teams, «портреты игрока»: сигнатуры, dotaPlus XP)
должен дать **>= +10 п.п.** над draft-only на pro.

Opus-критика плана (та же секция decisions.md) до запуска:
- **B1**: окно август–сентябрь уже открыто E-311/E-313 → это повторная
  selection-выборка, не новый terminal; нужны помесячные forward-фолды и
  проспективный тест на картах >= 24.09 после заморозки кандидата по хэшу.
- **B2**: вход draft в v2 должен быть причинным (помесячные снимки, обученные
  на пабликах ДО месяца карты); pro-мидов исключить из паблик-обучающих строк.
- **B3**: популяции длительности известны только постфактум → primary = All,
  маркеры также считать по всем картам.
- **M1**: записанные позиции Stratz могут быть постфактум → сверить записанные
  и оценённые (причинные) позиции на pro.
- **M2**: `dotaPlusHeroXp` может быть снимком на момент выгрузки, а не причинным
  накоплением → проверка монотонности; для сравнения — E-309 hero XP дал уже
  всего +0.34 п.п., CI [-0.27, +1.01].

Предсказания (decisions.md, там же):
- Свежий драфт: **+0.2..+1.0 п.п.** accuracy на публичном holdout патча 7.41f;
  на pro 7.41f n слишком мал (<300 карт), чтобы что-то разрешить. Опровергнуто,
  если fresh <= old на публичном holdout.
- v2 All: **+4..+7 п.п.** над draft-only, преимущественно за счёт ELO/team
  strength; новый «портретный» блок (pub hero comfort, dotaPlus XP) добавляет
  **<= +1.5 п.п.** поверх ELO + существующих признаков игрока. **+10 п.п. для
  All не ожидается** (лучший измеренный результат где-либо — 64.8% против K24
  61.6%, E-313). Опровергнуто, если v2 − draft < +2 п.п. (подозревать пайплайн)
  или если портретный блок даёт > +3 п.п. (подозревать утечку раньше всего
  остального).

## Протокол

Две независимые стадии.

**Стадия 1 (fresh draft).** Причинный рефит draft-only LR-моделей по 4 фазам
(All, Early Win, Late, Early NW) на окне обучения 01.07–17.09.2026 минус
H_pre, с фиксированным C; детекция патча 7.41f — по JS-дивергенции окна
кандидата относительно среднего baseline-окна (метод
`js_divergence_gt_mean+3std_of_baseline`). Сравнение OLD (05.09) vs FRESH на
H_pre (12–14.09, n=109 133) и H_post (>=17.09, n=48 027) публичных holdout;
на pro 7.41f данных недостаточно для отдельного разрешения.

**Стадия 2 (v2).** Причинные team/player признаки (ELO, командная сила) +
причинный draft-логит + опциональный «портретный» блок (паблик-история
игрока/героя, dotaPlus XP) поверх. Арм-сетка: D (только причинный draft),
E_raw/E_cal (K24-логит), LR (блендинг draft+K24), G71 (71 причинный признак
без портрета), V2a (G71 + draft-логит), V2b (V2a + портрет), CTRL (V2b с
переставленным (permuted) портретом — null-контроль). Помесячные forward-фолды
май–сентябрь 2026, пулинг ALL n=20 210 карт (`v2/report.md`), затем
пересчёт доверительных интервалов с исправленной кластеризацией серий
(`ci_fix/`, см. ниже) — используются как основной источник цифр.

Отдельная проверка «честного маркера» (`verify/`): по данным строго после
2026-08-14 (постфактум-cutoff), не входившим ни в один фолд обучения, чтобы
проверить устойчивость результата вне обучающего окна.

## Что опровергнуто / подтверждено

- **Опровергнуто**: предсказание +0.2..+1.0 п.п. для свежего драфта на 7.41f
  (стадия 1). Фактическое направление — небольшое ухудшение по accuracy на
  All (−0.31 п.п.) и Early NW (−0.36 п.п.), logloss в пределах шума.
- **Подтверждено** (с уточнением): v2 All дал +6.18..+6.25 п.п. над draft-only
  — в пределах предсказанного диапазона +4..+7 п.п., ближе к верхней границе.
- **Подтверждено**: портретный блок не даёт измеримого прироста поверх ELO +
  существующих причинных признаков — предсказание «<=+1.5 п.п.» выполнено с
  запасом (фактически ~0, CI включает 0 и на V2b−V2a, и на стратификации по
  покрытию; V2b−CTRL едва различим от 0).
- **Подтверждено**: предсказание владельца **+10 п.п. для All не достигнуто**
  (фактически ~+6.2 п.п.) — как и было предсказано в decisions.md заранее.
- **Не разрешено окончательно**: early_nw_direction честный маркер после
  исправления бага в разметке даёт CI, включающий 0 (+3.95 [−0.73, 8.56]) —
  портретный вклад для этой цели статистически не отличим от нуля, хотя
  point estimate положительный.
- **Критика B1 (retrospective selection на августе-сентябре) подтвердилась
  как риск, не снята**: результаты стадии 2 — это тот же ретроспективный
  май-сентябрь, что уже открывали E-311/E-313; проспективный тест на картах
  >= 24.09 после заморозки кандидата по хэшу **не проводился** в рамках этого
  прогона (манифест заморожен 2026-09-23T00:39:06Z, но forward-holdout после
  этой даты ещё не набрался).

## Где искать ошибку

- **Фрагментация series_id (устранена в ci_fix)**: старая кластеризация по
  сырому `series_id` давала 2098 из 5874 пар карт с одинаковым составом
  команд в пределах <8 ч, но с разными id серии — bootstrap CI считал их
  независимыми, недооценивая дисперсию. `ci_fix/build_real_clusters.py`
  перестраивает кластеры по составу+времени, расхождение падает до 549/5874
  (74% исправлено), но не до 0 — остаток непроверен на предмет истинных
  разных серий с совпадающим составом.
- **Баг разметки в `ci_fix/check2_fair_marker_ci.py:81`**: конкретно для
  early_nw_direction перерасчёт с исправленными кластерами дал скачок
  2.93→8.05 п.п. — не потому, что портрет внезапно стал полезнее, а из-за
  разницы в purge-множестве обучающих строк для этой более шумной цели.
  Использовать для early_nw_direction только повторно проверенное значение
  +3.95 п.п. [−0.73, 8.56], а не число из `ci_fix/ci_results.md:119`.
- **Семантика `dotaPlusHeroXp` (гейт G2)**: 97.75% строк неубывающие, но
  средний прирост после поражения (375.54) заметно выше, чем после победы
  (285.76) — асимметрия нетипична для чистого счётчика «сыграно XP» и
  указывает на возможный снепшот на момент выгрузки API, а не строго
  причинное накопление (см. M2 в критике). Не проверено: причинно ли поле
  вообще пригодно для использования как признак «до карты».
- **Популяции длительности известны только постфактум**: Early Win / Late /
  Early NW определяются по фактической длине карты, которая на момент
  прогноза ещё не известна — primary метрика должна быть All, вторичные
  цели читать с поправкой на этот источник смещения (B3).
- **Окно август–сентябрь уже открыто E-311/E-313**: числа стадии 2 —
  повторная selection-выборка на данных, уже видевших отбор ранее; не новый
