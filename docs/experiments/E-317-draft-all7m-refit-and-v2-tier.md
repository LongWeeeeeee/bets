## B. v2 с учётом уровня лиг

**Вопрос.** Прирост v2 на pp-картах почти весь от ELO (E-316: V2a − D +11,8 п.п.). Может, любительские
карты (92% теста и большая часть обучения) размывают структуру pp и v2 надо учить только на pp или с
признаком уровня? H1 — размывают; H2 — объём важнее.

**Схема.** Харнесс `run_stage2.py` из E-315 (помесячные фолды май–сентябрь 2026, purge по сериям,
CatBoost с ранней остановкой, thread_count=3), тест — только pp-карты (лиги с tier professional/premium
по `/api/leagues` OpenDota на 23.09, 2 695 лиг). Плечи: `*_all` — как было; `*_tier` — плюс столбец is_pp;
`*_pp` — обучение только на pp-строках. Короткое окно обучения с 01.04.2026 (366–1 974 pp-строк на фолд),
длинное — с 01.01.2025 (~55–62 тыс. строк, из них pp ~9–10 тыс.). Контроль: V2a_all − D на pp = +11,80 п.п.
[8,90; 14,83] — совпало с E-316 (+11,8 [8,9; 14,8]).

**Прогнозы:** P1 (признак уровня нейтрален) — держится на ALL; P2 (только pp хуже) — держится по log loss;
P3 (длинное pp ≈ all в пределах [−0,5; +1] п.п.) — **опровергнут**: хуже по точности и значимо хуже по
log loss на всех трёх целях; P4 (калибровка по pp не хуже) — **опровергнут**, значимо хуже;
P5 (+10..+13 п.п. к D) — держится на ALL.

**Механизм.** Сила команды уже закодирована в ELO и признаках игроков, которые переносятся между уровнями;

~9–10 тыс. pp-строк длинного окна log loss значимо хуже. **H2 подтверждена, H1 опровергнута: v2 учить на
всех уровнях.**
