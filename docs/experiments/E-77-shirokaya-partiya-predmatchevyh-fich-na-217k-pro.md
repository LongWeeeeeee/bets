# E-77. Строить признаки — наша работа, отбирать — модели

- **Дата:** 2026-08-12 (alex: «матчей достаточно что ml сама отобрала фичи или
  нам нужно их искусственно формировать?»)

## 1. Разделение труда

**Отбор** модель делает сама, и данных теперь хватает: 191 825 обучающих карт
против 15 признаков — переобучения нет, регуляризация раздаёт веса. Это видно по
результату: половина признаков получила вклад около нуля, и я их не выкидывал
руками.

**Построение** модель сделать не может, и дело не в объёме. Она видит одну
строку за раз, а «сколько игр у игрока», «его винрейт», «средний рейтинг его
соперников» — агрегаты ПО ДРУГИМ строкам. Из одной строки с десятью id героев и
десятью id аккаунтов эти величины не выводятся: информации там нет.

Исключение — эмбеддинги сущностей: эмбеддинг игрока и есть выученный агрегат.
На паблике отвергнут (E-75), на 217 тыс. про-матчей для частых игроков стал
реален и не проверен.

## 2. Результат

Всё считается одним хронологическим проходом, строго по прошлому.

| признак | вес | AUC без него | вклад |
|---|---|---|---|
| draft_logit (паблик-модель по героям) | +0.178 | 0.6597 | **+0.0223** |
| **opp_elo** (средний рейтинг соперников за карьеру) | +0.221 | 0.6751 | **+0.0068** |
| elo (рейтинг игроков) | +0.180 | 0.6784 | +0.0036 |
| games (сыграно матчей) | −0.708 | 0.6793 | +0.0026 |
| **hero_pool** (широта пула героев) | +0.475 | 0.6794 | +0.0026 |
| **pos_games** (игр на этой позиции) | +0.235 | 0.6799 | +0.0021 |
| form (последние 20 матчей) | +0.148 | 0.6802 | +0.0017 |
| hero_games (игр на этом герое) | +0.066 | 0.6802 | +0.0017 |
| career_days (стаж в днях) | +0.108 | 0.6812 | +0.0007 |
| hero_wr, rest_days | | | +0.0002 |
| cohesion (сыгранность), elo_spread | −0.000 | 0.6819 | **0.0000** |
| winrate (пожизненный) | +0.188 | 0.6824 | −0.0004 |
| tier1_games (счётчик игр против сильных) | +0.192 | 0.6843 | **−0.0024** |

**Всё вместе: AUC 0.6819. Только герои: 0.5935.**

Главное содержательное: **важнее, ПРОТИВ КОГО игрок играл, чем сколько**. Средний
рейтинг соперников за карьеру даёт вдвое больше, чем собственный рейтинг игрока.
При этом та же идея в виде СЧЁТЧИКА матчей против сильных (`tier1_games`) не
просто бесполезна, а вредит: коллинеарна с `opp_elo` и вносит шум. Одна мысль,
две формы — работает одна.

## 3. Исправление к E-75

Там признак «привычность позиции» дал −0.003, и это было объяснено фразой
«профессионалы позицию не меняют». **Объяснение неверно.** Замер на 16 028
игроках с 20+ про-матчами:

| | доля |
|---|---|
| играют строго одну позицию (>=95% матчей) | **14.9%** |
| основная позиция < 80% матчей | 64.7% |
| основная позиция < 60% матчей | 39.2% |
| играют 2+ позиции (от 10% матчей каждая) | 72.3% |

Медианный профессионал проводит треть матчей не на основной позиции. Настоящая
причина нуля — **конструкция признака**: доля матчей на позиции у игрока с
раскладом 50/50 равна 0.5 для обеих, и «уверенно играет обе» неотличимо от
«поставили не туда». Абсолютный счётчик `pos_games` этой болезни не имеет и
даёт +0.0021.

Отсюда правило в `AGENTS.md`: нулевой результат объясняется в последнюю очередь,
и перед объяснением смотреть на сам признак — покрытие, разброс, корреляцию с
уже вложенным. Это отделяет «сигнала нет» от «признак посчитан не так».

## 4. Что осталось непроверенным

- эмбеддинги игроков, обученные на ПРО-матчах (не на паблике);
- цена: весь замер по AUC, а не по ROI. По E-76 рост винрейта на фаворитах
  экономически почти ничего не значит — нужен джойн по реальным коэффициентам;
- признаки, требующие сбора: стадия турнира, призовой фонд, дни с последней
  смены ростера.
