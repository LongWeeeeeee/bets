# E-319. Драфт на про-картах: сколько он весит и почему v2 его теряет

- **Дата:** 2026-09-23. Запрос владельца: «Добейся лучших результатов +5% хотя бы. считай что драфт
  это основа предсказания и если он работает плохо значит модель обучена неправильно даже лучшая
  команда проиграет если драфт ужасный».
- **Продолжает:** [E-317](E-317-draft-all7m-refit-and-v2-tier.md) (раздел C: v2 без драфта на pp
  не хуже полной v2).
- **Цель (допущение, сказано владельцу):** +5 п.п. точности на картах pp (OpenDota tier
  professional/premium) над текущей v2 (V2b 66,92 %, G71P 67,56 %).
- **Смешение, названное до замеров:** драфт-модель, обученная на про-картах, может «выиграть» точность,
  выучив силу команд (сильные команды берут мету). Поэтому решающая метрика — прибавка к ELO и
  corr(логит драфта, логит ELO), а не точность драфта в одиночку.

## Результаты (pp, 1 720 карт, бутстрап по сериям 1000×)

| шаг | что мерили | результат |
|---|---|---|
| 1. Проверка утверждения | драфт при фиксированном ELO | фаворит по ELO ≥0,65: 70,5 % (драфт <0,45, n=251) → 79,6 % → 85,6 % (драфт ≥0,55, n=284); ELO 0,50–0,65: 50,3 % → 61,5 % → 62,1 %. corr(драфт, ELO) = 0,084 |
| 1. | сила и масштаб | AUC драфта 0,582, ELO 0,743; LR y ~ ELO + драфт: коэффициент драфта 0,58 [0,37; 0,83] (не-pp лиги 0,63 [0,56; 0,68]) — паб-модель переуверена на лигах в ~1,7 раза |
| 2. Граница | in-sample LR на pp | ELO 67,50 % → ELO + драфт 68,37 %; драфт меняет выбор на 153 из 1 720 карт (прав на 55 %). Симуляция: +5 п.п. требует коэффициент драфта ×3 |
| 3. L4 | логиты фазы Early NW в v2 ALL/EW/Late | ALL: V2b_ENW − V2b +0,76 [−0,12; 1,69]; EW −0,42 [−2,49; 1,68]; Late 0,00. Около нуля |
| 4. Комбинатор | LR ELO + драфт вне выборки, те же фолды | обучение на pp: **68,78 %**, на всех лигах 68,43 %; CatBoost V2b 66,92 %, G71P 67,56 %, только ELO 67,21 %. LR(pp) − V2b **+1,86 [0,34; 3,29]**; log loss 0,5864 (all) против 0,5932 |
| 5. Поправка по героям | LR ELO + драфт + знаковый one-hot 127 героев, C по внутреннему сплиту | C = минимум сетки (0,003) во всех 5 фолдах; AUC драфта 0,582 → 0,595, corr с ELO 0,086 → 0,091; с ELO точность −0,76 [−1,75; 0,23] |
| 6. Разреженная LR | ELO + драфт + 71 признак (+ 43 портрета), L1/L2 | ничто не лучше ELO + драфт (68,72 %): +признаки −0,23…−0,58; +портреты −0,70…−1,98 (L2 на pp: значимо хуже) |

На всех 20 210 лиговых картах драфт внутри CatBoost работает (V2b − G71P: ALL +0,69 [0,18; 1,20],
Late +1,12, EW +0,98), а на pp — нет (ALL −0,64, Late −0,43). Логистическая регрессия на тех же
двух числах забирает драфт и на pp.

## Предсказания и что с ними стало

- Проверка утверждения: AUC драфта 0,57–0,59, коэффициент 0,3–0,8, разрыв WR фаворита ~12 п.п. —
  **сбылись** (0,582; 0,58; 15 п.п.).
- L4: ALL +0,5…+1,5 п.п., log loss −0,005…−0,015; EW +1…+2 — **не сбылись** (log loss −0,0025,
  EW −0,42).
- Поправка по героям: AUC драфта 0,585–0,60, corr с ELO ≥0,12 — AUC сбылось (0,595), утечки силы
  команд нет (0,091). Порог развилки A (AUC ≥0,62) не достигнут.

## Механизм (гипотезы с проверкой)

1. **CatBoost размывает слабый признак на малом срезе (проверено частично).** На pp у драфта нет
   взаимодействий, которые стоило бы учить (разрыв WR одинаковый при любом ELO, шаг 1). Деревья на
   115 колонках тратят сплиты на признаки, которые на pp шумят (шаг 6), а коэффициент драфта
   откалиброван на всех лигах. Линейная модель с двумя числами этого не делает.
2. **Драфт у про слабее, потому что его выравнивают баны и мета (частично проверено).** AUC одной и
   той же паб-модели падает с уровнем: отложенные пабы 0,6246 (n=1 327 731, `honest_test` прода 05.09),
   свежие пабы H_post 0,6286 (E-316), все лиги master 0,5922, pp 0,582. Медианный |p − 0,5| на pp
   0,080 против 0,088 на прочих лигах. **Против:** `pro_forward_evaluation` того же прода — AUC 0,6289
   на 639 про-картах (другой период, ±0,045 на 95 %). Отделить «баны и мета выравнивают драфт» от
   «сдвига популяции» на этих данных нельзя.
3. **Драфт кодируется для лиг не так, как для пабов (опровергнуто кодом).** `p` в master строят 7
   месячных снимков `hero_role_position_pair` (`base/tools/prematch_public_draft.py:30-54`, энкодер
   `:93`); позиция = индекс слота (`base/draft_features.py:132`, `:180`), слоты для пабов и лиг
   переставляет одна и та же процедура по прошлой ролевой истории
   (`base/tools/prematch_causal_dataset.py:264-276`, `:351`, `:430`). Разницы нет.
4. **Паб-модель неверно оценивает героев для про (развилка A).** На уровне отдельных героев на 7–26
   тыс. лиговых карт не подтверждается (шаг 5). Большого свежего лигового корпуса для дообучения нет:
   в `runtime/artifacts/misc/pro_corpus_rich.npz` 1 261 591 карта, но с 2026-01-01 только 45 772
   (с 2026-04-01 — 27 601, это и есть master), позиций героев нет. Остальное — прошлые патчи.

## Где искать ошибку

- Коэффициенты шага 1 и граница шага 2 посчитаны in-sample на тесте pp; вне выборки проверено
  только в шаге 4 (там 68,78 % — выше in-sample 68,37 %, потому что LR максимизирует правдоподобие,
  а не точность).
- LR (pp) выбрана из двух вариантов обучения постфактум; честное сравнение без выбора — LR на всех
  лигах: +1,51 [0,00; 3,04] к V2b.
- Разница CatBoost и LR может частично идти от сида и ранней остановки CatBoost (один сид, 20 %
  хвоста на остановку). Контроль: E_cal (LR на одном ELO) совпадает с LR_E до сотых (67,21) — фолды
  и кластеры совпадают.
- Поправка по героям: знак +1/−1 по слотам 0–4/5–9 `heroes`. Если порядок слотов в master не
  «radiant затем dire», поправка — шум. Косвенная проверка: сумма по строке ровно 0 на всех 26 980
  картах.
- Коэффициент драфта в LR отражает масштаб паб-модели на лигах; если `p` в master посчитан снимком,
  у которого другая калибровка, чем у боевого, вывод «×1,7» относится к снимку.
- sklearn на macOS сыплет RuntimeWarning overflow в matmul (Accelerate BLAS); предсказания конечны,
  LR_E совпадает с E_cal — на результат не влияет.

## Вывод

Утверждение владельца на про-картах подтверждается по направлению: драфт — самостоятельный сигнал, и
при ужасном драфте даже явный фаворит проигрывает заметно чаще (−15 п.п.). По величине — нет: на pp
драфт даёт +1,2…+1,6 п.п. к ELO, и нынешняя v2 на CatBoost эту прибавку теряет. Исправление,
которое доказано: считать pp-прогноз логистической регрессией ELO + драфт (+1,86 п.п. к V2b). До
+5 п.п. не хватает сигнала драфта в ~3 раза; ни фазовые логиты, ни поправка по героям его не дают,
кодирование позиций для лиг и пабов одинаковое, а свежих лиговых карт для отдельной про-модели
драфта — 46 тыс. за 2026 год. Интеграция в диспетчер не делалась: v2 в диспетчере на паузе по решению
владельца.
