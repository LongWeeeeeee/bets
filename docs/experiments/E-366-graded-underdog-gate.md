# E-366. Ступенчатый гейт ставок на ELO-андердога

- **Просьба владельца (09.10.2026, через сессию-супервизора).** Заменить бинарный запрет
  `win_against_elo_blocked` (E-351, с 03.10; с 08.10 узко снят E-365) ступенчатым: при отставании по ELO
  ≤ 100 нужна уверенность ML ≥ 65 %, ≤ 300 — ≥ 70 %, больше — не ставить.
- **Возражение к средству (до прогона, супервизор + ведущий).** На строках E-365 буквальное правило (уверенность =
  max по моделям за сторону ставки) пропускает 43 карты: 16/27, P2 −2,7 % (37 с ценой), Q3 −20,0 % (28); оставленные
  47 — P2 +11,4 %, Q3 −6,1 %. Сырая уверенность на андердогах завышена: верхняя половина по expected_wr (в среднем
  0,78) выиграла 15/37. Направление (ступенчатый гейт) оставлено, средство заменено на EV-гейт.
- **Правило решения (записано до прогона, карточка ingame-geh5).** Выкатка под флагом только если EV(m=0,05) лучше
  текущего гейта по суммарной прибыли и при Q3, и при P2, в обеих схемах вне выборки, и парный бутстрап по сериям даёт
  P(разница > 0) ≥ 0,9 во всех четырёх; пол по кэфу включён. Иначе — идея.
- **Прогноз до прогона:** провал (рынок и так переоценивает андердога: 0,365 против факта 0,307, E-365).
  Совпал.

## Определения

- Андердог U: |ΔELO| ≥ 50 против стороны ставки (`elo_target_edge` ≤ −50), отставание = −edge.
- `conf_max_for` / `conf_mean_for` — max / среднее уверенностей моделей, проголосовавших за сторону ставки.
- CUR (бой с 08.10): ставка на U, если game_time ≥ 300 и перевес по нетворсу > 0 (E-365).
- OWN_max / OWN_mean — правило владельца с max / средней уверенностью; `_nocap` — без запрета > 300.
- EV(m): p_cal · кэф ≥ 1 + m; p_cal — логистическая регрессия (logit средней уверенности, ΔELO/100,
  перевес/1000 + флаг пропуска, эра) на F+E+U с исходом; вне выборки — без своей серии (LOSO) и только по
  прошлому (walk-forward, ≥ 60 строк обучения). Решение по той же цене, что и ROI.
- Цены Q1/Q3/P2 — как в E-351/E-365. Пол по кэфу — `min_odds` диспетчера; у 18 отсеянных с 03.10 пола в
  строках нет, поэтому «пол вкл.» их исключает, «пол выкл.» — включает.

**Калибровка на 90 картах U (log loss):** рынок Q3 0,545 / P2 0,558; p_cal LOSO 0,616, walk-forward 0,645;
сырая средняя уверенность 0,794, max 0,911. Модели на андердогах не лучше рынка даже после калибровки — EV-гейт

**Пересечение с текущим гейтом** (U с исходом, пол выкл., P2): OWN_mean и не CUR — 6/4, 10 с ценой, +10,32 ед.;
оба — 1/0, +1,25; CUR и не OWN_mean — 14/3, 15 с ценой, +4,69; ни один — 13/49, 54 с ценой, −12,35.
OWN_mean почти не пересекается с CUR: это другие карты (андердог чаще отстаёт по нетворсу, все модели за него
уверенно согласны). Половину прибыли даёт одна победа по 6,2.

**Проверка (Opus hard-verifier, ACCEPT_WITH_CAVEATS).** Знаки ΔELO и перевеса, уверенности, фолды без утечки, цены
решения и ROI совпадают; все четыре разницы EV−CUR < 0 при любом сиде и с полом и без. Оговорки исправлены в v2:
24 группы «пара команд × день» были разбиты между запасным ключом `pairday:` и ключом серии `s…` (склеено 22, 2 —
серии через полночь МСК, оставлены; P меняется на ≤ 0,02). Голос `prematch` (выключен в бою с 24.09) входил в среднее:
только по внутриигровым моделям OWN_mean и не CUR — 6/3, 9 с ценой, +11,32 ед. (пол вкл.); только свежие котировки P1
(≤ 300 с): 7 ставок, 5/2, +7,43 ед. Без победы по 6,2 (её P2-котировке 708 с) — +6,37 ед.; 7 из 11 карт — эра до all7m.

Цифры супервизора воспроизведены точно (43 карты, 16 побед, P2 −2,7 % на 37, Q3 −20,0 % на 28; оставленные 47:
P2 +11,4 %, Q3 −6,1 %; верхняя половина expected_wr 0,780, 15/37).

## Решение

- Текущий гейт (запрет + снятие E-365) остаётся. Правило владельца в буквальном виде не выкатывается — оно
  хуже текущего и по Q3, и по P2.
- OWN_mean по внутриигровым моделям (средняя уверенность моделей за сторону ≥ 0,65 при отставании 50–100,
  ≥ 0,70 при 100–300) — идея ingame-f97l: проверка только на картах после 09.10, нужно ≥ 20 карт с ценой сверх
  CUR (~0,4 в день → ~08.12, промежуточный счёт 09.11). Журнал диспетчера хранит голоса — правило считается задним
  числом, код не нужен. Критерий: ROI > 0 при Q3, P2 и свежих P1, P(прибыль > 0) ≥ 0,9.

## Где искать ошибку

- Знаки: `elo_target_edge` < 0 — сторона ставки андердог; `target_lead` > 0 — сторона ставки впереди.
- 18 отсеянных с 03.10 без `min_odds`: таблица «пол вкл.» их не видит; смотреть «пол выкл.».
- OWN_mean выбран после прогона среди ~8 вариантов гейта × 2 цены: множественные сравнения; 10–11 ставок; одна
  победа по 6,2 даёт половину прибыли.
- Q3 — котировка до 180 с после тика (допущение: игрок сам проверяет цену); P2 может быть старой ценой.
