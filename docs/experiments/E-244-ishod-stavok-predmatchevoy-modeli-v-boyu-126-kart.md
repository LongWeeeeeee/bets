# E-244. Исход ставок предматчевой модели в бою: 126 карт, 74.6%, провал полосы 0.60–0.65

- **Дата:** 2026-09-01. Запрос alex: «проведи инспекцию прода: ml модели,
  эксперименты их обучения, словари и в общем мой подход — где мы теряем винрейт».
- **Вопрос:** сходится ли фактический винрейт ставок пути `prematch_model_bet`
  с обещанием `lan_expected_wr`, и в какой полосе (уверенность, кэф, номер
  карты, сторона) он ниже безубыточного. Популяция — только ставки этого пути:
  у STAR-ставок (early/late/all) журнала исходов нет вовсе.
- **Харнесс:** `runtime/experiments/cyberscore-prod/bet_outcomes_e244/master2.py`
  (сегменты и калибровка), `gate_counterfactual2.py` (заблокированные гейтом
  кандидаты из `map_verdicts.json`), `odds_join.py` + `odds_roi.py` (попытка
  джойна с ценой — отвергнута, см. дефекты), `check_31min.py`.
- **Входы:** копируются в `./serv1_data/` рядом со скриптами:
  `scp serv1:/root/main/runtime/{prematch_model_bet_sent.jsonl,prematch_model_eval.jsonl,live_elo_progress.json,winline_odds_history.jsonl} serv1:/root/.local/state/ingame/map_verdicts.json serv1_data/`
- **Запуск:** `cd runtime/experiments/cyberscore-prod/bet_outcomes_e244 && ../../../../venv_catboost/bin/python3 master2.py`
- **Дефекты, найденные ДО выводов:**
  1. В журнале 204 строки, но 126 уникальных решений: `dedup_key = match_key`
     вместе с суффиксом `.0`/`.1` (`base/cyberscore_try.py:27504`), и та же
     карта уходит второй раз после смены ключа. 64 карты из 126 — дважды.
     Все n ниже — по уникальным картам.
  2. `runtime/prematch_model_eval.jsonl` — не журнал вето: 478 из 485 записей
     `reason=ok`, это проверка полноты входа, а не причина отказа модели.
  3. Джойн цены по паре команд + номер карты без даты и лиги подхватывает чужие
     матчи из 30 тыс. строк истории: полоса цены 3.5–10 даёт 100% побед на
     n=10, средняя цена 2.33 при пороге модели 1.0–1.8. ROI отвергнут.
  4. `/root/.local/state/ingame/map_verdicts.json` — скользящий кэш ~22 карт
     (31.08 13:53 → 01.09), а не архив: контрфакт по гейтам на нём не считается.
- **Результат** (n=126, Уилсон 95%):

  | сегмент | n | WR | ДИ95 |
  |---|---|---|---|
  | все | 126 | 74.6% | [66.4; 81.4] |
  | карта 1 / 2 / 3 | 59 / 51 / 15 | 76.3 / 70.6 / 80.0% | |
  | уверенность 0.60–0.65 | 16 | **43.8%** | [23.1; 66.8] |
  | уверенность 0.65–0.70 | 20 | 70.0% | |
  | уверенность 0.75–0.80 | 21 | 90.5% | |
  | уверенность ≥0.80 | 47 | 85.1% | |
  | min_odds 1.6–1.8 | 21 | **47.6%** | [28.3; 67.6] |
  | \|model_elo\| < 50 | 28 | 60.7% | [42.4; 76.4] |
  | сторона radiant / dire | 56 / 70 | 69.6 / 78.6% | |

  Калибровка: заявлено 61.1 → факт 43.8 (0.60–0.65); 64.6 → 70.0; 73.5 → 90.5;
  81.3 → 85.1. Промах только в одной полосе, и она стоит ровно на безубыточной
  цене (`LAN_ODDS_GRID`: 0.60 → 1.67, запас +0.2%).
- **Контроль:** исход берётся из `live_elo_progress.json` — ledger живого ELO,
  не зависящий от модели; покрытие 126 из 126. Дубли сняты по (match_id, map_num).
  Что могло бы дать 43.8% помимо дефекта модели: случайность (n=16, ДИ до 66.8%).
  Не исключено — полоса требует n ≥ 60 до любой правки порога.
- **Где искать ошибку:** (1) n=16 в проваленной полосе; (2) окно 18 дней,
  одна мета-версия; (3) `radiant_win` в ELO-ledger не сверен с внешним
  источником (OpenDota) ни по одной карте — если ориентация сторон в записи
  перевёрнута, все числа зеркальны; (4) снимок модели заморожен на корпусе
  23.08 (см. инспекцию 01.09 в `.omc/decisions.md`) — часть промаха может быть
  ценой устаревания, а не полосы.
- **Вывод:** порог не двигать. Завести постоянный журнал исход + цена для ВСЕХ
  путей ставки (STAR-ставки сегодня не сверяются ни с чем); чинить dedup-ключ
  (срезать суффикс карты); пересчитать полосу 0.60–0.65 при n ≥ 60.

## Дополнение 01.09 (тот же ход) — разрез по периодам: предсказание НЕ сбылось

Предсказание перед разрезом: после заморозки снимка (корпус 23.08) винрейт ниже.

Конфаунд найден: периоды — это разные популяции. 15–23.08 в журнале Team Spirit (13),
Nigma (10), Yandex (10), Falcons (7), Liquid (6) — тир-1 турнир; 24.08–01.09 — Team Lynx,
Klim Sani4, Summer Bear, Level UP, PuckChamp — онлайн тир-2/3. То есть по 18 дням
цена устаревания снимка НЕ идентифицируется, а промах относительно обещания сидит на
**тир-1 картах** (−7.0 п.п. при n=41), где вход модели беднее всего (E-195: отказ 35.6%)
и где, вероятно, линия рынка острее — цены не записаны (`--no-odds`), проверить нельзя.
На онлайн тир-2/3 модель ПЕРЕвыполняет обещание (+6.7 п.п.), несмотря на fill<1 у 50 из 85.
По силе ELO: \|model_elo\| ≥150 даёт 88.9% (n=36) во втором периоде и 66.7% (n=12) в первом.

Что это меняет в выводе: полоса 0.60–0.65 и «LAN-таблица на онлайне» как причина потери
не подтверждены; следующий разрез — по тиру команд на n ≥ 60 в тир-1, с записанной ценой.
