# E-373. Живой контрфактик гейтов пропуска WIN-ставок

Карточка ingame-gaqh, orchestra-задача win-gate-cf-20261010. Сессия ingame-3d (claude:1cef9fff), 10.10.2026.

## Вопрос

Режут ли гейты пропуска WIN-решений диспетчера (`skipped[].reason` в `ml_dispatch_decisions.jsonl` и блоки доставки — записи `delivered[status=blocked]` того же журнала; в `bet_dispatch_ledger.jsonl` блокированных записей нет, он служит только для «позже доставлено») ставки, которые по живой цене Winline были бы прибыльными? Живые контрфактики до этого были только у гейтов на андердога (E-351, E-365, E-372). У early_solo_blocked (с 15.09, офлайн-основание E-291), veto, conflict и late_conflict_wait их не было.

## Прогноз и правило (записаны до прогона)

- early_solo_blocked: заблокированная сторона выигрывает 55–60 %, подразумеваемая вероятность ~60 %, ROI −3…−8 % (гейт полезен, но слабо).
- veto: заблокированная сторона < 50 %, ROI < 0.
- conflict: около монетки.
- **Опровержение:** у гейта ROI заблокированного набора > 0 и ДИ целиком выше 0 по фактической цене → флаг гейта пересматривается.

## Метод

- Первый пропуск на (карта, сторона, причина), карта = числовой id из `base_url`. Только `market == "win"`.
- Исход: STRATZ `didRadiantWin` → `applied_maps` леджера ELO (у tombstone исхода нет). Корпус npz выключен: согласие сторон с STRATZ < 99 %.
- Цена: последняя принятая открытая котировка `winline_current_map_winner` того же match_id в окне [ts − 600; ts + 5] с. Сторона определяется точным совпадением имени после `norm()` (p1 = первое имя в `canonical_key`). Несовпадение = нет цены, без угадывания.
- ROI = среднее (исход × цена − 1) по строкам с ценой. ДИ — бутстреп по сериям (2 000 повторов, seed 20261010). Ключ серии = отсортированная пара команд + календарный день MSK.
- Периоды: до/после 03.10 00:00 MSK (1790974800; смена пола на калиброванный, 1a30ebc7) и до/после 09.10 20:15:18 MSK (1791566118; снятие запрета на андердога).
- Отдельно «позже доставлено»: та же карта и сторона ушли ставкой позже (журнал `delivered` или леджер).

## Дефекты, найденные ДО выводов

r0 (Codex 011b2019) ведущий забраковал по четырём пунктам. Все четыре починены в r1 (d5967342):

1. **late_conflict_wait сливал обе стороны карты.** Журнал пишет пропуск и Radiant, и Dire на каждом тике ожидания, поэтому попадание было ровно 50,0 % во всех периодах (97/194, 70/140, 27/54). В r1 роли разобраны из `detail` ("early[...]->X vs ['late']->Y"): `:early_side` и `:late_side`. Добавлен assert «ни одна строка гейта не содержит обе стороны одной карты»: на r0 он красный (100 карт ожидания), на r1 зелёный (14 строк гейтов).
2. **conflict без стороны** (`side = null`, 0 годных строк). В r1 24 события → 48 направленных кандидатов по набору поддерживающих моделей.
3. **Блоки доставки без подпричины.** В r1 43 события → floor 36 / no_price 4 / other 3, по определению E-361 (`scoreboard.py:180`: строго `price < min_odds`).
4. **early_solo «позже доставлено = 0/127» выглядело подозрительно.** Сверено с журналом и леджером, включая записи без market: 0, пропущенных пар 0.

## Механизм

Гейты срезают стороны, у которых ранние модели расходятся с поздней или с остальными. Без поддержки модели такая сторона по живой цене не лучше рынка. Для андердога она хуже рынка: то же, что E-374 (андердог по ELO в игре −32,5 %, n 249) и E-347 (драфтовые ★ ≈ монетка). У фаворита Winline уже закладывает перевес в цену (безубыток ~71 %), а без согласия моделей фаворит выигрывает 52–62 %. Поэтому прогноз по early_solo (55–60 %) завысил попадание: в заблокированном наборе почти половина — андердоги с 31 %.

## Решение

Решаю: все гейты оставить как есть (early_solo_blocked, veto, conflict, ожидание 31′, пол по кэфу). Правило опровержения не выполнено ни для одного: у всех ROI ≤ 0 или ДИ задевает 0. Откат не нужен.

Данные по андердогу (особенно 8/24 на `win_late_after_wait`) переданы в ingame-5mgd: там открыт вопрос владельца о возврате `ML_DISPATCH_WIN_UNDERDOG_BLOCK=1`. Флаг меняет та сессия, не эта.

## Независимая проверка

Opus hard-verifier (свежий контекст, свои скрипты без gate_cf.py), вердикт VERIFIED:

- **Пересчёт с нуля.** 417 строк четырёх основных гейтов, 0 расхождений по исходу, цене и строке источника. n, победы, безубыток и ROI для early_solo, veto и обеих ролей ожидания совпали точно.
- **10 случайных строк.** Сверка с сырыми журналом, STRATZ и Winline: 10/10.
- **Сторона цены.** Независимый путь `card_team_order`: p1 = первое имя в 38 505 котировках, 0 расхождений.
- **Ориентация исхода.** Лидер по NW ≥ 12k после 25′ совпадает с победителем STRATZ на 90/97 картах; 7 — камбэки.
- **Попадание early_solo — не эффект отбора.** 45,8 % и с ценой (33/72), и без цены (22/48).
- **«Позже доставлено» 0/127.** Подтверждено. 58 записей леджера «раньше» на 1,2–4,9 с — это отправки килов того же тика: леджер округляет ts вниз до секунды.
- **Пол.** Все 36 строк floor — `price < min_odds` (пример: 1,32 < 1,92, строка журнала 2417).
- **Красный/зелёный.** Три мутанта Radiant/Dire: 2, 5 и 4 падения; оригинал 15/15.
- **Бутстреп.** Собственный (5 000 повторов, другой seed) — в пределах 1,5 п.п. (early_solo [−40,6; +4,2]). Кластер = серия: 56 групп на 72 карты.

Проверка ведущего «строка не несёт id предыдущей карты». Строка доигранной карты выглядит как следующая (см. память `finished-map-row-looks-like-the-next-map`). У 439 из 528 строк есть старт карты в корпусе npz. Для всех 439 разность «время тика − старт − игровое время» лежит в 0…1 500 с (медиана 914 с: драфт + задержка трансляции). Игровое время больше длительности карты по STRATZ — 0 строк. Остальные 89 строк вне корпуса так не проверяются.

## Контроль

- Сторона: тест на снятых строках журнала. Красный при перестановке Radiant/Dire (мутанты выше).
- Попадание «ровно 50 %» в r0 и его исчезновение в r1 подтверждают, что разбор ролей ожидания убрал смешение сторон.
- Цена не заглядывает вперёд: ≤ +5 с от тика.

## Где искать ошибку

- Цена на тике пропуска (≤ 600 с назад) — не исполнимая цена. Для поздней стороны ожидания это цена первого тика, а не 31′; цена на тике доставки посчитана отдельно, только для доставленных.
- Срезы с ценой и без цены — разные подмножества: Winline снимает рынок на решённых картах (без цены 30–40 % строк).
- Гейты пересекаются: одна карта бывает в нескольких. Выборки не независимы, поправки на множественность нет. Из ~12 срезов по роли ELO один с ROI > 0 (early_solo без андердога, +19,5 %, n 20 с ценой) — ожидаемый шум.
- Ключ серии «пара + день MSK» может склеить две серии в один день или разрезать серию через полночь.
- 16 карт без исхода (STRATZ не знает, в леджере tombstone).
- NW на тике в журнале нет, поэтому остаток после гейта 11k (E-357, с 07.10) для андердога на `win_late_after_wait` не измерен.
