# E-321. Первая котировка Winline на карту против ELO

- **Дата:** 2026-09-23. Идея владельца: «можно считать по первой как кэф на карту потому что он
  отражает именно то что мы видим после драфта». Продолжает поиск новой информации о силе команд
  после [E-320](E-320-k24-elo-dynamics-on-pro-maps.md).
- **Прогноз до замера:** склеится 1–3 тыс. карт, из них 150–400 тестовых pp; AUC рынка на pp
  0,74–0,80; точность не растёт с задержкой котировки. **Не сбылось по AUC** (0,694), по числу карт —
  на нижней границе (308 pp).

## Склейка

- Фильтр: `market_status=open`, `accepted`, `source=winline_current_map_winner`, оба кэфа > 1;
  3 538 записей `odds_promoted_from_match` исключены.
- Карта: по `match_id` (289) или по лиге + паре id команд из `canonical_key` + номеру карты в серии +
  |ts − wall| < 4 ч (ещё 129). Итого 418, ориентировано 391 (93,5 %).
- Ориентация: `p1_odds` относится к первому имени ключа (совпадает с `card_odds` на 35 151 записи).
  Имя сопоставляется с id по названиям OpenDota `/api/teams/<id>` и `base/id_to_names.py`, оба
  источника согласны в 155 из 155 случаев. Порядок id в ключе случаен (первый id — radiant в 50,6 %),
  поэтому по нему ориентировать нельзя.
- `pro_corpus_rich.teams[:,0]` — radiant: совпадение `wins` с master `y` на 26 980 картах.
- Задержка первой котировки от `ts`: p10 84 с, медиана 848 с, p90 1 031 с.

## Результат (те же карты, ELO = вариант new3x_dur_ac из E-320)

| выборка | n | рынок: точн. / AUC | ELO: точн. / AUC | corr логитов |
|---|---|---|---|---|
| все | 391 | 64,2 % / 0,721 | 66,5 % / 0,726 | 0,818 |
| pp | 308 | 62,0 % / 0,694 | 65,6 % / 0,710 | 0,800 |
| pp, котировка не раньше `ts` | 276 | 62,3 % / 0,691 | 65,2 % / 0,709 | 0,799 |

LR y ~ ELO + драфт + рынок на 391 карте (in-sample, бутстрап по сериям 500×): коэффициенты 0,73 /
0,67 / 0,55. Интервал рынка [−0,04; 1,18], ELO [0,25; 1,25].

Точность рынка по задержке: <0 с 65,8 % (38), 0–600 с 65,0 % (40), 600–900 с 69,2 % (169),
900–1200 с 55,6 % (126), >1200 с 72,2 % (18). Монотонного роста нет, признаков того, что котировка
видит ход игры, нет.

## Вне выборки: Winline поверх ELO + драфта

Решение владельца после отказа от OddsPortal: «используем то что сами парсим с winline». Проверка:
`runtime/experiments/elo/winline_first_quote_20260923/oos_market_combiner.py`, результаты в
`runtime/artifacts/elo/winline_first_quote_20260923/oos_market_combiner.json`.
- A0 — LR ELO (new3x_dur_ac) + драфт на всех картах master до начала месяца теста.
- A1 — второй шаг: логит A0 + логит рынка, обучается только на картах с котировкой из прошлых месяцев.
- A2 — один рынок.

Ориентированные котировки есть только за август (210 карт) и сентябрь (181). Поэтому A1 обучен на
августе и проверен на сентябре: коэффициенты A0 0,91, рынок 0,19. Утечки нет: максимальное время
обучения меньше минимального времени теста в обоих фолдах.

| срез | A1 − A0 точность | A1 − A0 log loss |
|---|---|---|
| все (181) | +0,55 п.п. [−2,30; +3,45] | −0,0055 [−0,0115; +0,0012] |
| pp (101) | 0,00 п.п. [−4,04; +4,00] | −0,0044 [−0,0127; +0,0053] |

Прогноз (log loss −0,002…−0,008, точность 0…+1 п.п., в пределах шума) сбылся. Рынок сам по себе (A2)
хуже A0 во всех срезах. Вывод: котировка Winline в прогноз для pp пока ничего доказанного не
добавляет. Если логировать её дальше, через несколько месяцев выборка станет достаточной для
проверки на ~0,005 по log loss.

## Механизм (гипотеза, не проверено)

Winline, похоже, выставляет линию на карту от своей оценки серии, а драфт почти не учитывает.
Корреляция с ELO 0,80, и рынок хуже его. Проверка: сравнить первую котировку карты 2 и 3 с
котировкой карты 1 той же серии. Если линия почти не двигается после драфта, гипотеза подтверждена.

## Где искать ошибку

- Все склеенные карты — после 2026-05-01. Проверить, окупается ли рынок в прошлом, нельзя, а
  выборка мала: на 308 картах интервал точности около ±5 п.п.
- У 38 карт котировка раньше `ts` (до −6 405 с). Возможно, это котировка предыдущей карты серии,
  привязанная к следующей. На вывод не влияет: без них AUC 0,691.
- 27 неориентированных карт исключены.
- Котировка записана с неизвестной маржой; снятие маржи простое: 1/o, нормированное на сумму.
