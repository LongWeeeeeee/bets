# Большой прогон: все гипотезы серии late/tower на 50k карт

**Зачем.** Серии 2–7 гоняли варианты на про-корпусе, где популяция после всех
фильтров сжимается до 20–160 карт на клетку. Это шум: доверительный интервал
шире любого измеряемого эффекта, и решение на таких числах принимать нельзя
(замечание alex). Все накопленные гипотезы проверяются одним прогоном на
50 000 паблик-карт, где на клетку приходится от нескольких сотен до тысяч
сигналов.

**Устройство.** Правило СБОРА словаря и правило ОЦЕНКИ разделены полностью:
шесть словарей собраны по разным правилам, а каждая гипотеза оценки применяется
ко всем шести одинаково. Оценка нигде не использует длину карты как условие
допуска — только «карта дожила до минуты T» плюс наблюдаемое на T состояние.

## Словари в прогоне

| словарь | правило сбора |
|---|---|
| `V0_base` | текущее прод-правило, ПОЛНЫЙ корпус (референс) |
| `S_V0_base` | текущее правило, подвыборка 400k (база сравнения) |
| `E_dur45_k05` | длина >= 45 + равенство k=0.5 |
| `E_dur40_k05` | длина >= 40 + равенство k=0.5 |
| `T_gap2_m32` | структурный перекос >= 2 очков на 32' |
| `W_tl34` | маркер «кто удержал строения к 34'» вместо победителя |

## Гипотезы

### Правило сбора
- **H1.** Длина в правиле сбора: `>=45` и `>=40+k0.5` бьют базу. Серия 5 дала
  +4…+7 п.п., но на 116–200 сигналах. Проверить на равном n и по всем правилам оценки.
- **H2.** Словарь на структурных перекосах (`tower_gap`) предсказывает камбек
  лучше обычного. На про не хватило данных (метрика была на 4–25 картах).
- **H3.** Маркер `tower_lead` («чей драфт держит строения») даёт метрику, чьё
  РАСХОЖДЕНИЕ с фактическим состоянием карты работает как сигнал на камбек —
  главная идея alex, не проверена вообще.

### Правило применения
- **H4.** Минута оценки: 28 / 30 / 32 / 34 / 38 / 42 — где сигнал сильнее.
- **H5.** Длина тестовой карты: 30–40 / 40–45 / 45–50 / 50–60 / 60+. На паблике
  сигнал падал с 79.7% до 59.0%, на про клетки были по 45–100 сигналов.
- **H6.** Верхняя граница применения: с какой минуты/длины late пора гасить
  (в проде такой границы нет вообще).
- **H7.** Состояние по нетворту: равный / отстаёт 3–8k / отстаёт 8–15k / ведёт.
- **H8.** Структурное состояние: T3-диф 0/1/2/3, линии бараков, мегакрипы.
- **H9.** Пороги `|index|`: 4 / 6 / 8 / 10 / 13 — рабочая точка по WR × объём.

### Комбинации
- **H10.** Согласие структуры и драфта -> WR (на 10k картах было 88.8%);
  конфликт -> вето (на 32' было ровно 50/50).
- **H11.** Ставка на андердога: структурно или по нетворту отстающая сторона
  при сильном late-драфте (на 10k картах 55–66% против базы 20–34%).
- **H12.** Итоговая таблица «объём × WR» по решётке (минута × состояние × порог)
  для выбора рабочей точки под прод.

## Чем НЕ мерить

AUC — она уже сделала своё дело (показала, что сигнал есть) и дальше только
маскирует объём. Решение принимается по паре «винрейт + число сигналов», а
окончательное — по цене, которой у нас пока нет (идея 1 раздела 5).

## Известные ограничения прогона

1. Паблик даёт завышенные абсолютные значения (самозасев словарей, ниже уровень
   игры) — ориентир по величине эффекта, не по абсолюту; про остаётся контролем.
2. Выборка 50k — «последние» карты патча, то есть один период меты.
3. Карты, закончившиеся раньше минуты оценки, из популяции выпадают — это
   корректно для ставки в момент T, но занижает достижимый объём.
