# E-368. Что меняет в деньгах ранний релиз early_nw_release

**Вопрос (связь с E-290, E-362).** Живое правило `early_nw_release`
(`base/ml_dispatch.py:793`, конфиг `ML_DISPATCH_EARLY_NW=1, START 240 с, MIN_LEAD 1000`)
выпускает WIN-ставку досрочно (240 ≤ game_time < 600, лид по командному NW ≥ 1000)
вместо ожидания fallback на 600-й секунде. Сторона ставки та же, исход карты тот же —
разница в деньгах только от (а) цены Winline в момент релиза против цены на 600 и
(б) ставок, которые ранний релиз отправил, а путь через 600 заблокировал бы (floor / veto /
against-ELO / dedup), или наоборот. E-290 выбрало пороги на корпусе со сдвинутыми на минуту
часами; E-362:63 — «+1 не мерили». Это единственное боевое правило ставок, чей офлайн-порог
не проверялся вживую.

**Предсказание до прогона.** Цена лидера по NW укорачивается с ростом лида, так что
price_release > price_600 на большинстве карт, в среднем +0,05..+0,15. Риск: по E-360 первая
свежая current-map котировка Winline приходит с медианой 848 с после старта карты — у многих
решений на 4–10-й минутах свежей цены может не быть (ставка уходит без прайс-чека или
блокируется floor).

**Prereg-правило (заморожено до данных, бриф STEPS 3).** Keep early release, если нижняя граница
95% CI парной ΔROI (release − 600) > −0,05 и не более 25 % ранних ставок без свежей цены;
предложить выключение (`ML_DISPATCH_EARLY_NW=0`), если верхняя граница < 0; иначе
«inconclusive, n too small» с оценкой n для полуширины CI 0,10.

## Решение

Правило не меняется (keep), прод-изменений нет — ни конфиг, ни рестарт, ни деплой.
Перепроверить, когда число парных разрешённых удвоится (~27 → 54) или если будут
подбираться пороги старта/лида (START 240 с / MIN_LEAD 1000).

## Где искать ошибку

- Dedup скрывает 29 поздних тиков: эффект «заблокировано путём через 600» не измерен
  (0 наблюдаемых блокировок ≠ 0 истинных). Джойн без `match_id` использует уникальную
  пару/карту/время — при конфликтах числовые ID не переименовываются.
- 21,6 % отправленных ставок без свежей цены, и все 8 выиграли (селекция): результат
  описывает только оценённую по ценам выборку.
- Один совместный релиз с Lane-ELO: без него +4,22 п.п. [−0,15; +8,07] — нижняя граница
  уходит в минус; скрытые более ранние обычные релизы неизвестны.
- Исходы — из кэшей (неразрешённых 7 всего / 1 отправленная); котировки — ближайшие,
  а не чеки исполнения у букмекера.
