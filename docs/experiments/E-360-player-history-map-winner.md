# E-360. Победитель карты с историей игроков против ELO A

- **Дата:** 2026-10-08, запрос владельца: «построй новую ml модель по предсказыванию
  победителя на карте. Задача обойти elo на 7пп минимум… история игроков: их
  показатели по героям, по позициям, свежие лузстрики/винстрики, перфоманс vs
  среднего на персонаже, на персонаже + позиции… в публичных матчах есть и про
  игроки». Карточка ingame-4b1k, задача orchestra `player-map-winner-20261008`.
- **Вопрос:** насколько модель после драфта (ELO A + драфт + история игроков)
  точнее боевого ELO A вне выборки; на всех лиговых картах, на картах команд бота
  (обе команды в словарях бота) и на pp.
- **Возражение до работы:** предматчевый потолок E-335 на картах бота — 67,24 %
  при K24 67,23 %, верхняя граница 70,9 % [66,0; 74,7]. +7 п.п. из предматчевой
  информации лежат за границей; после драфта граница не действует, но прошлые
  честные прибавки — +1–3 п.п. (E-322 +1,28; ранги E-337 +0,63 к K24; пул героев
  E-343 ≈0; стрики E-115 +0,0002).
- **Прогноз (записан до прогона):** полная модель на картах бота TEST26
  +1,5 п.п. [−0,5; +3,5]; паблики поверх ≤ +0,5; ≥ +4 — сначала искать утечку.

## Харнесс

`runtime/experiments/player-winner/n4_harness/eval_models.py` — помесячное
расширяющееся окно, тестовые месяцы 2025-01..2026-09: обучение на картах с
ts < начала месяца − 3600 с, серии с любой картой теста вычищены; ранняя остановка
LightGBM на последних двух месяцах обучения; гиперпараметры зафиксированы до
прогона (lr 0,03, 31 лист, min_data 200, ff 0,8, bagging 0,8, L2 1, ≤3000
раундов); близнец — L2-логистика. M0 = сырая ELO A, M1 = ELO + драфт + mapno,

парный бутстрап по сериям, 1000×. Признаки слотов сводятся в разность средних
сторон и разности по позициям R_k − D_k.

## Механизм (`lead/mechanism.py` → `mechanism_v1.json`)

Прибавка игроков (M2 − M1) сосредоточена там, где ELO команды не знает состав:

| срез | PRE n | PRE M2−M1 | TEST26 n | TEST26 M2−M1 |
|---|---:|---:|---:|---:|
| |pA − 0,5| < 0,05 | 23 515 | +2,29 | 5 320 | +1,88 |
| |pA − 0,5| 0,15–0,3 | 24 301 | +0,44 | 5 675 | +0,78 |
| у одной из сторон 0 игроков, игравших вместе за 30 д | 11 718 | **+3,71** | 2 769 | **+3,36** |
| у обеих сторон состав сыгран (5 из 5) | 56 364 | +0,81 | 11 457 | +0,93 |
| карты бота, состав сыгран (≥4) | 10 733 (оба окна) | +0,16 | | |
| карты бота, состав несыгран (≤3) | 424 (оба окна) | +0,47 | | |

ELO ведётся по команде; когда под тегом команды играет новый или сборный состав,
рейтинг описывает не тех людей, и история игроков это исправляет. На картах бота
96 % карт — сыгранные составы, там ELO уже знает силу, и игроки добавляют
+0,1–0,2 п.п.

## Контроль и где искать ошибку

- Дубликаты карт под другим id (утечка исхода в wr): одинаковый состав+герои с
  2023 г. — 7 групп с разрывом ≥ 30 мин (реальные переигровки), не влияет.
- Паб-драфт-головы обучены на пабликах 7.41 по 23.09.2026 — на картах 2026 года
  они знают мету того же периода. Прирост драфта TEST26 (+2,49) против PRE
  (+1,41) с этим согласуется. Абляция без паб-голов: `eval_nopubheads_v2` (см.
  ниже).
- Позиции = порядок слотов pro_corpus_compact (сверено с сырыми позициями STRATZ
  на 22 картах / 220 слотах); реальную игровую роль никто не проверял.
- Окно TEST26 кончается 20.09 (дальше ELO A в levels.npz нет); сентябрь 630 карт.
- Причинность по началу карты: для одного игрока перекрытий нет; базы (герой,
  позиция) могут включать карты других игроков, начатые, но не законченные к
  моменту запроса, — эффект пренебрежимый.
- Независимая проверка (Opus hard-verifier, 08.10, только чтение): VERIFIED_WITH_CAVEATS.
  V1 про-признаки перебором на 60 слотах карт бота TEST26 (wr_30d, hero_wr,
  hero_role_wr, perf_imp, imp_ewma10, streak, pro_n) — расхождение ≤ 4,3e-8,
  сыгранность 20/20; V2 пары карт с ≥ 8 общими аккаунтами за 6 ч — 7 029, ни
  одной с теми же героями, ни одной < 600 с (продолжения серий, не алиасы); V3
  все точки таблицы пересчитаны из `predictions.npz` точно, обучение 8 из 21
  фолда пересобрано независимо, train_max_ts < отсечки во всех 21; V4 склейка
  ELO (173 855) и ориентация (62,0 % против 38,0 % при перевороте); V5 паблики
  end < start, базы [день−28, день), ранги asOf < ts. Не проверялись:
  причинность самого реплея ELO A (взята из E-338), даты патча 7.41,
  пересчёт ДИ бутстрапа.
- Второй проход (lead, 08.10): точки и ДИ таблицы абляции пересчитаны своим кодом
  и своим зерном — совпали (TEST26 все +1,68 [1,11; 2,27], бот +0,49 [−0,91; 1,99]).
  `sid` недосклеивает серии примерно на 10 % (TEST26: 17 306 sid против 15 807
  групп «та же пара команд + лига, карты ≤ 8 ч подряд»). Бутстрап по
  объединённым кластерам почти не расширяет ДИ: все [1,11; 2,24], бот
  [−1,01; 1,99], PRE бот [−1,20; 0,17]. Выводы не меняются
  (`.orchestra/evidence/player-map-winner-20261008/second-pass-ci*.json`).
- Помесячно (верификатор): M1 − M0 в 2025 от +0,28 до +1,67 (типично +1,1), с
  2026-01 от +1,57 до +2,82 → верхняя граница вклада меты паб-голов в TEST26 M1
  ≈ 1,4 п.п. M2 − M1 по месяцам +0,7…+2,3 до 2026-07, потом +0,40 (2026-08,
  n=1 983) и −0,32 (2026-09, n=630) — корпус с середины августа собирает в разы
  меньше карт (E-356), месяцы шумные.
