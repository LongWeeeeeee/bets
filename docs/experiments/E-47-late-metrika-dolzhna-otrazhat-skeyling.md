# E-47. Late-метрика должна отражать скейлинг, а не «дожим»

- **Дата:** 2026-08-06 (замечание alex: late-метрика должна отражать героев,
  скейлящихся в лейт — «если игра затянулась и тяжёлые коры добрались до
  предметов, таргет должен вывезти». Медуза против Алхимика очевидна, но когда
  оба пика лейтовые, один всё равно сильнее — ловить надо это. Плюс лейтовый
  драфт может отыгрывать даже из отставания)

## Поправка к E-46

E-46 «улучшил» solo сбором на структурном перекосе, но метрика уехала в
противоположную от смысла сторону: наверх пошли Viper, Necrophos, Beastmaster,
вниз — Medusa (62.3% -> 47.5%) и Faceless Void (61.2% -> 44.8%). Это метрика
«кто дожимает сломанную игру», а не «кто сильнее в лейте». Винрейт вырос,
смысл — нет.

## Метрика скейлинга

`scaling = WR(герой при длине 45+) − WR(герой при длине 25–35)` по ячейкам
{герой, позиция}; два словаря собраны без holdout-карт, условие равенства
выключено — важна длина, а не близкий счёт.

| прибавляют к лейту | | проседают | |
|---|---|---|---|
| Medusa pos2 | **+29.0** | Lycan pos2 | **−23.7** |
| Alchemist pos4 | +26.1 | Viper pos1 | −20.1 |
| Alchemist pos5 | +22.2 | Sniper pos1 | −19.8 |
| Shadow Fiend pos4 | +21.9 | Keeper of the Light pos2 | −17.6 |
| Zeus pos3 | +21.2 | Phoenix pos2 | −17.3 |
| Faceless Void pos1 | +19.9 | Huskar pos1 | −17.2 |
| Lone Druid pos3 | +18.5 | Necrophos pos1 | −15.9 |
| Medusa pos1 | +17.7 | Beastmaster pos1 | −14.6 |

Содержательно метрика ровно та, что описана в задаче.

## Но как предиктор лучше не разница, а уровень

Скейлинг-разница на затянувшихся играх даёт 56.6–57.6%, тогда как **solo,
собранный только на играх 45+**, — 64.6–65.4%. Разница — производная, для
предсказания нужен уровень. Зато знак разницы важен сам по себе: на ВСЕХ картах
скейлинг даёт 47.8%, то есть лейтовый драфт вреден, если игра не затягивается.

## Главный результат: источник solo надо выбирать по прошедшему времени

Популяции наблюдаемы в live («игра дожила до минуты T»), порог `|idx| >= 2`,
вторая половина holdout:

| дожила до | late-solo (прод) | early_end-solo | solo коротких 25–35 | **solo длинных 45+** |
|---|---|---|---|---|
| 26' | 55.0% | **57.7%** | 54.9% | 55.8% |
| 30' | 56.4% | 56.0% | 53.1% | **57.8%** |
| 36' | 58.8% | 52.3% | 49.1% | **62.2%** |
| 42' | 60.2% | 48.7% | 45.7% | **65.3%** |
| 48' | 60.1% | 47.3% | 44.3% | **65.8%** |

- **solo на длинных играх бьёт прод-late-solo на каждом моменте после 30-й
  минуты**: +1.4 / +3.4 / +5.1 / **+5.7 п.п.** Устойчиво по половинам
  (63.4/65.3 на 42', 64.3/65.8 на 48').
- Приём симметричен, как и предполагал alex: до 30-й минуты выигрывает
  `early_end`-solo (57.7% на 26'), после — solo длинных. Каждая метрика работает
  на своей фазе, и обе портятся на чужой: early_end на 48-й даёт 47.3%, solo
  коротких — 44.3%, то есть становятся АНТИсигналом.
- При отставании лейтовый драфт тоже отыгрывает: на картах 40+ с отставанием до
  8k solo длинных даёт 67.1% против 65.9% у прод-late-solo.

## Что это значит для прода

Сейчас `mid_output.solo` берётся из одного словаря независимо от того, сколько
идёт игра. Правильнее переключать источник по прошедшему времени: до 30-й
минуты — early_end, после 36-й — словарь длинных игр. Это чистый драфт, никаких
ingame-признаков, и всё наблюдаемо в момент решения.

## Где искать ошибку

1. Словарь длинных даёт меньше ставок (3 511 против 5 219 на 42') — сравнение
   при равном объёме не делалось, часть прироста может быть отбором.
2. Проверено только на паблике; на про надо повторить (там ячейки реже).
3. Проверено только для solo — cp1vs1/duo могут вести себя иначе.
4. Прод-правило диспатча (E-46) показало, что прирост метрики не переносится на
   отбор с networth-монитором; это ограничение остаётся в силе и здесь.
