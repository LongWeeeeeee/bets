# E-40. Исторических котировок нет: чем именно заблокирована задача 3.1
- **Дата:** 2026-08-06 (разведка данных перед задачей 3.1 «цена как вероятность»)
- **Зачем запись.** Отрицательный результат по ДАННЫМ так же важен, как по замеру:
  без него следующая сессия снова потратит час на поиск котировок в архивах.
- **Что искали:** пара «наша вероятность — рыночная цена — исход» на исторических
  матчах. Она нужна и задаче 3.1, и выводу E-34 про андердогов, где прибыльность
  держится на допущении «кэф выше 2.0».
- **Где смотрели и что нашли:**

  | источник | что там | годится |
  |---|---|---|
  | `runtime/team_kills27_shadow.jsonl` | 2 158 оценок на 76 матчей, поле `odds` есть | **нет** |
  | `runtime/team_kills25_shadow.jsonl` | то же, старее (по 31.07) | нет |
  | `runtime/*_telegram_sent.jsonl` | только дедуп: `claimed_at`, `dedupe_key`, `match_id` | нет |
  | `log.txt` | обнулён 03.08 при деплое | нет |
  | `runtime/winline_odds_history.jsonl` | заведён 06.08 (задача 0.1), 113 записей на 2 карты | со временем да |

- **Главная ловушка, из-за которой источник выглядел годным.** В shadow-логе есть
  поле `odds`, и по нему кажется, что цена писалась всё время. Но у ВСЕХ 2 158
  записей `odds = 1.8` — это зашитое допущение, из которого выводится
  `ml_threshold = 1/1.8 = 0.5556`, а не снятая с рынка котировка. Проверять такие
  поля распределением, а не наличием: одно значение на две тысячи записей — это
  константа, а не данные.
- **Исхода в shadow-логе тоже нет.** `roster_kills` — историческая статистика
  команды (`ge27_rate`, `mean_kills`, окно, патч), а не результат матча. Исход
  восстанавливается только джойном по `match_id` с про-корпусом.
- **Скорость накопления.** Shadow-лог: 2 158 оценок на **76 матчей за 5.8 суток**,
  то есть **~13 матчей в сутки** проходит через оценку. История котировок пишется
  только по картам, которые опрашивает поллер, поэтому это верхняя граница. При
  таком темпе выборка в 200 карт с ценой и исходом набирается около двух недель,
  400 — около месяца.
- **Что это значит для E-34.** Вывод «андердоги модели берут 50.6% против базы
  38.3%» остаётся верным как ФАКТ, но перевести его в ROI нельзя до накопления
  цен. Ставить по нему до этого — значит принимать на веру, что кэф выше 2.0.
- **Что можно сделать раньше, без цен:** на тех же 76 матчах shadow-лога есть
  `ml_probability`, `nw_hit_count`, `nw_max_wr`, `elo_gate_eligible`,
  `tier_segment` — это живой прод-журнал решений. Проверка калибровки
  `ml_probability` на нём не требует котировок, только джойна с исходами. Выборка
  мала (76 матчей), но это РЕАЛЬНЫЕ прод-решения, а не бэктест.
- **Где искать ошибку:** (1) 5.8 суток могли попасть на затишье в календаре —
  темп 13 матчей/сутки стоит пересчитать через неделю; (2) поллер котировок мог
  стартовать не на всех картах, тогда реальное накопление ниже оценки;
  (3) `winline_odds_history` пишет строку только при ИЗМЕНЕНИИ цены — карты с
  неподвижной линией дадут одну запись, и по ним движения линии не увидеть.
