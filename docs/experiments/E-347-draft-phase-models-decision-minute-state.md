# E-347. Драфт-модели: живая точность ★ и обучение под минуту решения

- **Дата:** 2026-10-02. Запрос alex: «Ищи как можно улучшить наши ml модели обе early late all.
  Возможно есть уже свежие новые карты и можно переобучить. но меня больше интересует подход к
  обучению в целом». Продолжение E-315/E-317 (задача draft-ml-v2-20260923).
- **Вопрос:** (1) что боевые ★ четырёх драфт-моделей дают на живых про-картах на честной популяции
  (все карты, без фильтра по итоговой длительности); (2) что даст смена цели обучения: вместо
  «победа при итоговой длительности в окне» — «победа на картах, которые к минуте решения t ещё идут,
  при всём, что известно на минуте t».
- **Харнесс:** `runtime/experiments/draft-cp/phase_live_20261002/analyze.py` (живой замер),
  `runtime/experiments/draft-cp/phase_state_20261002/{build_dataset.py,run_experiment.py}` (офлайн).
- **Артефакты:** `runtime/artifacts/draft-cp/phase_live_20261002/results.md`,
  `runtime/artifacts/draft-cp/phase_state_20261002/results.md`, `results.json`, `predictions_t{10,20,31}.npz`.
- **Запуск:**
  `venv_catboost/bin/python3 runtime/experiments/draft-cp/phase_live_20261002/analyze.py`;
  `venv_catboost/bin/python3 runtime/experiments/draft-cp/phase_state_20261002/build_dataset.py && venv_catboost/bin/python3 runtime/experiments/draft-cp/phase_state_20261002/run_experiment.py`.
- **Предрегистрация:** `.omc/decisions.md`, раздел 2026-10-02 (до первых чисел). Гипотеза: на 31-й
  pp ΔLL(состояние + драфт + взаимодействия − состояние) ≤ −0,003 с ДИ без нуля. Прогноз ведущего:
  ΔLL −0,003…−0,008 — **не сбылся**, наблюдаемое −0,029 (в 4–10 раз больше).

## Исходное устройство моделей (не менялось)

`base/train_draft_phase_models.py:70-83`: логистическая регрессия по героям/позициям/парам на пабах
(6,6–7,3 млн карт), каждая фаза отдельно, популяция — по ИТОГОВОЙ длительности: Late ≥ 36 мин,
Early Win 20–34 мин, All ≥ 20 мин, Early NW — карты с наблюдаемым окном 20–28 мин. Итоговая
длительность в момент ставки неизвестна. Калибровки нет. На pp драфт даёт AUC 0,58–0,61 против
0,74 у ELO (E-319, E-322). Что уже пробовали (E-315/E-316/E-317/E-322): удвоение данных +0,2 п.п.,
только свежий 7.41f — хуже (All −0,31 п.п.), драфт по про-лигам поверх ELO +1,28 п.п. н.з.

## Часть 1. Живые ★ на честной популяции

296 живых про-карт 12.09–30.09.2026 (склейка по match_id из URL с точными наборами героев по
сторонам; 87 карт периода без исхода в корпусе, 21 — после 30.09). Первая запись карты = 00
(медиана game_time −79 с, после драфта).

| модель, ★ ≥ 0,60 на 00 | n | точность | Wilson 95 % | согласна с ELO | против ELO |
|---|---:|---:|---|---|---|
| Early NW | 187 | 51,9 % | 44,7–58,9 | 94 / 67,0 % | 93 / 36,6 % |
| Early Win | 191 | 50,3 % | 43,2–57,3 | 97 / 66,0 % | 94 / 34,0 % |
| Late | 115 | 55,7 % | 46,5–64,4 | 57 / 71,9 % | 58 / 39,7 % |
| All | 97 | 52,6 % | 42,7–62,2 | 46 / 71,7 % | 51 / 35,3 % |
| фаворит ELO | 296 | 67,6 % | 62,0–72,6 | | |

McNemar против ELO на картах расхождения: Early NW p = 0,012, Early Win p = 0,003, All p = 0,049,
Late p = 0,148 (Late хуже ELO не значимо). ДИ по сериям (155 серий) близки к Wilson. Если 87
несклеенных карт ведут себя как склеенные, итог почти тот же (Late 55,7, All 52,1); даже если все их
★ верны — не выше 64,4 % (Late), всё ниже ELO.

Early Win внутри своего окна (карта закончилась на 20–34-й) 63,6 % против 47,9 % вне — **это не
довод за модель**: у ELO та же разница (79,2 % против 63,5 %), короткие карты просто легче угадать.

## Часть 2. Модель под минуту решения (офлайн)

Популяция на минуте t ∈ {10, 20, 31}: карты с длительностью > 60·t. Признаки состояния S на минуте t:
NW, XP, разница и сумма убийств, прирост NW за 5 минут. Признаки драфта D — выходы боевых моделей
all7m (логиты All / Late / Early Win, направление и «нет маркера» Early NW); модели учились на пабах
без про-match_id, для лиговых карт они вне выборки. Обучение — лиговые карты с 2025-01-01 строго до
месяца теста (и конец карты до него), вычищены серии месяца теста; помесячно вперёд май–сентябрь.
C — на последних 10 % обучения. ДИ — 2 000 перевыборок по сериям.

pp (1 720 карт, 868 серий; на 31-й — 1 425 / 783):

| минута | Late один | All один | S | S + D | S + D + S×D | S + ELO | S + D + ELO |
|---|---:|---:|---:|---:|---:|---:|---:|
| 10-я, точность | 55,7 % | 56,6 % | 67,8 % | 68,5 % | 68,5 % | 72,0 % | 73,4 % |
| 10-я, LL | 0,6914 | 0,6811 | 0,5889 | 0,5720 | 0,5724 | 0,5405 | 0,5266 |
| 20-я, точность | 55,7 % | 56,6 % | 76,3 % | 78,5 % | 78,4 % | 77,8 % | 79,5 % |
| 31-я, точность | 57,3 % | 55,8 % | 79,6 % | 81,7 % | 81,7 % | 79,4 % | 82,1 % |
| 31-я, LL | 0,6838 | 0,6857 | 0,4216 | 0,3927 | 0,3927 | 0,4087 | 0,3809 |

| разность (pp) | ΔLL [95 %] | Δточность, п.п. [95 %] |
|---|---|---|
| 10-я: S+D − S | −0,0169 [−0,0242; −0,0093] | +0,76 [−0,75; +2,34] |
| 10-я: S+D+ELO − S+ELO | −0,0138 [−0,0209; −0,0066] | +1,40 [+0,06; +2,85] |
| 20-я: S+D − S | −0,0267 [−0,0347; −0,0180] | +2,21 [+0,80; +3,53] |
| 31-я: S+D − S | −0,0290 [−0,0383; −0,0197] | +2,04 [+0,65; +3,45] |
| 31-я: S+D+ELO − S+ELO | −0,0278 [−0,0368; −0,0186] | +2,74 [+1,45; +4,08] |
| 31-я: взаимодействия (S+D+S×D − S+D) | +0,0001 [−0,0005; +0,0006] | 0,00 |

Лиговые карты того же периода (n 20 280 на 10-й, 16 348 на 31-й) — то же: S+D − S на 31-й
ΔLL −0,032 [−0,035; −0,029], +1,8 п.п.

На 31-й в равных играх (|NW| < 3 тыс., n 239) состояние почти слепо (54,0 %), с драфтом 62,8 %;
при 3–8 тыс. 71,4 → 73,4 %; при 8 тыс.+ 91,9 → 91,9 %.

**Механизм.** Драфт сдвигает логит на постоянную величину при любом перевесе — взаимодействия ноль.
Сам по себе на про-картах он слаб (сила команд перекрывает его на 00), но состояние на минуте t снимает
неопределённость «кто сильнее сейчас», и остаётся вопрос, во что этот перевес конвертируется — на
него драфт и отвечает. Отсюда прибавка растёт с минутой (−0,017 → −0,027 → −0,029).

карты (как их посчитал прод, с живыми позициями; «нет маркера» Early NW в журнале нет — подставлено

## Часть 4. Боевые ставки на победу против ELO (подсчёт ведущего, до цен)

Доставленные ставки `market=win` журнала 12.09–30.09, одна на карту, исход по match_id
(186 из 243 склеены):

| правило | за фаворита ELO: n / выиграно | против ELO: n / выиграно | expected_wr (против) |
|---|---|---|---|
| `win_single_model_confirm` | 93 / 77,4 % | 52 / 38,5 % | 0,725 |
| `win_late_after_wait` | 19 / 73,7 % | 22 / 36,4 % | 0,665 |

Пол по кэфу `1/(expected_wr − 0,12)` ≈ 1,7 для ставок против ELO при безубыточности ≈ 2,6 по
фактической частоте.

**Окупаемость по живой цене Winline** (`runtime/experiments/draft-cp/phase_roi_20261002/run.py`,
правила цены из E-327 `eval_winline_bets.py`: последняя котировка нашей стороны этой карты не позже
ставки, возраст ≤ 300 с в игре / ≤ 1 800 с до горна, без закрытия рынка между котировкой и ставкой;
ДИ — 2 000 перевыборок по сериям). Предрегистрация до склейки цен: ROI против ELO < 0, за ELO в
[−5 %; +15 %] — обе сбылись. Воронка: 237 доставленных → 182 с исходом → 126 с ценой.

| ставки на победу | с ценой | выиграно | средний кэф | ROI [95 %] |
|---|---:|---:|---:|---|
| за фаворита ELO | 80 | 78,7 % | 1,57 | +13,9 % [−0,3; +28,2] |
| против фаворита ELO | 46 | 30,4 % | 3,60 | −17,3 % [−59,5; +27,7] |
| за фаворита, \|ΔELO\| ≥ 50 | 63 | 85,7 % | 1,51 | +20,2 % [+5,5; +34,9] |
| против фаворита, \|ΔELO\| ≥ 50 | 34 | 20,6 % | 4,05 | −45,9 % [−82,3; −5,7] |
| все | 126 | 61,1 % | 2,31 | +2,5 % [−14,5; +19,5] |

Порог 50 — `ML_DISPATCH_UNDERDOG_MIN_DIFF` диспетчера, задан в брифе до прогона как чувствительность.
При возрасте котировки 120/600 с против ELO −12,2 % [−57,9; +35,1] (n 41); при обоих ограничениях
−43,7 % [−86,0; +1,6] (n 29).

**Оговорка проверки (hard-verifier, ACCEPT_WITH_CAVEATS).** Цены совпали на 126/126 ставках независимой
склейкой, ROI до 0,1 п.п. Но против ELO при |ΔELO| ≥ 50 ставки С ценой выиграли 7/34 (20,6 %), БЕЗ цены — 10/21
(47,6 %), Fisher p = 0,070 (11 из 21 отсеяны как устаревшая котировка). С подставной ценой (последняя котировка
без ограничения возраста, медиана 742 с) против ELO при |ΔELO| ≥ 50 −13,4 % (n 48), без порога +2,5 % (n 64), за ELO
+17,5 %. Значит, в деньгах убыток ставок против ELO — направление, а не доказательство. Доказано другое: частота
выигрыша ставок против ELO 37,5 % (n 72), при |ΔELO| ≥ 50 — 30,9 % (17/55) при expected_wr ≈ 0,71 — оценка
вероятности и пол по кэфу для них не откалиброваны. Порог 50 был в брифе автору до прогона
(чувствительность), в предрегистрации `.omc/decisions.md` — нет.

## Дефекты, найденные ДО выводов

- Первый прогон автора упал на форматировании пустого слоя (|NW| ≥ 8 тыс. на 10-й); отчёт
  пересобран из сохранённых результатов без перерасчёта.
- Срез «ветка Late на 31-й» у автора (Late★ и сторона Late отстаёт или |NW| < 3 тыс., сторона Late
  выигрывает 36,9 %, n 314) **не совпадает с продом**: прод ставит за Late-сторону, если её NW ≥ порога
  таблицы (−8 546 на 31-й при WR90, `base/cyberscore_try.py:6553-6559`), то есть берёт все перевесы и
  отсекает отставания хуже 8,5 тыс. На срезе как в проде (pp n 392) Late-сторона выигрывает 75,0 %,
  модель S + D выбирает верную сторону в 80,1 %; значимость не мерилась. Цифра 36,9 % в выводы не идёт.

## Контроль (hard-verifier, Opus, свежий контекст; вердикт ACCEPT_WITH_CAVEATS)

- Повтор подгонки — совпадение до 0,0; LL/точность из predictions_t31.npz сходятся с отчётом.
- **Утечка «будущей меты» в драфт-признаки** (all7m учились на пабах до 21.09, тест с мая):
  модели 05.09 (оценочные, конец обучения ≤ 13.08) на окне 14.08–21.09: pp 31-я ΔLL −0,0252
  [−0,048; −0,001] (n 294) против −0,0250 у all7m; лиговые −0,0337 [−0,048; −0,020] (n 927).
  По месяцам на pp 31-й: май −0,0245, июнь −0,0261, июль −0,0375, август −0,0318, сентябрь −0,0176 —
  май, где «будущего» больше всего, не выделяется. Строго чистый сентябрь после 05.09: n 74,
  ΔLL +0,0019 [−0,042; +0,049] — решить нельзя.
- Гибкая модель состояния не съедает прибавку: сплайны по S против линейной −0,0007, CatBoost(S)
  хуже линейной (+0,0032); сплайны S + D против сплайнов S −0,0293.
- Позиции: канонические позиции — послематчевые Stratz; при позициях, восстановленных до игры по
  частоте героя на позиции (совпадают со Stratz на 57,6 % сторон), прибавка −0,0290.
- Убийства на индексе t — накопленные до 60·t секунд (сверка с first blood 0,993 / 0,000), заглядывания
  вперёд нет. Популяция = ровно duration > 60·t.
- Живой замер (часть 1) пересчитан независимо из сырого журнала: все числа в пределах 0,1 п.п.

## Где искать ошибку

- Нет кэфов: на 31-й рынок видит то же состояние (Pinnacle 78,1 % на 32 картах, E-327). Точность
  модели — не перевес над ценой.
- Нет проспективной проверки на картах после 21.09 (нет канонических драфт-строк).
- Индекс NW по минутам выведен по аналогии с убийствами, напрямую не проверен.
- На 10-й все склеенные карты длиннее 20 минут (покрытие канонических строк), это отбор выживших.
- pp ограничен когортой master.npz E-322 (1 720 до отбора по минуте).
- Множественных поправок нет; первичная гипотеза одна — pp, 31-я, ΔLL.

## Вывод

1. Переобучать четыре драфт-модели на свежих данных — не рычаг: кривая обучения плоская, свежих
   пабов после 21.09 нет, а про-карты после 23.09 без драфт-строк.
2. Слабость не в данных, а в цели обучения: фаза задана фильтром по итоговой длительности, а ★
   используется как самостоятельный голос. Подход, который работает: драфт-модели остаются как
   есть — извлекатели признаков, обученные на миллионах пабов, — а решение принимает модель под
   конкретную минуту ставки (00, 10-я, 31-я), обученная на лиговых картах, которые к этой минуте
   идут, с состоянием игры, ELO и выходами драфт-моделей; достаточно логистической регрессии
   без взаимодействий.
3. Для 31-й (ветка Late) такая модель даёт откалиброванную вероятность — её и надо сравнивать с
   живой ценой Winline вместо табличного expected_wr. На живых входах прибавка в log loss
   сохраняется (31-я, n 244), проспективно (после 22.09) карт пока мало для вывода.
4. Прямое следствие для живых денег: ставки, где ★ драфт-модели идёт против фаворита ELO
   (|ΔELO| ≥ 50), выигрывают 30,9 % (17/55) при expected_wr ≈ 0,71 — пол по кэфу их не отсекает.
   ROI по цене Winline −46 % только на подмножестве с ценой; с подставной ценой ≈ −13 %, ДИ через ноль.
   Решение о гейте — за владельцем. Прод не менялся.
