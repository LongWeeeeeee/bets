# E-318. Kills v3: прематчевые модели окон килов против боевой панели

- **Дата:** 2026-09-23. Запрос владельца: переобучить лиды окон 5–15 / 10–20 / 15–25 / 20–30,
  сторону side≥30 и тотал total≥55 на per-player статистике OpenDota и сравнить с тем, что
  раздаёт прод (прематч-панель `ml-models/prematch_panel`).
- **Продолжает:** [E-281](E-281-kills-relative-public-transfer.md) (относительные профили паблика),
  [E-314](../EXPERIMENTS.md) (предыдущий кандидат окон).
- **Пререгистрация** (до любых тестовых метрик): rank0 каждой цели — предзарегистрированный
  первичный результат; rank1/rank2 — вторичные; со-первичные метрики dLL и dAUC; селекция только
  на V3; тест — один запуск с lock по sha256 селекции.

## 1. Данные

**Датасеты** (`data/kills_v3_20260923/`): `od3` (онлайн), `od3u` (od3 + блок U — 9 колонок
`public_kills_block` как чистая функция 10 hero id), `od3_delay1200` (фичи пересобраны с
задержкой видимости 1200 с), `od3_frozen0911` (замороженный реплей истории:
`--history-cutoff 1789169900` = 11.09 23:38Z, `history_last_end` продовых kills).

- **Объём od3:** 233 110 query-карт (событий 267 360: 250 453 STRATZ + 16 907 OpenDota).
  Сплит: train_pool 228 532 (до purge 228 539, вычищено 7) / valid 3 151 / test 1 420.
- **Микс источников по сплитам:** train 215 926 STRATZ + 12 606 OD (~94% STRATZ);
  valid 14 + 3 137 (99,6% OD); test 262 + 1 158 (~82% OD).
- **Базовые rates (train_pool):** p_own_ge30 0,568; p_total_ge55 0,653; доля положительных лидов
  окон 0,466–0,474. Покрытие теста: team kills for 89,6%, player kills 100%.
- **Причинность:** событие истории применяется только если `end < start` запроса; номер игры
  серии считает старты < старта запроса. Аудит причинности билдера: PASS 6/6 (brute-реплей
  300 строк — 0 расхождений; канарейка max|corr| 0,338).
- **Блоки признаков:** G (глобальные лиги + серия), T (командные: килы за/против, KPM, окна,
  win rate, effective n, дни с прошлой, Poisson-ожидание, ELO), P (игроки: KDA, GPM/XPM/NW/LH/DN,
  урон, хил — суммы и средние), H (герои), S (контекст серии; serving-unverified,
  `team != 0`), U (pub-hero priors из `ml-models/public_kills`, только od3u).
  OD-only extras (`kills_v3_train.py:30` EXTRAS): `obs_placed`, `sen_placed`, `stuns`,
  `teamfight_participation`, `camps_stacked`.
- **Метки окон STRATZ vs OpenDota** совпадают точно на 65–80% карт (corr ≥ 0,993) — train на
  94% STRATZ, valid/test почти полностью OD: это смещение домена меток, а не только фичей.

## 2. Протокол

- **Валидационные трети** V1/V2/V3 = 1271/1289/591 карт. Селекция rank0 — минимум V3
  калиброванного log loss, не более двух альтернатив; селекция только на V3.
- **Тестовый lock:** `selection.json` несёт sha256 выбранных записей/моделей, сверяется до
  маркера старта теста; тест запускается один раз (`test.json` + `test_predictions/*.npz`);
  стадия `--stage test` в одиночку падала — исправлено (двойной маркер старта теста).
- **Статистика:** day-кластерный парный бутстрэп, 2000 реплик, seed 0
  (`paired_bootstrap(ours, theirs, mids, days, reps=2000, seed=0)`).
- **Пути модели:** бинарный (NB/Gaussian count path) и count-бленд; Platt-калибровка на логите
  (`platt_input=logit`, обратно совместимо). Полный проход train — 9,8 с, 2,5 ГБ (`matrix()`).
- **Сравнение с E-314:** у E-314 окна = 1 radiant-строка на карту, у нас 2 — MUST-FIX из
  hard-верификации: `collapse_to_radiant p=(p0+1-p1)/2, y=y0` (тесты: 9 passed, 4 новых
  краснели на копии до фикса). Вторичная колонка `*_sym=(p0+1-p1)/2` предзарегистрирована,
  первичная — radiant-строка.
- **Прод-панель (N3):** снапшот журнала `runtime/artifacts/kills/kills_v3_20260923/prod_journal/ml_panel_serv1_20260923.jsonl`
  (sha `bfebf5fc`), 264 карты с 12.09, 221 в нашем датасете (все — тестовый сплит).
  Цели панели: `w_*` (окна P(лид Radiant > 0)), `rad_30_25` (P(radiant ≥ 30, училась без 26–29),
  `total_55_50` (P(≥ 55, училась без 51–54) — сравнение на всех картах И на подмножестве
  с исключённой серединой. Берётся первая строка журнала на карту (`ts < end`);
  медиана `ts − start` 802 с (старт, видимо, до драфта) — панель прематчевая.
  Когорта сравнения: карты ≥ 1789171200, n 178–221.
- **Предзарегистрированные вторичные (без обратной связи от селекции):** чувствительность к
  лагу раздачи (те же rank0-модели на фичах с задержкой 1200 с; предсказание: блоки T/P EWMA
  потеряют < 0,002 LL; если выбран S — потеря больше, т.к. предыдущая карта серии
  (концы за ~5–15 мин до следующего старта) становится невидимой); бленд
  `p = (p_v3_online + p_panel)/2` на панельной когорте парным day-бутстрэпом против панели.

## 12. Вердикт

- v3 бьёт предшественников: E-281 (side30 значимо, total55 паритет) и E-314 (окна −0,013…−0,039,
  side30 −0,050, total55 −0,018 в full_u1).
- v3 НЕ бьёт боевую панель, кроме total55: окна и side30 хуже на +0,016…+0,049 LL;
  total55 лучше по LL (−0,012, нз). Бленд (v3+панель)/2 значимо лучше панели только на
  total55 (−0,0156 [−0,0271; −0,0013]); на окнах бленд не значим (5–15 −0,0035, остальные +0,008…+0,012).
- Гипотезы преимущества панели (не проверены): H2 — у панели есть блок pub-моделей героев
  (`public_kills_block.py`; по докстрингу его отсутствие стоит −0,027 LL), у v3 его не было;
  H1/H4 ИСКЛЮЧЕНЫ провенансом (explorer): панель училась на 482 486 про-картах до TEST_FROM
  2026-03-29 (`ml-models/prematch_panel/manifest.json:9`), т.е. старше v3 — ни in-sample
  (окна не дотягиваются до 09-12), ни свежести (7.41f ~09-15 чужд обеим).
- Адаптивный шаг U (после увиденного full_r1-теста) раскрыт ниже. На тесте U улучшил окна
  (−0,0047…−0,0101 LL) и total55 (−0,0052), ухудшил side30 (+0,0041); на V3 картина была иной
  (side30/total55 лучше, окна ~0 кроме 20–30).
- **Прод не менялся.** Следующий рычаг: добавить T/P-фичи игроков v3 в собственный офлайн-корпус
  панели (тест на 26k карт) вместо перестройки фич панели внутри v3. Развёртывание — только
  с согласия владельца.

## 13. Конфаунды и ограничения

- **Адаптивный шаг (раскрыт):** блок U добавлен после просмотра full_r1-теста; предрегистрация
  U-ветки сделана после этого факта, селекция full_u1 — только на V3, тест — один запуск.
- **Множественность:** первичен только rank0; rank1/rank2 вторичны. Дрейф базы
  (V2 ~0,73 против теста 0,627 для total55) примешивает сдвиг калибровки в LL — поэтому
  dAUC со-первичен.
- **Панельная когорта мала:** ~200 карт за 12 дней — эффекты < ~0,02 LL неразличимы.
- **Pub-look-ahead:** pub-модели учились по 08-09 — для train/valid-строк U заглядывает в
  будущее; для теста (≥ 08-20) чисто.
- **Метки STRATZ vs OD:** согласие окон 65–80% — train преимущественно STRATZ, valid/test OD.
- **Блок S serving-unverified:** задержка 1200 с даёт ≤ 0,0011 LL — serving-риск S мал, но
  продовой проверки нет.
- **Панель p** берётся из earliest-строки журнала; первая строка приходит через 1,6–22 мин
  после OD start_time (медиана 802 с).
- **Когорты E-281/E-314** — OD-only подмножества (парные сравнения на пересечениях).
