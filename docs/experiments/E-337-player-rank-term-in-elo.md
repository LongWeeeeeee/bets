# E-337. Ранг игроков как добавка к ELO

- **Запрос владельца (24.09.2026):** «Я считаю, что ранги игроков тоже должны как-то влиять на их общий рейтинг».
- **Предрегистрация:** `runtime/artifacts/elo/rank_prior_20260924/PREREG.md`. Дополнения A и B записаны до склейки с
  исходами. Дизайн и код до запуска прошли внешнее ревью (Codex, вердикт «пригоден после исправлений»; все
  исправления внесены).

## Данные и защита от утечки

- **Источник.** Снимки Valve для исторического теста не годятся: в них нет account_id, и они собираются только с
  18.09. Поэтому взят STRATZ — `players(steamAccountIds ≤ 5)`:
  - `ranks { rank asOfDateTime }` — смены медали;
  - `leaderboardRanks(skip, take ≤ 20)` — место в лидерборде, запись примерно раз в сутки.
- **Склейка на дату.** Берутся записи строго раньше начала карты. Место действует не дольше 35 дней. Запись
  `rank: null` значит «выпал из лидерборда» и перекрывает прежнее место. Текущие поля аккаунта не используются никогда.
- **Балл.** Медаль даёт порядковый номер 1…35, Immortal = 36. Immortal с местом получает
  36 + max(0, log2(5000 / место)).
- **Модель.** К разнице K24 добавляется w·Δбалла·g, где g = среднее по 10 аккаунтам n0/(n0 + сыгранных карт).
  Сетка: w ∈ {0…32}, n0 ∈ {∞, 50, 200}. Вариант I (старт рейтинга новичка от ранга) тоже проверен.
- **Протокол.** Выбор по log loss на валидации среди карт с покрытием, тест смотрится один раз. Контроль: w = 0
  воспроизводит K24 до 1,1·10⁻¹⁶, I(0) — до 2,7·10⁻¹⁵.

**Покрытие.** Анонимны 39 % аккаунтов: 1 817 из 4 621, в пробе было 27 из 50. История медалей есть у 2 755,
история мест — у 1 439. Места покрывают весь период: октябрь 2025 – июль 2026 по 4,5–8,4 тыс. записей в месяц. В
августе и сентябре 2026 их 20,6 и 18,0 тыс.: страница 0 (последние 20 записей) берётся всегда, а у более старых
страниц — только каждая вторая. Помесячного всплеска, похожего на задним числом дописанную историю, нет; по дням не
проверялось. Доля карт с покрытием на тесте:

| правило | pp | карты бота | все лиговые |
|---|---|---|---|
| ≥ 3 известных на сторону | 37 % | 40 % | 5,8 % |
| ≥ 2 | 74 % | 76 % | 14,6 % |

**Покрытые карты не случайны.** На тесте K24 на них точнее: 65,9 % против 60,5 % по всем лиговым картам, 70,3
против 66,8 на pp. На валидации pp обратная картина: 63,5 против 64,2. Поэтому все сравнения ниже парные.

w0 = 20), но хуже B.

## Механизм

- **Ранг — отдельная ось силы.** Корреляция с разницей K24 всего 0,26. Сильнее всего он работает у игроков с малой
  лиговой историей: выбран n0 = 50, при 500 картах вес ранга падает в 11 раз.
- **Поверх варианта E-336 точность почти не растёт.** Гипотеза (не проверено): разгон новичков ×3 уже быстро подтягивает
  рейтинг тех же игроков. Проверка — сравнить прибавку ранга на картах с новичками при K24 и при E-336.
- **До +5 п.п. ранг не доводит.** Потолок E-335 на картах бота — 70,9 % для любого рейтинга «только сила».

## Расхождения: чей выбор выигрывает (25.09, вопрос владельца)

Расхождение — карта, где оба варианта отходят от 0,5 и называют разных фаворитов. На такой карте выигрывает ровно
один выбор, поэтому Δ точности = доля расхождений · (2 · винрейт − 1). Тождество сходится до 0,001 п.п. (K24 → E-336),
26 тестовых карт с p = 0,5 ровно исключены.

**K24 → вариант E-336** (тест; в скобках — расхождения, где E-336 уверен: |p − 0,5| ≥ 0,05):

| популяция | расхождений | доля карт | выбор E-336 выигрывает | при уверенности E-336 ≥ 0,05 |
|---|---|---|---|---|
| все лиговые (31 989) | 3 457 | 10,8 % | **55,1 % [53,6; 56,8]** | 59,7 % [56,5; 63,1] (985) |
| не-pp (18 867) | 2 083 | 11,0 % | 55,5 % [53,5; 57,6] | 60,1 % [56,3; 64,2] (621) |
| pp (1 743) | 160 | 9,2 % | 53,1 % [45,7; 60,1] | 58,3 % [41,2; 73,5] (36) |
| карты бота (2 240) | 183 (≈ 9 в неделю) | 8,2 % | **48,1 % [41,2; 55,7]** | 53,1 % [39,6; 66,7] (49) |

Для справки, валидация: все лиговые 54,9 % [53,6; 56,2] на 5 247 расхождениях; pp 53,8 % [48,8; 59,2] (353);
карты бота 53,9 % [48,2; 59,9] (306).

- Расхождения лежат у 0,5: медиана |p − 0,5| у E-336 — 0,03. Винрейт растёт с уверенностью E-336: 52,0 % при
  < 0,02, 54,6 % при 0,02–0,05, 59,7 % при ≥ 0,05.
- На расхождениях E-336 откалиброван: обещает в среднем 0,538, выигрывает 0,551. K24 на тех же картах обещает 0,525
  своей стороне, а выигрывает она 0,449.
- На картах бота преимущества нет: тест 48,1 %, валидация 53,9 %, оба интервала накрывают 50 %. Гипотеза (не
  проверено): у команд бота длинная лиговая история, и разгон новичков ×3 — главный источник прибавки E-336 — там почти
  не срабатывает. Проверка — доля расхождений с новичком (< 50 карт) на картах бота против остальных.

**Ранг** (правило ≥ 2): меняет фаворита редко, но на этих картах чаще прав.

| пара | популяция | расхождений | доля карт | выбор с рангом выигрывает |
|---|---|---|---|---|
| K24 → K24 + ранг | pp | 19 | 1,1 % | 79 % [61; 95] |
| K24 → K24 + ранг | карты бота | 39 | 1,7 % | 62 % [45; 77] |
| E-336 → E-336 + ранг | pp | 14 | 0,8 % | 57 % [29; 79] |
| E-336 → E-336 + ранг | карты бота | 32 | 1,4 % | 59 % [42; 75] |

**Прогноз, записанный до запуска** (`.omc/decisions.md`, 25.09 ~01:25):

| что прогнозировал | ожидание | факт | итог |
|---|---|---|---|
| доля расхождений K24/E-336 | 8–15 % | 10,8 % | сбылся |
| винрейт E-336 на расхождениях, все лиговые | 54–58 % | 55,1 % | сбылся |
| то же, pp | 50–53 % | 53,1 % | сбылся |
| то же, карты бота | 45–50 % | 48,1 % | сбылся |
| доля уверенных расхождений | ≤ 20 % | 28,5 % | не сбылся |
| ранг на pp: доля расхождений / винрейт | 2–3 % / ~60 % | 1,1 % / 79 % | не сбылся |

Порог решения — винрейт на картах бота ≤ 45 % с интервалом ниже 50 — не достигнут.

## Где искать ошибку

- **Ретроспективность.** `asOfDateTime` STRATZ не доказывает, что место было известно в тот день: историю могли
  дозаполнить позже, а сопоставление имени и аккаунта — сделать по позднему знанию. Положительный результат нужно
  подтвердить проспективно (ранг снимается до карты) до любого использования в проде.
- **Край сетки.** Выбран w = 32, максимум сетки. Более широкая сетка — это второй взгляд на тест; не делалось.
- **Анонимность 39 %.** Покрытые карты — не случайная выборка. Сравнение парное, внутри покрытых карт, на все карты
  не переносится.
- **Шаг 2 страницы и свежесть 35 дней.** Выпадение из лидерборда в пропущенной странице даёт устаревшее место.
  Это шум, а не утечка.
- **Тест 05–09.2026** уже использовался в E-335 и E-336. Выбор здесь только по валидации.
