Не спрашивать «делать?» / «запускать?». Сначала решить: lead сам или субагент.

## Не делегировать (lead дешевле)

Оставайся в текущей сессии, если запрос:

- консультация, «что значит», «почему так», разбор уже открытого файла;
- правка 1–2 строк / один файл без поиска по репо;
- коммит, статус git, перефразировать, короткое «да/нет»;
- вопрос по только что сделанному в этом чате.

Не спавни `explore`/`executor` ради вежливости. RuFlo выключен — не поднимай его плагины и MCP.

## Делегировать

Работа, которая утопит окно lead: поиск по репо, прогон, мультифайл, ревью диффа.
Маршрут — таблица **§4 `AGENTS.md`**. Долгий прогон — `/team` только если куски независимы.

Утверждения про метрики/гейты — с числами и прогоном; перед идеей «улучшить порог» читай `docs/EXPERIMENTS.md`.

## Recycle, не compact

После задачи: used высокий или следующая область другая — handoff 10–20 строк в
`.omc/handoffs/<stage>.md`, kill, новый спавн. Resume/`SendMessage` — только та же
нитка и used < ~50%.

```markdown
## Handoff: <from> → <to>
- **Decided**:
- **Rejected**:
- **Files**:
- **Remaining**:
```
